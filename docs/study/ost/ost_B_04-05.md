# OST notes B: categories 04 (Takeoff tab in detail) and 05 (Conditions and layers)

## CATEGORY 04

### 04.00 Takeoff tab overview (id 662)
- OST-04-001: Takeoff tab (formerly "Image tab"; the old Takeoff tab became the Summary tab) is the main workspace: view plans, create Conditions, draw takeoff, draw annotations, print, manage Alternates/Change Orders, comments.
- OST-04-002: Screen regions: Image window (not undockable), toolbars (undockable), Pan window, Conditions window (tabs: Conditions list, Bid View, Zones, Planroom), Layers window, Status bar (not undockable), Resource Center panel.
- OST-04-003: Status bar shows: page n of N, page size (height x width, e.g. 36 x 48), zoom %, length of current segment while drawing linear/area, length of a selected segment.
- OST-04-004: Dockbars (Pan, Conditions, Layers) and most toolbars can be dragged out and docked elsewhere or put on a second monitor.

### 04.01 Image window (id 663)
- OST-04-005: Image window = plan viewer plus takeoff and annotation drawing surface. Pan/Conditions/Layers can be undocked to enlarge it.

### 04.01.01 Image window context menu (id 664)
- OST-04-006: Hovering a single selected takeoff object shows a popup: condition number and name, quantity results, assigned bid/typical area.
- OST-04-007: Context menu varies by click target (blank space, takeoff, typical group frame or marker, annotation). Commands: Align Grid (area with grid), Set Length (linear, manual length override), Set as Curved Segment, Set as 3-Point Curved Segment (bezier-like, adjustable ends and middle), Assign to Current Area (bid area picked in Settings toolbar Area dropdown), Count as Negative Quantity (object shown with minus sign and reduces totals), Set Typical Group Marker Count (number of markers at one spot, multiplies totals).
- OST-04-008: Annotation shapes: Change Color, Change Line Width (preset pixel list).
- OST-04-009: Submenus mirror toolbars: Tools, Zoom, Rotate/Flip, Overlay.
- OST-04-010: Reassign Condition: when all selected objects share one Style (Linear/Area/Count), pick another Condition of the same Style to move them to (since v4.00).
- OST-04-011: New Comment (icon at click point), Copy/Paste Backouts (area backouts copied to another area object or the same one), Copy Current View (image to clipboard), Rename Page, Delete Page.
- OST-04-012: Delete Page removes the page and all takeoff and annotation on it from Base Bid and every Alternate/Change Order, cannot be undone, confirmation cannot be suppressed, only allowed from the Base Bid.
- OST-04-013: Image Legend commands: Select All Image Legend Objects, Filter Image Legend to Active Areas (hides conditions not used in the active bid area; affects printing), Reset Image Legend, Group Image Legend (locks it as one unit with opaque white background).

### 04.02 Toolbars overview (id 665)
- OST-04-014: Toolbars toggled via View > Toolbars. Work Date toolbar only in DPC mode; Quick Takeoff toolbar only in unlicensed PlanViewer mode (results not saved).
- OST-04-015: Many toolbar functions duplicated in File/Edit/View/Tools/Image/Bid menus and context menus. Hover for tooltips.

### 04.02.01 Page navigation toolbar (id 666)
- OST-04-016: Controls: Back/Forward (history of last page or zoom level, like a browser), page drop-down (all pages and page folders in current bid), Previous Page (Page Up), Next Page (Page Down).
- OST-04-017: Drop-down icons: blue page icon = page has takeoff (annotations do not count as takeoff); green check = marked Takeoff Complete. Drop-down is resizable and scrolls with wheel.
- OST-04-018: Options (Tools > Options): show/hide page index and sheet number beside sheet name; sheet name always shown.
- OST-04-019: Ctrl+G opens Go To dialog to jump to a page number.

### 04.02.01.01 Advanced mouse controls (id 775)
- OST-04-020: Spacebar toggles last tool and Select; for takeoff tools toggles Select vs Takeoff. Ctrl+drag draws a zoom box.
- OST-04-021: Advanced mouse (can be disabled in Options; main Image window only): right-drag pans; wheel click toggles zoom and last takeoff tool; with Zoom tool active the wheel steps zoom levels; otherwise wheel pans vertically, Shift+wheel pans horizontally, Ctrl+wheel zooms; wheel tilt pans horizontally.

### 04.02.02 Tools toolbar (id 667)
- OST-04-022: Tools: Select, Takeoff (Space toggles), Zoom (left-click in, right-click out, drag a box; Ctrl+mouse buttons; +/- keys; Ctrl+wheel), Zoom Full Page (* key), Magnify (loupe without changing zoom; base image only when overlays present), Pan (drag; Alt+wheel vertical; Shift+wheel horizontal; right-drag), Find Text (Ctrl+F).

### 04.02.03 View toolbar (id 668)
- OST-04-023: Buttons toggle: Conditions window, Pan window, Layers window (Ctrl+L), Annotation and View window (Ctrl+2), View window (3rd), Image Legend (list of conditions and optionally results on the current page).
- OST-04-024: Annotation and View window: second image window; can annotate and set scale; cannot draw/modify takeoff, no overlays, cannot delete a page.

### 04.02.04 Annotation toolbar (id 669)
- OST-04-025: Annotation tools (do not affect quantities): Dimension line (measure without a condition), Text, Highlighter (default yellow), Callout, Arrow, Line, Rectangle, Oval, Freehand polygon, Cloud, Ink, Hot Link, Named View. Default color red except highlighter.
- OST-04-026: Exporting a bid with "Pages with Takeoff" only excludes pages that hold only annotation. Workaround: place one dummy Count object on each page to force inclusion.

### 04.02.05 Zoom toolbar (id 670)
- OST-04-027: Full Page (*), Zoom In (+), Zoom Out (-), Zoom 100% (/) based on page size, Custom Zoom (typed percent or list), preset zoom dropdown (always includes the fit-to-page level). Zoom centers on cursor.
- OST-04-028: Follow-the-leader: after two consecutive pages are set to Full Page zoom, a prompt offers to apply it to the remaining pages; answering No (default) suppresses the prompt for this bid for the session. Same behavior for rotation.

### 04.02.06 Settings toolbar (id 671)
- OST-04-029: Scale button (set page scale; must be verified before takeoff). Area dropdown lists Bid Areas and Typical Areas of the current bid; areas holding takeoff on the current page are bold; typical areas show occurrence count in parentheses. Lookup button opens Bid Areas dialog (add/edit/delete).

### 04.02.07 Mark Takeoff Complete toolbar (id 672)
- OST-04-030: Per-page checkbox; shows a green marker in the page navigator.

### 04.02.08 Takeoff BOOST toolbar (id 292)
- OST-04-031: Auto Takeoff (uploads plan set to a cloud service which returns linear/area/count conditions and takeoff), Auto Count (pick a sample symbol, finds matches across a batch of at most 20 pages), Auto Link (builds named views plus hot links pointing at detail and section sheets), Auto Scale (detects scale on all pages). Auto Name is accessed from the project cover sheet. Toggled via View > Toolbars.

### 04.02.09 Takeoff mode toolbar (id 673)
- OST-04-032: Continuous Mode (connected linear segments), Backout Mode (deduct a region from existing area takeoff), Align Grid Mode (only with a single gridded area selected), Auto Count (legacy, replaced by BOOST), Split Linear Segment (click a point on the selected object to break it in two), Split Area Object (draw a line through; cannot split an object that has backouts, delete them first), Simplify Area Object (removes unnecessary vertices).
- OST-04-033: Split and Simplify require a current maintenance subscription (licensing note).

### 04.02.10 Image toolbar (id 674)
- OST-04-034: Convert to TIFF creates a TIFF copy in a "Converted" folder and repoints the cover sheet; original untouched; offers Convert All when other PDFs exist. Used to speed page navigation.
- OST-04-035: Rotate Image Left/Right (90 degrees), Flip Horizontal/Vertical; rotation/flip also transforms takeoff and annotation on the page; display-only, image file unchanged (except overlays). If the underlying image is removed, takeoff rotation reverts to 0.
- OST-04-036: Adjust Plans dialog (display adjustments, option to apply to all plans in the project).

### 04.02.11 Rotate/Flip takeoff toolbar (id 675)
- OST-04-037: Rotates/flips only selected takeoff about the combined centerpoint of the selection. Blocked with an error if the result would extend off the page.

### 04.02.12 Overlay toolbar (id 676)
- OST-04-038: Add Overlay (choose plan to lay over current), Resize Overlay wizard (Alt+R), Align Overlay (fine tune), Deskew Overlay, Remove Overlay, Toggle Base/Overlay/Both view.

### 04.02.13 Print Area toolbar (id 677)
- OST-04-039: Toggle on; choose paper size from selected printer; portrait/landscape toggle; the region is rescaled to fit the paper. Must use its own Print button; main toolbar Print ignores the print area.

### 04.02.14 Quick Takeoff toolbar (id 678)
- OST-04-040: For PlanViewer and DPC-Foreman licenses only: Line, Area, Count, Quantity display, Delete, Units. Results are temporary, cleared on tool change, page change, bid change, or close. Needs correct scale.

### 04.02.15 Text format toolbar (id 679)
- OST-04-041: On-demand: font, size, color, bold, italic, underline, alignment. Appears only when clicking the text part of a text-enabled object (text annotation, dimension line label, area takeoff label, style label, image legend).

### 04.03 Pan window (id 680)
- OST-04-042: Thumbnail of page with a black View Indicator rectangle for the visible region; hidden when zoomed to fit or when the image is smaller than the window. Drag the indicator (left or right button) to pan. No takeoff drawing in the pan window.

### 04.04 Conditions window (id 681)
- OST-04-043: Tabs: Conditions (conditions list and typical groups with quantities for the current page), Zones, Project View (switch between Base Bid, Alternates, Change Orders; add/delete them; synced with main toolbar drop-down), Planroom (only for projects from planroom OSX files), Comments (comments/replies on this page), Views (all Named Views; filter to pages with views or All Pages; double-click opens in a new window; up to 5 view windows).
- OST-04-044: Conditions list columns showable/hideable: No., Height, Quantity 1/2/3. Can be grouped by Condition Type (default on) and organized into Condition Folders (name limit 50 chars) that collapse/expand.
- OST-04-045: Quantity column decimals controlled by a program-wide decimals option.
- OST-04-046: Zones are like bid areas but can split takeoff objects; used for phases.

### 04.04.01 Conditions window toolbar (id 682)
- OST-04-047: Buttons: Add New (context-sensitive: condition, typical group, zone, alternate, change order, folder), Edit, Delete, Duplicate, Reassign Takeoff (active when takeoff objects are selected, then pick the target condition), New Folder, Unlock Bid and DPC Mode (DPC licensing).
- OST-04-048: Removing a condition, typical group or zone from the base leaves child bids untouched; the reverse holds too.
- OST-04-049: Deleting a Condition or Typical Group always asks for confirmation (cannot be suppressed) because it deletes all objects drawn with it and all markers in the current bid. Alternate/Change Order/Zone delete confirmations can be suppressed (re-enable with "Turn on all confirmation dialogs" in Options). No undo for any of these.

### 04.04.02 Conditions list context menus (id 683)
- OST-04-050: Menu items: New (Condition, Typical Group, Folder), Insert Style Set, Change Properties (also double-click or Edit), Change Details (interactive bid mode with the bidding app), Save to Style Library, Save as New Style Set, Duplicate (assigns new number and color; multi-select ok), Duplicate and Reassign Takeoff (moves current-page takeoff to the duplicate), Set Layer, Set Type, Rename (also click twice on name), Select Objects (all objects of the condition on the current page), Reassign Objects (selected objects to the selected condition), Show Group Takeoff at Marker (project-wide typical group display), Group by Type, Expand/Collapse all Types, Expand/Collapse all Folders, Show Columns (Cond number, Height, Qty 1/2/3).

### 04.05 Layers window (id 684)

### 04.06 Annotation and View window (id 685)
- OST-04-052: Second image window (Ctrl+2 or View menu): shows any page or named view, allows annotation, set scale, creating named views and hot links; no takeoff drawing, no undo/redo (deletes are permanent). Hot links open here by default (option to change to main window or view window).
- OST-04-053: Annotation edits sync immediately between windows; takeoff drawn in the main window appears in secondary windows only after reloading the page.

### 04.06.01 View window, 3rd (id 1020)

## CATEGORY 05

### 05.01 What are Conditions (id 686)
- OST-05-001: A Condition = definition of a measurable building object. Holds name, dimensions (e.g. wall height), layer, quantity results, appearance. One Condition per unique object type; every height change needs its own Condition.
- OST-05-002: Four Styles (basic kinds): Linear, Area, Count, Attachment (plus Typical Group as a style choice). "Style" also means a Condition saved to the Masters library. "Type" is the grouping label for organizing.
- OST-05-003: A Condition is created once and used on all pages; cumulative quantities are broken out by page, bid area, type, zone on Summary/Worksheet tabs. Recommended to assign Type and Layer to every Condition.
- OST-05-004: Five ways to add a Condition: create from scratch, duplicate, add from Style Library, insert a Style Set, copy/paste between bids. Auto Takeoff (BOOST) also creates its own Conditions.

### 05.02 What are Layers (id 687)
- OST-05-005: Layers = show/hide groups. Hiding does not change quantities. System layers (not editable/deletable, can be hidden): Image, Annotation (hot links, text, dimension lines, markups, image legend), Comments, Default (takeoff for conditions without a custom layer).
- OST-05-006: Custom layers are per bid; Masters has a Default Layers list added to all new bids; changes to either do not retroactively affect the other.
- OST-05-007: Hidden layer: its objects are not printed; the Conditions on it become unusable (greyed in list, takeoff hidden); same for annotation and comments when their layer is hidden. Layers affect Image Legend and printing.
- OST-05-008: Cannot delete a layer that any Condition is assigned to (even with no takeoff); reassign first.

### 05.02.01 Adding layers (id 688)
- OST-05-009: Add via the Layers window button or via the lookup beside the Layer field in Condition Properties; typing a new layer name in the field prompts to add it. Both edit the same project-level list. New layer row: name plus Show checkbox (default checked). Layers can be renamed and reordered; non-system layers with no conditions can be deleted.

### 05.02.02 Assigning a condition to a layer (id 689)
- OST-05-010: New conditions go to the Default layer. Assign via the Layer field in Condition Properties or via multi-select (Ctrl/Shift) > right-click > Set Layer.

### 05.03 Create a condition, general properties (id 690)
- OST-05-011: Create via New button, Add Condition icon, right-click > New > Condition, or Insert key (when Conditions window focused). A Condition Wizard first asks for Style unless disabled.
- OST-05-012: Common fields: Style (Linear, Area, Count, Attachment, Typical Group, plus any saved Style Library entries), Name (limit 255 chars as of 4.00.00, was 75), Type (optional, recommended), Layers (default "Default"), Cond. No. (auto sequential, editable to any unused number). Properties dialog has General and Advanced tabs that vary by Style.
- OST-05-013: Pasted takeoff between bids auto-creates needed conditions.

### 05.04 Linear conditions (id 691)
- OST-05-014: General tab: Dimension (Height, Thickness, Slope), Appearance (Color, Pattern, pattern spacing when the pattern is not solid/transparent), Results (up to 3 quantities; Quantity 1 required, default Length in LF; Q2 and Q3 only show on Worksheet if Q1 valid), Notes.
- OST-05-015: Linear result formulas (L = total drawn length, H = height, T = thickness):
  - Length = L (units ft, in, yd, m, mm).
  - Segment Count = number of linear segments (a square = 4).
  - Surface Area single side = H * L.
  - Surface Area both sides = H * L * 2.
  - Surface Area top OR bottom = T * L.
  - Surface Area top AND bottom = T * L * 2.
  - Surface Area single end = H * T.
  - Surface Area both ends = H * T * 2. UNKNOWN: whether end area is multiplied by segment count, object count, or is a single end-cap total.
  - Surface Area all side/duct = (T * L * 2) + (H * L * 2).
  - Volume = H * T * L.
- OST-05-016: Advanced tab: Round Quantity + Round To (each segment rounded to the increment, always up, e.g. 12 in = whole feet); Drop/Run + Add Length (extra length box per segment for electrical/plumbing; if a value is preset it is prefilled per segment and editable; if blank, an empty box appears); Manual Length Entry (not to scale; length typed after the draw, no automatic length); Connect + Tolerance (connects to perpendicular objects within tolerance; defaults from Options new-project settings); Trim (stops a linear at a perpendicular object); Set as Curved Segment (all segments curved).
- OST-05-017: UNKNOWN: how Drop/Run lengths combine into Length (presumably L_total = sum(segment) + sum(drops)) and whether they feed area/volume results.
- OST-05-018: No waste factor is applied by OST on any result; waste is applied downstream in the bidding tool.

### 05.04.01 Linear slope (id 692)
- OST-05-019: Slope given as rise:run. The drawn line is the plan (horizontal) projection; true length = sqrt(run^2 + rise^2) scaled: length_true = L * sqrt(1 + (rise/run)^2). Example: 4:12 slope, 12 ft drawn gives 12.649 LF (factor 1.05409).
- OST-05-020: No industry conversion factors, no waste, no overhang. Results are exact geometry.

### 05.05 Area conditions (id 693)
- OST-05-021: General tab: Dimension (Thickness for volume; Slope), Appearance (color, pattern, spacing is display only), Results (up to 3; Q1 default Area SF), Notes.
- OST-05-022: Slope for areas: Rise:Run for plan (birds-eye) takeoff, Run:Rise when measuring on an elevation. Only area and volume are slope-adjusted.
- OST-05-023: Area results (A = area, BA = backout area, AA = attachment area, L = perimeter, BL = backout perimeter, AL = attachment perimeter, GL = grid length, V = volume, BV = backout volume, AV = attachment volume):
  - Area = A - BA (ignores attachments).
  - Area (Ignore Backout Areas) = A.
  - Area (Minus Attachments) = A - BA - AA.
  - Perimeter = L + BL - AL (formula as given; description says it includes backout perimeters and excludes attachment perimeters). UNKNOWN: why AL is subtracted here, and whether it is a doc typo.
  - Perimeter (Without Backout Perimeters) = L - BL as given. UNKNOWN: semantic is outer perimeter only, so the sign convention for BL is ambiguous.
  - Perimeter (Plus Attachment Perimeters) = L + AL.
  - Grid Length (Visible) = GL: cumulative grid line length, excludes perimeter.
  - Tile Count (Average) = area_sf / tile_area_sf (800 SF with 8 SF tile = 100).
  - Tile Count (Visible) = count of whole or partial tiles shown by grid alignment (each partial counts as one).
  - Area Counts = number of area objects on the current page.
  - Volume = A_sf * Thickness - BV (ignores attachments).
  - Volume (Ignore Backout Volume) = V.
  - Volume (Minus Attachments) = V - AV - BV.
- OST-05-024: Advanced tab: Round Quantity + Round to (per segment); Grid + Tile size + Gap (gap = grid line thickness, acoustical-ceiling style); Display Pattern While Drawing (default on; off shows outline until closed); Display Dimension (label with Quantity 1 result at the center of each object; font size adjustable); Display Name (label next to object, limited to 9 chars, longer names shown truncated with "..."; formatted per object); Snap to Linear + Position (Inner Edge, Center, Outer Edge relative to nearest parallel linear) + Tolerance (e.g. 1'6"); double-clicking inside a room outlined by linear takeoff auto-fills the area.
- OST-05-025: Gridded attachments must match parent orientation (a 2x4 grid needs a 2x4 attachment, not 4x2).

### 05.05.01 Area rounding (id 694)
- OST-05-026: Rounding applies to each drawn segment, always up to the next multiple of the increment; the display on the plan is unchanged (10'6" with a 1' increment is computed as 11'). The final area is not rounded.
- OST-05-027: Example: square 121 in per side. Round to 6 in: side 126, area = 126*126/144 = 110.25 SF (unrounded 121*121/144 = 101.67 SF). Round to 2 ft (24 in): side 144, area 144 SF. L-shape example: segments rounded individually (35 in becomes 36 in at 6 in; 86 in becomes 90 in at 6 in; at 24 in: 35 becomes 48, 86 becomes 96). Can inflate results by over 10% on irregular shapes.
- OST-05-028: Recommended practice: round totals in Excel or in the bidding tool, not here.
- OST-05-029: UNKNOWN: the polygon algorithm that turns rounded segment lengths into area for non-rectangular shapes; the article only shows rectangles and one L-shape.

### 05.05.02 Area slope (id 695)
- OST-05-030: Conversion tables: degrees to percent grade to rise:run ratio (e.g. 45 deg = 100% = 1:1; 4.7636 deg = 8.33% = 1:12; 26.565 deg = 50% = 1:2; 30 deg = 57.74% = 1:1.7321), and pitch (x:12) to degrees (12 = 45, 6 = 26.5, 4 = 18.5, 3 = 14, 1 = 4, approximate).
- OST-05-031: Math (derived): slope factor = sqrt(1 + (rise/run)^2); sloped area = plan area * factor; percent = tan(deg) * 100; ratio 1:n where n = 1/tan(deg). Uses plain trigonometry, not industry tables.

### 05.06 Count conditions (id 696)
- OST-05-032: Count conditions measure "each" objects. Shape chosen on the General tab; shape controls available dimensions and results. Area shapes: Square, Circle, Triangle, Diamond, Ellipse/Oval, Hexagon, Octagon, Rectangle. Linear (opening) shapes: RH Door, LH Door, Dbl Door, DE (double egress) Door, Win 1, Win 2, Win 3 (attachment article also lists Opening 1 and 2).
- OST-05-033: Dimensions: Height and Width for most; Rectangle also takes Depth; all other area shapes assume depth = width. Openings need only Height and Width. Objects are treated as 3D unless Height = 0. In plan view the drawn object length corresponds to the Height field (picture the object drawn on an elevation).
- OST-05-034: Display Size (percent) scales the on-screen takeoff symbol relative to its dimensional size (e.g. 50% so a 2x2 column symbol does not cover the plan).
- OST-05-035: Count result formulas (C = count, H, W, D = dimensions):
  - Count = C.
  - Total Height = C * H.
  - Perimeter = C * 2 * (W + D).
  - Surface Area top OR bottom = C * W * D.
  - Surface Area top and bottom = C * 2 * W * D.
  - Surface Area single width side = C * H * W.
  - Surface Area both width sides = C * 2 * H * W.
  - Surface Area single depth side = C * H * D.
  - Surface Area both depth sides = C * 2 * H * D.
  - Surface Area all sides = C * 2 * (H*W + H*D).
  - Surface Area all sides + top and bottom = C * 2 * (H*W + H*D + W*D).
  - Volume = C * H * W^2 (non-rectangle shapes, D = W) or C * H * W * D (rectangle).
  - The true drawn segment length is used for shape calculations, not the entered width, where they differ. UNKNOWN: exact geometry for circle/triangle/hexagon (formulas given are bounding-box style, not pi*r^2 etc.).
- OST-05-036: Result availability by shape (area shapes): Count, Perimeter, Surface Area all sides, all sides + top/bottom, top and bottom, top or bottom, Total Height are available for every area shape; both width sides: all except Circle and Triangle; single width side: all except Circle; single/both depth sides: only Ellipse/Oval and Rectangle; Volume: all except Ellipse/Oval.
- OST-05-037: Linear shape results: Count, Perimeter (top + both sides), Perimeter (4 sides), Surface Area both width sides, Surface Area single width side, for every door/window shape. Plain "Perimeter" is not offered.
- OST-05-038: Advanced tab: Connect + Tolerance (count object attaches to nearby linear/area takeoff and moves with it without changing the parent's quantity), Display Name (same 9-char label rule).
- OST-05-039: Up to three results; Q2 and Q3 need a valid Q1. Units depend on the chosen result.

### 05.07 Attachment conditions (id 697)
- OST-05-040: Attachment = Count condition tied to a Parent (Linear or Area takeoff object). Linear-shape attachments (doors, windows, openings) attach only to Linear takeoff; area-shape attachments (lights, vents, inserts) only to Area takeoff. Attached objects move with the parent.
- OST-05-041: Same General tab as Count (dimensions, appearance, shape, results up to 3). Shape drives results and allowed parent.
- OST-05-042: Advanced tab: "Backout Quantities from Parent" (default on) deducts the attachment's Quantity 1 result from the parent quantity (e.g. window area subtracted from wall SF). "Snap to Grid" lets the attachment snap to the parent's grid (e.g. light boxes in a ceiling grid).
- OST-05-043: Which parent results an attachment affects depends on the result type chosen; area results above define variants that ignore or subtract attachments (AA, AL, AV). UNKNOWN: exact formulas for how a door or window attachment reduces a linear parent's Length and surface area (which attachment result feeds which parent result).
- OST-05-044: After drawing with an attachment, its shape can only change within the same family (linear to linear, area to area).
- OST-05-045: Aligning a gridded area with attachments requires the attachments to still fit.

### 05.08 Copy and paste conditions (id 698)
- OST-05-046: Select condition(s), Ctrl+C or context menu Copy, switch to the target bid (other bid, alternate, change order), paste in the Conditions window (Ctrl+V). Copies conditions only, not takeoff. With the bidding app interactive, it must be open and licensed and the bid in Interactive mode or condition details are lost.

### 05.09 Duplicate conditions (id 699)
- OST-05-047: Duplicate with Ctrl+D, toolbar button, or context menu; multi-select ok. The copy keeps all properties except condition number and color (new ones assigned). The new copy is selected with its name in edit mode. Duplicate-and-reassign moves current-page takeoff to the copy.
- OST-05-048: With the interactive bidding link, duplicating a condition in OST also duplicates it in the bidding app including pricing items.

### 05.10 Delete conditions (id 700)
- OST-05-049: Delete via toolbar, context menu, or Delete key. Removes all takeoff drawn with the condition on all pages of the current bid only; other bids in the project are unaffected. Unsuppressible confirmation (Yes / Yes to All). No undo. To remove only takeoff, select the objects and delete them in the image window.

### 05.11 Create a Style from a condition (id 701)
- OST-05-050: Right-click > Save to Style Library (multi-select with Ctrl/Shift/Ctrl+A) saves Conditions as Styles into the master database; grouped by Condition Type (no type = group "Unassigned"). A same-name style prompts overwrite (Yes updates, No cancels). Requires Styles/Sets-Full Access right when logins are required.
- OST-05-051: Pricing from the Estimate/Worksheet tab is not stored in a Style; use Template Jobs for that.

### 05.11.01 Use a Style (id 702)
- OST-05-052: The New Condition dialog Style dropdown lists system styles (Linear, Area, Count, Attachment, Typical Group) then library styles grouped by type; type-ahead filters (auto-fills at one match). Created conditions are copies with no link back. Editing a condition or style never changes the other unless a condition is re-saved with the same name and overwrite is confirmed. Changes to a style affect only future conditions.

### 05.12 Style Sets (id 703)
- OST-05-053: Style Set = named group of Styles. Created from conditions via right-click > Save as New Style Set (auto-saves them as styles first; overwrite prompts on same name), then a dialog for Name and optional Owner. The sets list shows name, owner, style count. Also manageable in Masters > Style Library and Sets.

### 05.12.01 Insert a Style Set (id 704)
- OST-05-054: Right-click in the Conditions window > Insert Style Set, choose one or more sets, click Select; a Condition is created per style in each set. Existing conditions never change when masters change.
