# OST behavior notes, group D: categories 08, 09, 10

## Category 08: Annotations, plan markups, Image Legend

### 08.01 Annotations overview (id 735)
- OST-08-001: Annotation kinds: dimension lines, text, highlight, shapes (cloud, box, circle, ink), plus hot links and named views. Tools live on an Annotation toolbar.
- OST-08-002: Annotations are not takeoff. They add nothing to quantities and do not count when printing "pages with takeoff".
- OST-08-003: Annotations always live on a single Annotation layer; they cannot be put on any other layer.
- OST-08-004: Default font and color per annotation type are program options (Tools > Options > Fonts/Colors).

### 08.02 Dimension lines (id 736)
- OST-08-005: A dimension line is a reference line for measuring distance or checking page scale. It does not create takeoff.
- OST-08-006: Program auto-draws proximity dimension lines between nearby takeoff objects; can be disabled in Options General tab.
- OST-08-007: Draw = pick tool, click start, click end (two clicks, not drag).
- OST-08-008: Label text formatting edited by selecting the label with Select tool, which opens a Text Format toolbar; apply by clicking off. Color of an existing dimension line cannot be changed; only the default color (Options Fonts/Colors) affects new ones.
- OST-08-009: Dimension lines automatically break (split into pieces) at existing linear takeoff objects they cross, so one cannot span across linear takeoff directly. Also breaks on other dimension lines.
- OST-08-010: Workarounds: hide the layers holding the linear takeoff, or draw the line in a clear area and then move it. If vertical move is blocked, option "Restrict Lateral Movement of linear objects" must be cleared.
- OST-08-011: UNKNOWN: exact snapping/break rule geometry; whether dimension label shows scaled units with the page's unit format.

### 08.03 Text and text boxes (id 737)
- OST-08-012: Text tool: drag a box, type text, click away; then a Text Format toolbar opens for font changes. Used for field notes and special requirement callouts.
- OST-08-013: Text size is initially relative to page size (looks tiny on large plans) and is adjusted after entry.

### 08.04 Highlighter (id 738)
- OST-08-014: Highlighter draws a filled rectangle by dragging diagonally from a start corner, release to finish.
- OST-08-015: Palette of 48 selectable colors via the tool's drop-down; default yellow; default settable in Options Fonts/Colors.

### 08.05 Shapes (id 739)
- OST-08-016: Eight shapes: callout, arrow, line, rectangle, oval, polygon, cloud, ink (freehand).
- OST-08-017: Line color and line width chosen from a small drop-down arrow beside the tool button before drawing. Shapes remember last color and width across bids (global, not per project). Defaults in Options.
- OST-08-018: Callout: click arrow-tip point, drag to size the box, type message, set font.
- OST-08-019: Arrow and line: click start, click end.
- OST-08-020: Rectangle and oval: press at start, drag, release at end.
- OST-08-021: Polygon and cloud: click start, click each vertex, double-click to close/finish. Self-crossing (uncloseable) shapes are rejected like area takeoff: an audible thunk plays on an invalid segment, Esc backs up to the last valid point.
- OST-08-022: Ink: click start, hold and draw with mouse or pen, double-click to finish.
- OST-08-023: Existing shapes are resized and moved with the Select tool.

### 08.06.00 Auto Link (AI) (id 359)
- OST-08-024: Auto Link is a cloud AI feature on a "Takeoff BOOST" toolbar that creates named views and hot links for a whole project. Requires subscription tier, internet, write access, at least 2 pages. Pages are uploaded to a cloud service (licensing/legal note). Link symbols on sheets must be circles for now.
- OST-08-025: Run: click Auto Link, a welcome screen (can be suppressed) has Get Started; runs in background 20 to 30 minutes, with status popup bottom right, app remains usable.
- OST-08-026: Results: a "Views" sub-tab in the Conditions window lists created named views. It defaults to showing only pages that have named views (manual or auto). Double-click a view opens it in the Annotation and View window.
- OST-08-027: Re-run deletes all previously auto-created hot links and named views and rebuilds; manually created ones are untouched.
- OST-08-028: Revision sheets (numbered .1, .2) are weakly supported; links may point to old sheets. A popup warns when revision plans are detected.
- OST-08-029: For our clone: low priority; AI optional. UNKNOWN: how sheets are matched (sheet-number text on the symbol).

### 08.06.01 Named views, manual (id 740)
- OST-08-030: Named View = a named rectangular region (any part of a page, full page, or specific zoom) used as a navigation target; many per page allowed. Typical uses: schedules, details.
- OST-08-031: A Hot Link must point to exactly one named view; a named view may have zero or many hot links.
- OST-08-032: Create: Named View tool (own color picker, color applies to all manual named views and hot links), drag a green box from upper-left down-right, type name in the box corner, press Enter to commit. Clicking away instead creates a stray tiny view (error-prone).
- OST-08-033: Use: via hot link, or by choosing it in the View dropdown of the second View Window (button or Ctrl+2). View window allows some annotation, but takeoff and named view creation only in the main Image window.
- OST-08-034: Option "Open Hot Links in separate View Window" (default on): when off, hot links navigate in the main image window. Viewer-only licenses (no takeoff license) cannot use the second window, so option must be off.
- OST-08-035: Delete: select and press Delete or right-click Delete. Deleting a named view also deletes all hot links pointing to it.

### 08.06.02 Hot links, manual (id 741)
- OST-08-036: Hot link tool: click a spot on the page to place a small marker; a Select Named View dialog opens with two choices: pick an existing named view, or create a new one (dialog hides, tool switches to named view, user can go anywhere in the bid; the link stays at its original place and a Back button returns).
- OST-08-037: Hot links work in both Image window and View window.
- OST-08-038: Clicking a hot link activates it (navigates), so it cannot be selected by click. It must be selected by roping; then move or delete (Delete key or right-click).

### 08.07 Adjusting annotations and defaults (id 742)
- OST-08-039: Format text: Select tool, click annotation (text box, area label, dimension line label, legend text), Text Format toolbar appears (dockable), set style and size, click away to apply. Applies equally to auto-inserted proximity dimension labels and area labels.
- OST-08-040: Shape color and line width changed via right-click on the shape.
- OST-08-041: Delete via right-click Delete, main toolbar Delete button, or Delete key. Ctrl+Z restores immediately.
- OST-08-042: Defaults for future projects: Options > Fonts/Colors, choose annotation type in Default Font or Default Color list, Change Font/Change Color. New projects take the defaults; existing bids unaffected.
- OST-08-043: Shape formats (color, line depth) persist from use to use until changed.

### 08.08 Image Legend, adding (id 743)
- OST-08-044: Image Legend: an on-page table showing every condition used on the page, optional per-page quantities and condition type. Viewable and printable.
- OST-08-045: One global switch (View toolbar button or View > Image Legend); on means shown on all pages of the project, cannot be per page. Toggle again to hide on all pages.
- OST-08-046: Shows only conditions on visible layers. Default position upper-left of the image (off-screen if zoomed in).

### 08.08.01 Image Legend content (id 744)
- OST-08-047: Default legend columns: condition name, condition number, takeoff appearance swatch, Quantity 1 result. Program defaults in Options.
- OST-08-048: Per project (Cover Sheet > Preferences tab): choose which quantities to show, and toggles for Quantity Label, Condition Number, Condition Type; sort order choice of Condition Number, Name, or Condition Type. Applies to every page of the base bid, alternates, change orders.
- OST-08-049: Legend quantity is page-level (that condition's results on the current page).

### 08.08.04 Bid areas and layers vs legend (id 745)
- OST-08-050: Layer off or condition hidden removes that condition from the legend entirely.
- OST-08-051: On-screen, takeoff in non-active bid areas is drawn muted, but its quantities still count in the legend unless the legend is filtered. Print excludes takeoff outside the active area and the legend quantities are adjusted accordingly (example: a condition showing 43 SF on screen prints 21 SF when half its takeoff is in another area).
- OST-08-052: Context-menu toggle on the image window "Filter Image Legend to Active Area" makes the on-screen legend match print. It affects only on-screen display, not printing.
- OST-08-053: Option "Enable Active Area filter in Print Preview" in Options controls whether print applies the active-area filter.
- OST-08-054: Rule of thumb for clone: legend_qty(page, condition) = sum of that condition's page results restricted to visible layers and, if filter on, to the active area.

### 08.08.03 Group, ungroup, move legend (id 746)
- OST-08-055: Legend is a grouped single object by default with opaque white background; move by selecting and dragging like any object.
- OST-08-056: Ungroup via right-click uncheck "Group Image Legend": each condition/quantity item becomes an independent object with transparent background; can be moved next to takeoff as labels, individually or multi-selected (Shift-click toggles, rope). Font editable per selection.
- OST-08-057: Move ungrouped legend as a whole: context menu "Select All Image Legend Objects" or rope them.
- OST-08-058: "Reset Image Legend" in context menu restores upper-left position, grouping, and default font.

### 08.08.02 Formatting the legend (id 747)
- OST-08-059: Legend font defaults for new bids in Options Fonts/Colors; changing defaults does not alter existing bids.
- OST-08-060: Select legend item(s) to get Text toolbar; font size change grows/shrinks the whole legend. When grouped, after a font change a prompt asks to apply to all pages (default Yes) with a "Set as New Default" button writing to Options. Prompt suppressed when ungrouped.

## Category 09: Selecting and editing takeoff and annotations

### 09.01 Select, edit, delete (id 748)
- OST-09-001: Select tool: click an object to select (handles show for single); overlapping objects may need repeated clicks. Shift+click adds; clicking a selected object again deselects. Multiple selection shown with yellow highlight.
- OST-09-002: Roping (drag a box) has two modes set in Options > General: Touching (default: objects within or crossing the box) and Inclusive (only objects fully inside). Shift while using Select tool to rope additively.
- OST-09-003: Select all takeoff for one or more conditions on the current page: right-click condition(s) in the Conditions window, "Select Objects". Multi-select conditions with Ctrl (individually) or Shift (range; the article labels them oddly). Current page only.
- OST-09-004: Select All = Ctrl+A or Edit > Select All on the current page, only if focus is in the Image window. If focus is in the Conditions window it selects all conditions, and Delete would remove all conditions and all their takeoff in that bid (irreversible, confirmation prompt shown).
- OST-09-005: Delete takeoff/annotation: toolbar button, Delete key, or context menu. Undo works only until the user navigates to another page (undo stack is cleared on page change).
- OST-09-006: Deleting a condition deletes all its takeoff on all pages of that bid, with no undo, confirmed by prompt.
- OST-09-007: Hot links can only be selected by roping.

### 09.02 Resizing (id 749)
- OST-09-008: Resizing changes measurement and results. Linear: handles at both ends. Area (including backouts): handles at each corner. Hover shows resize cursor, drag to change.
- OST-09-009: Area vertices are shared by adjacent segments; moving or resizing one segment moves the two connected segments, which can change the shape unexpectedly.
- OST-09-010: Count and attachment objects cannot be resized individually; their size comes from Condition Properties dimension settings. Changing it changes all objects of that condition. To size one instance differently: create a new condition and reassign the object.
- OST-09-011: Attachments must fit horizontally on their parent object to attach.

### 09.02.00 Add or remove vertices (id 886)
- OST-09-012: Add vertex: select area object (vertices become active), hover over a segment (cursor shows crosshair with plus), click to insert a vertex. Segments/ends draggable. Extra vertices are harmless.
- OST-09-013: Remove vertex: drag a vertex onto the nearest neighboring vertex; they merge and two segments become one.
- OST-09-014: Simplify tool as automated removal (see 09.02.03).

### 09.02.01 Split segments and areas (id 1014)
- OST-09-015: Split tools live on the Takeoff Mode/Tools toolbar: Split (Linear) Segment and Split Area. Gated to maintenance-subscription users (licensing note).
- OST-09-016: Split Linear: pick split tool, select the linear object, then click on the segment at each place to break; any number of clicks. Resulting segments are independent (move, edit, delete). Tool stays active until another tool is picked (from a July 2026 release).
- OST-09-017: Split Area: select the area object, pick split tool, click to draw a splitting line across it, producing smaller areas. Since July 2026, can also draw a polygon split to cut out a section; polygon must start and end outside the area.
- OST-09-018: Area with backouts can be split, but a backout itself cannot be split (delete it, split, redraw).
- OST-09-019: Undo of a split needs multiple Ctrl+Z (twice for a linear; several for an area, since it is a sequence of actions).
- OST-09-020: UNKNOWN: how backouts are assigned to the child areas after a split; how quantities, attachments, and condition properties are inherited by the new pieces (presumably same condition).

### 09.02.02 Adjust angle by moving one endpoint (id 1051)
- OST-09-021: Segment Angle Adjustment tool (maintenance gated): select linear object, drag one end handle; the other end stays; length and angle change. If connected to another linear, the neighbor is stretched or shrunk to keep the connection.
- OST-09-022: Contrast: rotate moves both ends. This tool bypasses snap angle.

### 09.02.03 Simplify area (id 1009)
- OST-09-023: Simplify tool (maintenance gated): select area object, click Simplify; removes unneeded vertices to leave fewer, longer segments while keeping overall shape. Undo with Ctrl+Z. Useful after auto takeoff or tracing curves with straight segments.
- OST-09-024: UNKNOWN: simplification tolerance/algorithm and whether area changes slightly.

### 09.03 Copy, paste, move (id 750)
- OST-09-025: Copy/paste works within a page, across pages, and across bids (including alternates and change orders; use the Bid View tab of the Conditions window to switch bids without going to the Bids tab).
- OST-09-026: Paste auto-creates any condition missing in the destination bid.
- OST-09-027: Pasting to a page with different scale is not recommended; to a page with different size or orientation may error. Pages should have the same scale, size, and rotation.
- OST-09-028: Commands: context menu Copy/Paste, toolbar buttons, Ctrl+C / Ctrl+V. After paste the object follows the cursor/is placed then can be dragged or nudged.
- OST-09-029: Standard paste: repeated paste without moving the mouse offsets each new object slightly down-right of the previous; stacks if no room. Paste to a different page keeps the same relative location (same size/orientation).
- OST-09-030: Intelligent Pasting (option): pastes at the last cursor position (clamped near edges); if the user moves a pasted object, later pastes keep that relative offset; snaps to align horizontally or vertically with the original when near; a notice appears on first move. Works for count, linear, and rectangular area objects.
- OST-09-031: Move: Select tool, drag; arrow keys nudge. Attachments can only move within their parent; to change parent, delete and redraw. Linear objects restricted from lateral movement by default (Options: Restrict Lateral Movement of Linear Objects).

### 09.03.01 Copy/paste area backouts (id 720)
- OST-09-032: Backout copy: select a backout (may need two clicks, first click selects parent area), right-click, Copy Backouts; then right-click near target spot (same or other page), Paste Backouts; outline follows cursor centered; click to place. Can paste repeatedly. Shift-select several backouts to copy together.
- OST-09-033: To copy an area together with its backouts, rope the area (all objects get a yellow border); a single click selects only the area.

### 09.03.02 Copy/paste with attachments (id 724)
- OST-09-034: Attachments copy only if the parent is selected by roping together with them; clicking only the parent copies the parent only. Attachments cannot be copied or pasted alone because they require a parent linear.

### 09.04 Rotate and spin (id 751)
- OST-09-035: Rotate Takeoff: rotates one or many objects around one common center. Invoked from context menu Rotate/Flip > Rotate Takeoff, Rotate/Flip toolbar, or Ctrl+R. A handle with a green circle is dragged; angle snaps to the Snap Angle option (default 15 degrees); holding Shift overrides snapping temporarily.
- OST-09-036: Spin Takeoff in Place (Ctrl+S): each selected object rotates about its own center. Useful for directional count symbols.
- OST-09-037: Context menu content differs by object type and whether in a Typical Group Frame, but always includes Rotate/Flip.
- OST-09-038: UNKNOWN: flip (mirror) commands exist on the Rotate/Flip toolbar but are not detailed here.

### 09.05 Reassign takeoff (id 752)
- OST-09-039: Reassign takeoff to another existing condition of the same style only (linear to linear, area to area, count to count). The pick-list shows all like conditions, including auto-created ones.
- OST-09-040: Methods: select object(s), right-click, Reassign Condition (v4.00.00+), pick target; or right-click the target condition in the Conditions window, Reassign Objects, confirm Yes; or select target condition then the Reassign Takeoff toolbar button, confirm Yes.
- OST-09-041: Bulk: select one or more conditions, Select Objects, then Reassign Condition. Current page only; other pages keep their original condition.
- OST-09-042: Effects: results update immediately (old condition drops, new one rises) and the objects take the new condition's color/appearance.

### 09.06 Duplicate and reassign (id 753)
- OST-09-043: Right-click conditions with takeoff on the current page, "Duplicate and Reassign Takeoff": clones each selected condition (new condition number, new color) and moves all that condition's current-page takeoff to the clone. Multi-select supported.
- OST-09-044: Then open the clone's properties and edit (height, width, color, pattern). Page-scoped only. Main use case: copy takeoff from an 8 ft floor page to a 10 ft floor page and retarget heights without redrawing.

## Category 10: Typical groups, typical areas, repeating pages

### 10.01 Typical takeoff overview (id 754)
- OST-10-001: Three methods: Typical Areas, Typical Groups, Typical/Repeating Pages.
- OST-10-002: Typical Areas: multiplier only; one copy of takeoff is drawn and assigned to the typical area; counts per bid area drive multiplication behind the scenes; totals appear on Summary and Worksheet tabs; no actual takeoff shown, not usable with the field production-control product.
- OST-10-003: Typical Groups: takeoff objects defined in a frame; repeated at markers, visible; appear among Conditions and are placed much like count takeoff; become real takeoff in the field-production mode.
- OST-10-004: Repeating pages: virtual duplicates of a typical page; invisible in takeoff mode; multiply the typical page's takeoff so totals can be split by area or page; become real pages in field mode.
- OST-10-005: Typical Areas cannot coexist with Typical Groups/Repeating Pages in the same bid; chosen at project creation.
- OST-10-006: Cumulative typical results show on the Summary tab, not on the Takeoff (image) tab.

### 10.02 Typical Areas overview (id 755)
- OST-10-007: Concept: a typical area (e.g., apartment unit type) has a count per bid area; take off one instance once, assign to the typical area; quantities are multiplied by the count in each bid area. Reports break out by typical area, floor, building, or grand total.
- OST-10-008: Each instance must be identical including height; different height means a separate typical area, and since a condition holds one height, conditions must be duplicated (duplicate and reassign).
- OST-10-009: Do not put shared items (common walls between two typical units) inside a typical area; they would be over-counted. Take them off separately or as their own typical area.
- OST-10-010: Math (inferred): result(condition, bid_area) = sum over typical_areas of (takeoff_qty_in_typical_area(condition) * count(typical_area, bid_area)) plus directly assigned takeoff.

### 10.02.01 Creating Typical Areas and grid (id 756)
- OST-10-011: Enable: Cover Sheet of base bid, "Typicals" dropdown choose Typical Areas. Blocked if typical groups already used. Bid areas must exist first.
- OST-10-012: Cover Sheet > Typical Areas button opens the Typical Areas dialog: bid areas listed down the left, typical areas across (grid of counts). New button adds a typical area with a name of at most 50 characters (be descriptive, include height e.g. type plus 8'00").
- OST-10-013: Grid cell = how many times that typical area occurs in that bid area. Fill-down and fill-right helper buttons repeat values.
- OST-10-014: After OK the app computes total count per typical area, per floor, per building; shown in the Areas dropdown of the Takeoff tab. Example: 10 units per floor, 4 floors of 8 ft in 2 buildings gives 80; 5th floor 10 ft gives 20.

### 10.02.02 Assign takeoff to typical area (id 757)
- OST-10-015: Assign after drawing (recommended) or while drawing. Typical area setup (grid) must exist first, same as bid areas.
- OST-10-016: Selecting an area in the Area dropdown greys out takeoff not in that area; assigned takeoff shows in color. Area names are bolded in the dropdown if used on the current page (page-specific).
- OST-10-017: After drawing: pick area in dropdown, Select tool, select objects, right-click "Assign to Current Area". Same flow as bid areas.
- OST-10-018: While drawing: new takeoff auto-assigned to the currently selected area in the Settings toolbar; "(All Areas)" leaves takeoff unassigned. Risk: forgetting to change area when switching pages. Verify with Summary tab.

### 10.03 Typical Groups overview (id 758)
- OST-10-019: Typical Group is created like a condition at the top of the Conditions list under a Typical Groups header. Create: double-click header, or select header and click the add button, or press Insert, or right-click New > Typical Groups. The Style drop-down in Condition Properties can switch a condition into a typical group form.
- OST-10-020: Typical Group Properties fields: Style (Typical Group), Name, Layer, Cond. No., Width (marker size only), Color (frame and markers), Pattern (marker fill), Shape (marker shape), Quantity 1 (count of uses per page), Notes.
- OST-10-021: Layer assigned to the group controls visibility of markers and all takeoff shown at them; turning off the group layer hides markers and the displayed group takeoff. Objects inside the frame stay on their own condition layers.
- OST-10-022: Typical groups are height specific. After saving, the app prompts to draw the frame.

### 10.04 Drawing frames (id 759)
- OST-10-023: Frame: a rectangle drawn around takeoff; only the contained takeoff defines the group, not the frame size. Frame can be drawn before the takeoff exists. One frame per group; to redraw, delete the original.
- OST-10-024: Draw: select the group in the Conditions list, anchor-click then drag in the image, release; name appears at the bottom right of the frame.
- OST-10-025: Quantity effect: takeoff inside a frame is excluded from page and bid condition totals. Group Qty 1 is 0 until markers are placed. Condition totals are added back when objects move out of the frame, the frame is deleted, or a marker is placed on the current page.
- OST-10-026: Formula (inferred): condition_total = takeoff_outside_frames + sum over markers (takeoff_in_frame * marker_count), with negative takeoff objects subtracting.

### 10.04.01 Frame rules (id 760)
- OST-10-027: Do not overlap frames (results unpredictable though allowed).
- OST-10-028: Linear and area objects touching or inside the frame are members; a partially included object triggers a warning banner and counts as included.
- OST-10-029: Count objects and area attachments are members if their center point (the small center box) is inside the frame.
- OST-10-030: Linear attachments (e.g., doors) are members if the center of the opening is in the frame (equivalently 50 percent or more of the opening inside); the swing indicator is ignored.

### 10.04.02 Resize, move, delete frames (id 761)
- OST-10-031: Select a frame by its name panel. Resize: drag corner handles. Count of the group is unaffected but contained condition quantities change as objects enter or leave.
- OST-10-032: Move frame only (not takeoff): drag name panel; membership is recalculated. Move frame and contents: rope everything (frame border goes bold, takeoff yellow), then drag.
- OST-10-033: Delete frame only: select, Delete; takeoff stays and totals rise. Markers remain where placed but have no associated takeoff until a new frame is drawn. Delete frame with contents: rope all, Delete. Deleting a frame never affects the group or markers. To remove markers, delete the group itself.

### 10.04.03 Selecting inside a frame (id 1040)
- OST-10-034: Click selects one object; Shift+click selects several without the frame; roping also selects the frame (usually unwanted). Workaround: move the frame aside, rope, copy, move back.
- OST-10-035: Editing takeoff in a frame affects every marker in the same bid (markers are references).

### 10.04.04 Groups with alternates and change orders (id 1041)
- OST-10-036: Creating an alternate or change order recreates all existing typical group frames and markers (frames empty; takeoff not copied). Purpose: allow adding takeoff or negative takeoff inside the frame that propagates to all markers.
- OST-10-037: Typical workflow for swap: copy objects from base bid, paste into child bid frame, mark them Negative Takeoff, then draw replacement takeoff. Double-click any marker to jump to the frame page.

### 10.05 Placing markers (id 762)
- OST-10-038: A marker is a placeholder that echoes the frame's takeoff at that spot; the real takeoff exists only in the frame. Markers cannot expose individual objects for editing; edit the frame content (double-click a marker jumps to the frame, Back returns).
- OST-10-039: Place: select group, click once in the image (like count takeoff). If no frame exists, prompts to draw. Per-group context toggle "Show Group Takeoff at Marker" hides the echoed objects without changing math.
- OST-10-040: Each marker adds 1 to the group Qty 1 and adds the contained conditions' quantities to page and bid totals. Condition quantities in the list are page subtotals; bid-wide totals are on Takeoff/Worksheet tabs.
- OST-10-041: Marker near page edge: placed if the marker symbol fits even if echo is clipped.
- OST-10-042: Markers may overlap each other and other takeoff. If a marker intersects or lies inside a frame, a warning appears and the marker acts as regular takeoff, not as part of the frame content; markers are not allowed to nest inside a group.

### 10.05.01 Marker count (id 763)
- OST-10-043: Select a marker, right-click "Set Typical Group Marker Count", enter N: sets this marker's total to N (not N+1). N stacked markers appear; they can be pulled apart. Other markers unaffected.

### 10.05.02 Results after markers (id 764)
- OST-10-044: Placing one marker: group Qty 1 +1; each contained condition rises by its in-frame quantity (or falls if marked negative). Deleting markers reverses it.

### 10.05.03 Selecting, moving markers (id 765)
- OST-10-045: Select marker via rope (not by selecting its echo). Marker and echo act as one object. Shift+click or rope for multiple, including across groups.
- OST-10-046: Move by drag (same page), arrow-key nudge, or cut/copy/paste to other pages of the project; Cut deletes the original after paste (Esc cancels). Rotate and spin supported like normal takeoff.

### 10.06 Bid areas and typical groups (id 766)
- OST-10-047: Once a frame exists, the bid-area assignment of objects inside it is ignored. Only the bid area assigned to each marker counts. Summary tab grouped by area shows marker-based allocation. Unassigned markers go to unassigned.

### 10.07 Typical/Repeating pages overview (id 767)
- OST-10-048: Typical Page repeats identically in a bid; Repeating (Virtual) Pages are copies. In takeoff mode only the typical page is shown. Virtual pages are expanded in field mode.
- OST-10-049: Typical page takeoff is not counted in bid totals; only the repeating pages are (typical page acts as template). Combined with typical groups OK, not with typical areas.
- OST-10-050: Recommended order: finish takeoff on the typical page, assign it to the first instance's areas, then set repeats and virtual assignments.

### 10.07.01 Setting up repeating pages (id 768)
- OST-10-051: Cover Sheet (Pages tab) has a Repeats column per page; enter N to create N virtual pages shown indented below the typical page. Example: floors 2 through 5 means Repeats = 4.
- OST-10-052: Virtual pages inherit page size, scale, image, overlay (not editable); only Sheet No. and Sheet Name are editable. Renaming typical and virtual pages is independent.
- OST-10-053: Virtual Area Assignments can only be configured once takeoff exists on the typical page with bid areas.

### 10.07.02 Increase repeats (id 769)
- OST-10-054: Increase by entering a larger Repeats; new pages append to the bottom of the list, named after the typical page. Lowering the value is not allowed.

### 10.07.03 Decrease or delete (id 770)
- OST-10-055: Delete typical page from the Cover Sheet: removes the page, all its takeoff and all its repeating pages, with confirmation, not undoable.

### 10.07.05 Virtual Page Area Assignment (id 772)

Left column: Master Page Areas (bid areas used on the typical page, including unassigned). Right column: dropdown of all bid areas, mapping each master area to a target area for this virtual page.

## Category summary

### 08 Annotations and Image Legend (14 articles read)
- Annotations are non-quantity markups on a fixed annotation layer: dimension line, text, highlighter (48 colors), and eight shapes (callout, arrow, line, rectangle, oval, polygon, cloud, ink).
- Shape color and width persist globally across bids; defaults for new projects are in program options and never retroactive.
- Dimension lines split on linear takeoff by design; workaround is to hide layers or draw elsewhere and move.
- Named views are named page regions; hot links are click targets to exactly one named view (many links per view); deleting a view deletes its links. Second View window (Ctrl+2) is default target.
- Hot links are selected only by roping, since click activates.
- Auto Link is AI cloud automation of named views and hot links; re-run replaces only auto-made items.
- Image Legend: single global toggle, shows conditions on visible layers with page quantities; per-project preferences for content and sort set on Cover Sheet Preferences.
- Legend vs bid areas: on-screen counts all areas unless filtered; print filters to active area by default (an option).
- Legend can be ungrouped, individually moved, font-formatted, and reset.

### 09 Selecting and editing takeoff (12 articles read)
- Selection: click, Shift+click toggle, roping in touching (default) or inclusive mode, select-by-condition, Ctrl+A in image window only.
- Undo is lost on page change; deleting a condition is irreversible and removes all its takeoff in the bid.
- Resize via handles; area vertices are shared so edits propagate to neighbors; count and attachment size come from condition properties only.
- Vertex add/remove, split linear, split area (including polygon cut-out), angle adjust by one endpoint, simplify area: all editing tools, several gated by maintenance license.
- Copy/paste across pages and bids; destination conditions auto-created; scale, size, orientation should match; Intelligent Pasting remembers offsets and snaps.
- Backouts and attachments have their own copy rules (attachments only with parent roped).
- Rotate (shared center, snap 15 degrees default, Shift override, Ctrl+R) versus spin in place (Ctrl+S).
- Reassign takeoff by same style only, page-scoped; Duplicate and Reassign clones conditions then moves page takeoff.

### 10 Typical groups, typical areas, repeating pages (21 articles read)
- Typical Areas = count grid (typical area by bid area) multiplier, no visible takeoff, height specific, excludes groups and repeating pages in the same bid.
- Typical Groups = frame + markers; frame content defines group; content excluded from totals until markers are placed; each marker adds 1 times the in-frame quantities; marker count can be set to N.
- Frame membership rules: linear/area touching or inside; count/area attachment by center; linear attachment by opening center (50 percent).
- Bid area of in-frame objects is ignored; the marker's area assignment drives allocation.
- Child bids copy frames and markers (empty) so negative takeoff can adjust all markers.
- Repeating pages: Repeats column on the Cover Sheet; typical page excluded from totals; virtual pages locked except sheet number and name; Virtual Page Area Assignment maps master areas to per-page areas.
- Decreasing repeats only by deleting virtual pages; deleting the typical page destroys all.
- Field mode (separate product) explodes virtual pages and typical groups into real takeoff, typical areas not supported.
- Major UNKNOWNs: exact math and rounding for typical-area multiplication per quantity type; negative takeoff mechanics (defined in another category).
