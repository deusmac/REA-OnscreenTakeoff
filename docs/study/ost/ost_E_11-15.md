# OST notes E: categories 11 to 15 (plan organization/overlays, Summary tab, Estimate tab, pricing, printing)

## Category 11: Advanced plan organization and overlays

### 11.01 Plan organization overview (id 773)
- OST-11-001 Plan organization covers: navigation aids (sheet names/numbers, order, disciplines, folders), display quality (deskew, sharpen, darken, rotate, hi-res), converting source files to TIFF for speed, repairing broken file links, revision management via overlay compare.
- OST-11-002 Related topics: planroom downloads and paper/digitizer takeoff; virtual page assignment for repeating pages.

### 11.02 Improving page navigation (id 774)
- OST-11-003 Takeoff-tab navigation toolbar: pages dropdown (lists all pages of current bid, shows current), previous/next page arrows (sequential), back/forward arrows (view history like a browser, restores prior zoom/pan views).
- OST-11-004 Page Number is derived from the page's row position in the cover sheet grid, not an editable field. Sheet Number and Sheet Name are editable text.
- OST-11-005 Options (Tools > Options) can show/hide Page Number and Sheet Number in the navigator; Sheet Name always shows.
- OST-11-006 Three organizing steps: rename, collate (reorder), assign page folders/disciplines.

### 11.02.01 Renaming pages (id 998)
- OST-11-007 Rename in the cover sheet Plan Organizer grid (no preview) or on the takeoff tab via Edit > Rename Page or right-click Rename Page (shows the page, Next/Previous buttons step through pages).
- OST-11-008 Pressing Enter twice after typing a name advances to the next page.
- OST-11-009 Renaming changes only the displayed name, never the linked image file.
- OST-11-010 Auto Name feature (maintenance subscription) auto-reads sheet number and name from plans.

### 11.02.02 Collating pages (id 995)
- OST-11-011 Reorder rows in Plan Organizer by drag and drop onto the page they should follow, or Move Up / Move Down buttons (disabled at top/bottom). Multi-select only for contiguous rows (Shift); non-adjacent bulk moves not supported.
- OST-11-012 Changes saved on OK of the cover sheet. Takeoff tab navigator reflects new order.
- OST-11-013 Sheet Number + Name should be unique since they are the labels in the navigator. Do not edit the Image File cell (breaks link).
- OST-11-014 Delete pages: select with Ctrl/Shift, Delete button; confirmation is requested for each page that has takeoff or annotation. Deleting a page permanently deletes its takeoff and annotation.

### 11.02.03 Page folders (id 776)
- OST-11-015 Page folders group pages by discipline, floor, revision set, etc. Created with New Folder button in Plan Organizer. Default name "New Folder"; name limit 50 characters; type to rename.
- OST-11-016 Folder placement rule: new folder goes to top of grid; if a folder is selected the new one becomes a sub-folder of it; if a page (or non-folder row) is selected it is created at that page's level. A mistaken sub-folder can be dragged to top or deleted via the delete button.
- OST-11-017 Move pages into folders by drag and drop (single or multiple). Purely presentational; does not touch image files on disk.
- OST-11-018 Folders show expand/collapse arrows once non-empty. Expand All / Collapse All buttons under the grid. Folder tree also appears in takeoff-tab page navigator dropdown; collapse state on cover sheet does not affect navigator.

### 11.03 Cover sheet Image Folder (id 777)
- OST-11-019 Each page row stores an image file reference that is either relative (file name only, resolved as ImageFolder + file) or explicit (full path, ignores ImageFolder).
- OST-11-020 Image Folder field at bottom of cover sheet; defaults to the folder of the first images linked to the bid. Clearing it makes the grid show full paths.
- OST-11-021 Two buttons around the field: Change Folder (left; rewrites paths for selected pages) and Lookup Image Folder (right; browse to set the common folder). Setting Image Folder does not alter the grid text of explicit entries.
- OST-11-022 UNKNOWN: whether entries are stored internally as relative vs explicit or only displayed that way; how a file moved into a subfolder of Image Folder is represented.

### 11.03.01 Change Folder function (id 779)
- OST-11-023 Change Folder acts as find-and-replace on the path prefix of the selected pages. Dialog fields: Path (choose Image or Overlay), Change (pre-filled with selected pages' common folder), To (typed or browsed). Buttons: Change, Close.
- OST-11-024 Enabled only when all selected pages share the same folder; otherwise disabled. Repeat per folder group. Multi-select via Ctrl or Shift range.
- OST-11-025 Missing files show in red text in grid. Recommended: clear Image Folder first so full paths show.
- OST-11-026 Takeoff is stored in the database separate from the image; only a link to the file is stored. If an image is missing, takeoff is unaffected except for rotated pages: takeoff reverts to unrotated orientation until the link is restored, then rotation reapplies.

### 11.04 Missing Image Assistant (id 778)
- OST-11-027 On the image/takeoff tab, if a file cannot be found, an assistant offers Reestablish (opens a folder browse dialog) or Ignore.
- OST-11-028 Reestablish with a chosen folder re-links all other pages that came from the same original folder. Ignore: takeoff and annotation still show on a blank background, rotation reverted.
- OST-11-029 Multi-folder breaks require Change Folder repeated.

### 11.05 Visual settings, Adjust Images (id 780)
- OST-11-030 Adjusting display never edits the source file; stored as per-page display settings in database (for base images). If the same file is added again, settings must be redone. Exception: overlay adjustments modify a TIFF copy.
- OST-11-031 Adjust Images dialog (Image > Adjust Image, toolbar button, or Ctrl+I): Orientation (rotate/flip), Visualization toggles: Enhance (sharpen lines; on by default for every added image), Darken (thicken/darken lines), Invert (swap black and white), Bitonal (pure black/white, no grey/color). Checkbox "Apply to All Pages" applies to the whole project.
- OST-11-032 Shortcuts: Ctrl+E toggle Enhance for current page; Ctrl+Shift+D toggle Darken; Ctrl+I open dialog; hold Alt for pan with wheel; Shift+mouse pans horizontally; * zoom to full page; + zoom in; - zoom out; / zoom to 100%.

### 11.05.01 Rotating and flipping (id 781)
- OST-11-033 Base image rotate/flip is a stored display setting. Overlay image rotate/flip alters the overlay file itself (a copy if added via takeoff-tab Add Overlay, the original if added on cover sheet).
- OST-11-034 Rotating a page also rotates its takeoff. Separate commands exist to rotate only takeoff; blocked if rotated takeoff would no longer fit within the page horizontally or vertically.
- OST-11-035 To rotate page but not takeoff: duplicate the page on cover sheet, rotate the copy, copy/paste takeoff onto it; paste is refused if it will not fit.
- OST-11-036 Access: right-click Rotate/Flip (Rotate Image and Rotate Takeoff options), Image > Rotate/Flip, Adjust Images dialog, or Rotate toolbar. Unavailable when an overlay is assigned or the bid is in DPC mode.
- OST-11-037 Rotate = 90 degrees left (CCW) or right (CW). Flip = mirror horizontal or vertical (not equal to 180 rotation). Toolbar also has Convert to TIFF and Adjust.
- OST-11-038 Follow-the-leader: if two consecutive pages are rotated/flipped (or zoomed to Full Page) the same way, a prompt offers to apply to remaining pages. Default answer No; no re-prompt this session for that bid until two more consecutive same actions.

### 11.05.02 Deskew (id 782)
- OST-11-039 Image > Deskew opens a dialog; user drags a line across a known-horizontal feature left to right; display rotates so that line is level. Longer line gives better accuracy. Typical correction is only a degree or two.
- OST-11-040 Base deskew is a stored setting; overlay deskew rewrites the overlay file.
- OST-11-041 UNKNOWN: exact angle storage/precision, and whether deskew combines with 90-degree rotation setting as additive angles.

### 11.06 Convert to TIFF (id 783)
- OST-11-042 Built-in converter produces Group 4 TIFF from nearly any base image type (PDF, DWF, DWG, PLT, raster). Pros: faster load/nav, fewer resources. Cons: lower resolution, bigger disk and bid-package size, TIFF cannot be used with Auto Name; automation tools (Auto Takeoff, Auto Count, Auto Name, Auto Link) work better on native PDFs. Recommended to keep PDFs unless performance is poor.
- OST-11-043 Precondition: option "Disable High Resolution images" in Tools > Options must be unchecked, else the TIFF is low-res. Conversion captures the image as displayed (color/hi-res or bilevel/lo-res).
- OST-11-044 Only licensed users may convert. Originals untouched; copies stored in a "Converted" folder next to the original; cover sheet repointed to the TIFF.
- OST-11-045 Command: Image > Convert Current Image to TIFF. PDFs: a multipage PDF or other unconverted PDFs triggers "convert all?" prompt. Yes: one TIFF per page named original(1).tiff, original(2).tiff, etc. No: current page only. CAD files convert one at a time only. Only PDF supports convert-all.
- OST-11-046 Existing TIF/TIFF files can be converted to G4 only at the moment they are added (prompt); no later command. Workaround: add again then repoint links.
- OST-11-047 Progress bar shown; app may appear Not Responding while running.
- OST-11-048 No menu command to convert overlays (see 11.07.06).

### 11.07 Overlays overview (id 784)
- OST-11-049 Overlay shows an addendum drawing over the base to reveal differences. Rules: one overlay per base page (multiple addenda need duplicated base pages); overlay must be single page (only page 1 of a multipage PDF); overlays always display greyscale.
- OST-11-050 Colors: items only on the overlay appear blue (additions); items only on base appear red (deletions); matching content reads as grey (purplish grey when aligned). Pixel-level differences show at high zoom, expected.
- OST-11-051 Adding via takeoff tab auto-attempts to resize overlay to the base; saves a TIFF copy in an "Overlays" subfolder under the cover sheet Image Folder; cover sheet points to the copy. Adding via cover sheet makes no copy (changes hit the shared file) unless resized.
- OST-11-052 Overlay toolbar (below image toolbar, right): Add Overlay, Resize Overlay (Alt+R), Align Overlay, Deskew Overlay, Remove Overlay, Toggle Base / Overlay / Both view.
- OST-11-053 DPC: overlays are not included in DPC bid packages nor visible to foremen; do not draw takeoff while only the overlay is shown; swap base and overlay or duplicate page so base is the field-facing plan.

### 11.07.01 Selecting overlay (id 785)
- OST-11-054 Right-click > Overlay > Select Overlay Image, or toolbar Add Overlay: Add Image dialog, then an Overlay Orientation window (choose orientation relative to base). Wizard can be suppressed ("Do not show this again"); re-enable via Tools > Options "Show all Quick Start Wizards".
- OST-11-055 After orientation, OST tries to match size, then prompts deskew, align, resize. Best viewed zoomed out. For many overlays use the cover sheet method.

### 11.07.02 Deskew overlay (id 786)
- OST-11-056 Prompt Yes/No after add. Uses Select tool to drag along a horizontal line of the blue overlay left to right. Then prompts for resize.

### 11.07.03 Resize overlay (id 787)
- OST-11-057 Two-point calibration: click point A on overlay (upper left, large crosshair), then corresponding point on base (small crosshair); then point B near lower right on overlay, then matching base point. Overlay is scaled (and positioned) so both pairs coincide. Final base point can be re-clicked to fine tune. Accept dialog OK.
- OST-11-058 Resize edits the overlay file (TIFF in Overlay folder). Can be started later via right-click Overlay > Resize Overlay Image or toolbar. Needed when overlay DPI/size differs a lot (cover sheet adds).
- OST-11-059 UNKNOWN: scale math from the two point pairs; whether non-uniform (x vs y) scale is allowed or uniform only; whether rotation is derived from the pairs.

### 11.07.04 Align overlay (id 788)
- OST-11-060 Align tool: a line with green circles at both ends. Move handle drags overlay (arrow keys nudge); rotate handle spins about the center axis. Goal: predominantly grey. Then adjust takeoff for changes.

### 11.07.05 Multiple overlays via cover sheet (id 789)
- OST-11-061 Process: create a page folder named Overlays, Auto Add overlay files, copy each Image File path (Ctrl+C) and paste into the base page's Overlay Image cell. Cover sheet columns include Overlay Image and Show (values Original, Overlay, Both).
- OST-11-062 No orientation/deskew/resize wizards run. Edits write directly to shared files, so copy overlay files into their own folder first. Cover-sheet-added overlays are not optimized for view/print without the base.

### 11.07.06 Convert overlays to TIFF (id 790)
- OST-11-063 Method 1: add overlays as pages in an Overlays folder, convert all (PDF) to TIFF on the image tab, paste TIFF paths into Overlay field. Method 2: duplicate pages with overlays, move Overlay Image path into Image File on duplicates, convert, move paths back, delete duplicates.

### 11.08 Planroom projects (id 791)
- OST-11-064 Planroom projects arrive as .osx files; opening creates a project in the active database and adds a Planroom tab to the Conditions window for that project only. Planroom tab lists documents, controls downloading, checks for revisions.
- OST-11-065 Buttons: Download Selected Page (to Tools > Options > Folders > Planroom Folder, subfolder per project), Download All, Delete Page (file only), Cancel Download.
- OST-11-066 Status colors: white = not downloaded; yellow = current; red = update available; green = update downloaded; broken icon = unavailable.
- OST-11-067 On opening the image tab an update prompt may appear; Yes applies updates (pages may be added, deleted, renamed; takeoff on deleted pages is lost); No defers to next open. Check cannot be disabled; not reversible.
- OST-11-068 Some PDFs open in external viewer ("press Enter to view") per publisher setup. Bid date on Bids tab is editable on cover sheet, overwritten by planroom updates. Downloaded plans remain viewable if files remain locally. Print current view prints exactly what is on screen scaled to paper.

### 11.09 Paper plans (id 792)
- OST-11-069 Paper plans: recommend scanning or reprographics. Digitizer use supported. (Marketing content otherwise.)

### 11.09.01 Digitizer (id 793)
- OST-11-070 Supports GTCO-compatible digitizers and a vendor table; licensed users only (not the free viewer). Concepts: digitizer, stylus, mouse template (region where the stylus acts as mouse), active region, takeoff area, device info.
- OST-11-071 Setup: Digitizer > Use Digitizer; Device Info should list device; Place Template (click two template targets either side of the OST label; beeps confirm; Reset available).
- OST-11-072 Set Takeoff Area per page: place plan squared to grid, mark upper-left and lower-right with pencil, Digitizer > Set Takeoff Area, click upper-left then lower-right corners. Checkbox Apply to all Pages (not recommended). Stylus input outside the area is ignored except in mouse template region.
- OST-11-073 UNKNOWN: coordinate mapping math from digitizer to page (assumed linear between the two corners) and how scale is set for paper plans.

## Category 12: Summary tab

### 12.01 Summary tab detail (id 794)
- OST-12-001 Tab renamed: former Takeoff tab is now Summary tab (version 3.98.18.03); old Image tab became Takeoff tab. Shows per-condition quantity breakdown by the results chosen in Condition Properties (LF, SF, EA).
- OST-12-002 Can group by Zone, Area, Page, Type, any combination. Spreadsheet-like grid: click header to sort (arrow shows direction), drag header to reorder columns, drag column edge to resize, rows can be copied and pasted like a spreadsheet.
- OST-12-003 Bid View drop-down above tabs switches between base bid and child bids (alternates, change orders).
- OST-12-004 Default view is grouped by Area (broken by area per condition).
- OST-12-005 Delete a condition from this tab: removes all takeoff for it in the current bid only (not whole project), permanent, no undo. Not allowed while grouped by Area, Page or Zone.
- OST-12-006 Export to spreadsheet supported.

### 12.02 Summary context menus (id 795)
- OST-12-007 Two right-click menus: on condition info cells (No., Name, Height, Area, UOM columns): grouping options, expand/collapse, Delete (disabled when grouped by Area/Zone/Page; confirmation always asked, cannot be turned off). On a quantity cell: adds Show Decimal Places.
- OST-12-008 Decimal places set per column; applies on Summary tab and Conditions window. Display rounding only; full precision value stored and used in all calculations.

### 12.03 Grouping and sorting (id 796)
- OST-12-009 Group by Area, Zone, Type, Page via right-click toggles. Nesting order of groups: Pages, then Type, then Zones, then Areas. Group headers always sort ascending alphanumeric; column sort changes only the rows inside each group. Exception: area groups follow the layout order of the Bid Areas dialog.
- OST-12-010 Many groupings produce unwieldy output.

### 12.04 Summary report (id 797)
- OST-12-011 Print Preview button builds a report using current sort and grouping. Option Omit Notes on Report suppresses condition notes. Report exportable. Condition color/pattern icon prints with the row.

### 12.05 Typical areas on Summary (id 798)
- OST-12-012 Option "Takeoff + Typical Groups/Areas Totals": when not grouped by Area, conditions inside typical areas are listed at top with light grey highlight, Area column names the typical area. Number of uses is found on the Typical Area dialog on the cover sheet.
- OST-12-013 When grouped by Area: each typical area shown at top as a single-instance breakdown, then allocated quantities by bid area below.
- OST-12-014 Without the option there is no indication quantities come from typical areas. "Individual Typical Group Totals" applies only to typical groups.
- OST-12-015 UNKNOWN: precise formula; presumably allocated qty = single-instance qty * number of uses per bid area; not stated.

### 12.06 Typical groups on Summary (id 799)
- OST-12-016 With the totals option and no area grouping: conditions in a typical group frame listed at top (grey), Area column = group name. Grouped by Area: each group is a header with use count in parentheses, quantities are cumulative. "Individual Typical Group Totals" shows the amount inside a single frame instance.

### 12.07 Repeating pages on Summary (id 800)
- OST-12-017 Takeoff tab conditions window shows single-instance quantity of the typical page (example about 100 SF) with a green banner giving the repeating (virtual) page count (example 5). Summary shows totals across all virtual pages; area allocation per repeating page is shown under the condition and rolled into a "Multi-Area Total" cell. Area breakdown exists only if Virtual Page Assignments are configured.
- OST-12-018 Example math: single page 100 SF repeated 5 times assigned to Floors 1 to 5 gives 500 SF total, 100 SF per area (inferred).

## Category 13: Estimate tab

### 13.01 Estimate tab detail (id 803)
- OST-13-001 Tab was formerly Worksheet; renamed Estimate (3.98.18.03). Lists totals for every condition (used or not) in current bid (base, alternate or change order). Conditions without takeoff can have a quantity typed in manually.
- OST-13-002 Green columns: Material, Labor, Subcontractor unit amounts; Total computed from these and Quantity 1. Basic: total = Quantity1 * (material + labor + sub) (inferred; article states totals use these values and Quantity 1). To base cost on a different measure, set Result 1 in Condition Properties.
- OST-13-003 Checkbox to hide conditions with no quantity (zero).
- OST-13-004 Column reorder and resize like Summary; for versions before 4.0.0.821, do not move the green calculation columns because formulas depend on column positions.
- OST-13-005 Deleting a condition here is permanent and removes its takeoff (text says throughout the project here; the other tab articles say current bid; UNKNOWN which).
- OST-13-006 Estimate-tab pricing is not saved with a condition Style; use Template Jobs to reuse conditions with pricing.

### 13.02 Estimate context menus (id 801)
- OST-13-007 Right-click condition No./Name: group by Type and Page, expand/collapse, edit Condition Properties, open QuickBid condition details when connected, delete condition (permanent, confirm cannot be disabled).
- OST-13-008 Quantity column menu adds decimals setting per result column. Estimate tab decimals are independent of the conditions window; only Summary tab changes affect the conditions window. Rounding is display only.

### 13.03 Estimate grouping (id 802)
- OST-13-009 Group by Type, Page, both, or none. Hierarchy: Page first, Type nested under it.
- OST-13-010 Grouped by page: a condition has several rows but one set of Mat/Labor/Sub unit prices; editing one row changes all rows.

### 13.04 Estimate report (id 804)
- OST-13-011 Report is WYSIWYG of current grouping/sort via main toolbar print preview; exportable.

## Category 14: Pricing

### 14.00 Pricing options (id 312)
- OST-14-001 Three pricing methods: Estimate tab (rough unit cost), Microsoft Excel (links of condition results to cells), QuickBid (interactive or manual). Also export Summary/Estimate to CSV for other estimating tools.

### 14.01 Rough estimate on Estimate tab (id 805)
- OST-14-002 Cover sheet field Price Using decides method; one method for base, alternates and change orders. Default for new projects is Estimate tab; changeable in Tools > Options, New Projects, Price Using.
- OST-14-003 Per condition inputs: Material, Labor, Subcontractor dollars; total uses Quantity 1; manual quantity allowed for conditions without takeoff.

### 14.02 Price using Excel (ids 806, 807, 808)
- OST-14-004 Each condition result links to a specific cell or named range. Refresh (F9 or Bid > Refresh Worksheet) pushes quantities to Excel; default prompts to refresh on leaving a bid or closing (option "Prompt to refresh worksheet before closing Bid").
- OST-14-005 Set up: Price Using = Microsoft Excel (cell or name); Lookup chooses workbook; one project to one workbook; one bid per workbook; all bids of the project share the workbook but may use different sheets. Each bid's conditions must be linked separately (a link in base bid does not link the same condition in an alternate).
- OST-14-006 Cell mode: absolute address; inserting rows/columns does not move the target (still writes A1 etc.). Name mode: OST defines a named range so layout changes are safe.
- OST-14-007 Link flow: in Condition Properties click Link icon, workbook opens, double-click target cell, reference fills the result's Export box (read-only afterwards; relink via button). Repeat for each result of each condition.
- OST-14-008 Values sent are cumulative condition results for the whole bid (as seen on Summary and Estimate); no breakdown by type, area, zone or page. Must refresh after any change to results (draw, delete, typical changes). Requires full-licensed Excel.

### 14.03 Price using QuickBid overview (id 809)
- OST-14-009 Interactive project links OST bid to a QuickBid bid. Preconditions: both licensed, no bid filters in either, QB database open with create rights. Shared SQL: server name typed identically (case) in both apps.
- OST-14-010 Synchronized from OST to QB: conditions, bid areas, typical areas, takeoff quantities, alternates, change orders. Interactive mode syncs immediately; manual mode refreshes on F9.

### 14.03.01 Creating interactive bid (id 810)
- OST-14-011 Always starts in OST. Cover sheet Price Using = QuickBid (interactive) or QuickBid (manual); a Database lookup then appears listing databases currently available to QB. Interactive needs QB running; if user declines to start QB, project is created in manual mode and can be switched to interactive later, which creates the QB side.
- OST-14-012 Link icons: blue QB icon beside bid in OST Projects tab; green OST icon beside project in QB. Rights errors: clear filters, licensing, Full Access to bids list.

### 14.03.02 Rules and warnings (id 811)
- OST-14-013 Ownership: create projects, alternates, change orders, conditions (add/modify/delete), bid areas and typical areas, and quantities in OST (including manual quantities on Worksheet/Estimate tab). In QB, condition add/delete and quantity edits are disabled for linked jobs. QB owns: material and labor items on conditions, labor, material and all other costs.
- OST-14-014 Open QB condition details from OST: right-click condition > Change Details; default can be set via Options "Default dialog for Condition Change button".
- OST-14-015 One OST database to exactly one QB database, 1:1. Synchronized shared tables: Employees, Job Statuses, Condition Types, Cost Codes, Payroll Classes. One estimator at a time per interactive bid. Do not share Access databases; use SQL Server for sharing.
- OST-14-016 Do not renumber bids after creation (use Job No. field for custom numbers). After upgrade open QB first, then OST. Avoid special characters in names of bids, conditions, areas, typical areas, cost codes, payroll classes, job statuses, job types, condition types. Never open linked bid when other app is missing or unlicensed.

## Category 15: Printing

### 15.01 Printing overview (id 812)
- OST-15-001 Projects, Summary, Estimate tabs print or export; Takeoff tab prints to any printer, plotter or PDF generator. Print ranges: Current View, Current Page, Pages with Takeoff, All Pages; scale options incl. print-to-scale; Print Area tool. Relies on Windows print subsystem; avoid disconnecting default printer.

### 15.02 Printing tab reports (id 813)
- OST-15-002 Select tab, press Print Preview to generate the tab report; print or export (Bids/Projects tab report has Print button top left, export button). Related: bid packages via file, email, Project Express.

### 15.03 Takeoff tab print preview (id 814)
- OST-15-003 Open via Print icon, File > Print, or Ctrl+P; preview always shown. Printer settings are not saved by OST.
- OST-15-004 Toolbar: Print, Print Setup (page size, orientation), Range (Current View default, Current Page, Pages with Takeoff, All Pages; resets to Current View every open), Size (Fit to Page or 100% full size), Crop checkbox (select which printed sheets of a multi-sheet output; disabled with Fit to Page; needs multipage view), Show Footer, page navigator, single/multi page preview, Close.
- OST-15-005 Footer content: page name, print scale percent, project name, database, date and time.

### 15.03.01 Areas and layers in print (id 815)
- OST-15-006 Layers: only conditions on layers set to Show are shown and printed. Bid areas: only takeoff in the active area (area dropdown) prints, though other areas are shown greyed on screen. Option "Enable Active Area filter in Print Preview" (Tools > Options) off means all takeoff prints in full color. Image legend prints active-area quantities only; footer shows which area. Choose All Areas to print everything.

### 15.03.02 Multiple page view (id 816)
- OST-15-007 Multi-page button: drag to choose a grid of preview sheets. Crop selects individual sheets of the grid to print (not a pixel crop).

### 15.03.03 Caching (id 817)
- OST-15-008 Caching builds temporary printable images; can take minutes for many or large pages, so default is not All Pages. Low resources: print one page at a time.

### 15.04 Current view (id 818) and 15.05 Current page (id 819)
- OST-15-009 Current View prints exactly the visible zoomed region, default range. Current Page prints the whole active page; both use Size (Fit to Page or 100%).

### 15.06 Pages with takeoff (id 820)
- OST-15-010 Prints pages having takeoff. Annotation (dimensions, named views) does not count as takeoff; workaround is a dummy Count condition marked on each page to print.

### 15.07 All pages (id 821)
- OST-15-011 Range All Pages caches everything; heavy on memory; try ranges if failing.

### 15.08 To scale (id 822)
- OST-15-012 Size Full Size (100%). Memory heavy (hundreds of MB per page). If the printer cannot hold the full sheet, the plan tiles across many sheets (example: 36 x 48 inch sheet on 8.5 x 11 paper is about 24 sheets).

### 15.09 Print Area tool (id 823)
- OST-15-013 Toolbar button, page size dropdown from current default printer, orientation toggle; a grey frame with the paper's aspect ratio appears on the image, movable and resizable via handles. Print via printer icon on that toolbar. Range and Size disabled; region scaled to fit one page, scale shown in footer.
- OST-15-014 Math: scale = paper size / selected region size at plan scale (inferred); UNKNOWN exact formula and whether margins are subtracted.

## Category summary

### Category 11 (22 articles read)
- Page order, names, folders are presentation data in the cover sheet grid; Page Number derives from row order.
- Image links are relative to Image Folder or explicit; Change Folder is a path prefix find and replace for pages sharing a folder; missing files show red and a re-link assistant exists.
- Base image adjustments (rotate, flip, deskew, enhance, darken, invert, bitonal) are stored per page, never edit the file; overlay adjustments edit a TIFF copy.
- Rotating a page rotates its takeoff; takeoff-only rotation blocked when it would not fit.
- Overlay: one per page, single page file, greyscale, red = base only, blue = overlay only, two-point resize, align handles.
- TIFF conversion is optional and harms automation; PDF native preferred.
- Planroom .osx projects with download status colors; digitizer support with template and per-page takeoff area.

### Category 12 (7 articles read)
- Summary tab sums each condition's results with grouping by Page > Type > Zone > Area; sorting within groups.
- Display decimals are cosmetic; stored values full precision.
- Condition delete is permanent and blocked when grouped by area, page, zone.
- Typical areas, groups and repeating pages show single-instance and cumulative totals with options; repeating page counts shown by banner and multi-area total.
- Report mirrors grid grouping; notes can be omitted.

### Category 13 (4 articles read)
- Estimate tab lists every condition with Material, Labor, Sub unit prices and a total driven by Quantity 1.
- Manual quantity allowed for conditions with no takeoff; hide-zero option.
- Pricing is per condition (not per row) even when grouped by page; not saved in condition styles.
- Group by Page then Type; report is WYSIWYG.

### Category 14 (8 articles read)
- Three pricing methods chosen per project: Estimate tab (default), Excel, QuickBid.
- Excel link is per result per bid, cell or named range, cumulative bid totals only, refreshed with F9.
