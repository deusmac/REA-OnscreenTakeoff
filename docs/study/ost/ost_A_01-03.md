### 01.03.02 Select vs OK dialogs (id 206)
- OST-01-024 Dialog edits are held until Apply or OK. Conditions are not saved until then.
- OST-01-025 Immediate and permanent deletes: Conditions, Typical Groups, Zones, Alternates, Change Orders (child bids do not go to Deleted Bids). Takeoff, Typical Group Frames, drawn Zones and annotation delete immediately but are undoable until you leave the page.
- OST-01-026 Creating a bid consumes the next Bid Number and increments the Next Bid No. option even if cancelled ("burned"); only a manual edit of the option reuses it.
- OST-01-027 Select/Cancel dialogs open from a Lookup button to pick an existing master record; they also allow create/edit/delete/print and CSV import (Employees). OK-only dialogs (opened from Master menu) are management only.
- OST-01-028 Advice: in master dialogs, do not add, delete, then add again without pressing OK between (risk of inconsistency).

### 01.03.03 Sorting, searching, filtering, grouping (id 47)
- OST-01-029 Click column header once for ascending, twice for descending; triangle shows direction and sort key. Typing leading characters in the sort column jumps focus to first match.
- OST-01-030 Lookup boxes (text box with magnifier) do type-ahead: filter list by prefix as you type, auto-insert when one match remains. They support on-the-fly creation: typing a value that does not exist prompts to add it to the Masters.
- OST-01-031 Filter boxes sit above lists. Text filters match substring anywhere (not only prefix). Drop-down filters list values in use (Estimator list shows only employees with login enabled).
- OST-01-032 Filters persist across sessions and can block creating a new Project whose name does not match the filter. Must be cleared manually.
- OST-01-033 Grouping: Projects tab by Job Status, Condition list by Type, Summary tab by Page, Type, Zone or Area (combinations allowed).

### 01.03.04 Imperial or metric units (id 46)
- OST-01-034 Unit codes, Imperial: EA, IN, LF, LY (linear yard), IN2, SF, SY, SQ (roofing square = 100 SF, no metric equivalent, 1 SQ = 9.290304 m2), CF, CY. Metric: EA, mm, m, mm2, m2, mm3, m3.
- OST-01-035 Measurement mode is chosen at database creation (default Imperial) and sets the "New Bid" default Base Measurement (inches or millimeters) in Tools > Options. Each bid can override on its Cover Sheet > Preferences > General > Base Measurement. All dimension input boxes follow the bid's Base Measurement.
- OST-01-036 Mixing Imperial and metric bids in one database is discouraged (master tables, and QB cannot mix UOMs).
- OST-01-037 Metric quantities over 999 can display wrong if Windows regional number formatting is not US style (thousands comma).

### 01.03.05 Entering values in measurement boxes (id 625)
- OST-01-038 Imperial entry rule: the last two digits typed are inches, the digits before them are feet, no apostrophes needed. Examples: 8 = 8 in; 800 = 8'0"; 824 = 8' 24" = 10'0"; 1000 = 10'0"; 1010 = 10'10". To enter 824 inches type 6808 (68'8"). Parse: inches = last two digits, feet = remaining digits; total_in = feet*12 + inches (inches may exceed 11 and carry).
- OST-01-039 Metric entry: always millimeters (1.2 m = 1200; 10 cm = 100).
- OST-01-040 Decimals allowed for fractions of an inch or mm.
- UNKNOWN: whether apostrophe/quote characters or fractions like 1/2 are also accepted.
- UNKNOWN: how a value with decimals is handled in the feet part of an Imperial entry.

### 01.03.06 Decimal places and rounding (id 180)
- OST-01-041 Stored values are full precision; display rounding only. Default display is 0 decimals (standard rounding: 1.13 shows 1, 1.51 shows 2).
- OST-01-042 Per-quantity-column decimal setting: right-click a Quantity column on the Summary tab, Show Decimal Places, choose 0..n or Floating (floating max 6 digits right of the point). Each of Qty 1, 2, 3 is separate.
- OST-01-043 Summary tab setting drives the Conditions list on the Takeoff tab and the area takeoff dimension labels on the plan. Estimate tab has its own separate decimal setting.
- OST-01-044 These are program-level settings (all bids, all databases), not per bid.

### 01.03.07 Program options and preferences (id 985)
- OST-01-045 Pointer to Tools > Options; options cover data folders, tool behavior, new-bid defaults. Details live in other articles.

### 01.03.08 Plan, sheet, drawing, page terms (id 1037)
- OST-01-046 Terminology model: Page = container holding the Plan image (and optional Overlay), takeoff objects and annotations. Sheet No. = drawing number from title block (A101 etc.). Sheet Name = title from title block. Page Index No. = row position in the Pages grid. Plan = the sheet content; Image = underlying file (PDF, TIF) linked.
- OST-01-047 Page Navigator on the Takeoff tab can show Sheet No. and Page Index No. (each toggled in Tools > Options). Sheet No. and Name editable on Cover Sheet or by right-click in Image window.

### 01.04 Quick Start wizards (id 630)
- OST-01-048 Wizards: Database, Bid, Condition, Takeoff. Disable one by ticking its checkbox and closing; disable all (except Bid wizard) via a Tools > Options switch; disabling all also disables the Overlay wizard.
- OST-01-049 Bid Wizard off by default. It copies all plan images (all subfolders, all image types) to a local project folder under the Planroom folder (default C:\OCS Documents\OST\Planroom, set at Tools > Options > Folders), offers page-naming rules with Preview All, then creates the bid. Not suitable for shared SQL DB or network images.
- OST-01-050 Database Wizard shows when no DB open: create for me (new Access DB named from date/time, default folder C:\OCS Documents\OST), create own, or open existing. Two starter/sample databases ship with install.
- OST-01-051 Condition Wizard asks the Condition Style: Linear, Area or Count, then opens Condition Properties. Takeoff Wizard (per Condition type) shows when a Condition is first used.

### 01.04.01 Takeoff BOOST AI tools (id 330)
- OST-01-052 Suite: Auto Scale (sets scale for whole plan set), Auto Takeoff (creates Conditions and takeoff for footprint area, net area, ceilings split gypsum vs ACT, linear walls by type incl. existing walls, painting linear/wall surface both sides of interior walls, windows by type, counts like fixtures/doors/elevators, concrete volumes), Auto Count (count any pattern, user selects what to find, up to 20 pages per run, results arrive async), Auto Link (creates Named Views and Hot Links between pages, shown in a Views tab in the Conditions window), Auto Name (Sheet No./Name from title block).
- OST-01-053 Plans are uploaded to a cloud service. User must verify results. Auto Takeoff trial/limit tied to subscription tier (5 projects on the lower tier, unlimited on the higher).
- OST-01-054 Auto Takeoff output is a head start: user renames Conditions and reassigns takeoff to own Conditions. Output can feed a rough unit-cost estimate (Estimate tab) or export to the bidding app.

## Category 03: Creating and managing projects

### 03.01 What are projects, bids, jobs (id 643)
- OST-03-001 Project = bid = job; includes a Base Bid plus child bids (Alternates, Change Orders). "Job" is used only for the Job No. field.
- OST-03-002 Four creation paths: from scratch, planroom download (.osx file), duplicate existing, import (exported file). Duplicate copies pages, conditions, takeoff and name; only the bid number changes to the next available.

### 03.02 Creating a new project (id 644)
- OST-03-003 Creation triggers: File > New > Bid, New dropdown > Project, right-click > New > Project, Insert key on Projects tab. Cover Sheet opens; only Project Name is required (prefilled with default text). OK creates the project and opens the Takeoff tab.
- OST-03-004 Planroom projects prefill cover info; some fields revert on update; plans download on a Planroom tab in the Conditions window.
- OST-03-005 PDFs recommended to stay PDF (TIF conversion is slow and lower quality); optional per-page conversion for performance.

### 03.03 Cover Sheet part 1 (id 645)
- OST-03-006 Each Bid, Alternate and Change Order has its own Cover Sheet. Base Bid sheet has: general info (top), Plan Organizer tab, Preferences tab. Child sheets are simpler.
- OST-03-007 General fields: Job Status (lookup; new project defaults to the top status in master list), Bid No. (auto from Tools > Options > New Bid Next Bid Number, must be unique in database, editable), Project Name (75 chars, required, restricted to plain alphanumerics; avoid special characters like # % and slashes/brackets), Job No. (free alphanumeric, 50 chars), Estimator (lookup, add on the fly), Notes (shown on Projects tab), Price Using (default Estimate Tab; other options depend on installed products), Worksheet/Database (path, hidden when pricing on Estimate Tab), Typicals (Typical Groups vs Typical Areas, mutually exclusive, choose at start, Typical Areas disabled if any page repeats), Bid Date/Time (default now), Areas (opens Bid Areas dialog), Typical Areas (dialog).
- OST-03-008 Preferences tab (defaults copied from Tools > Options > New Bid at creation): General: Base Measurement (inches or millimeters), Takeoff in Increments (smallest unit of takeoff measurement, in inches or mm). New Page Defaults: Page Size, Scale Style, Scale. Image Legend: Quantities in Legend (which of up to three results show), Show Condition Number, Show Condition Type, Sort Legend by (Number, Name or Condition Type; only when legend is one block).
- UNKNOWN: Effect of "Takeoff in Increments" (snap rounding of measured lengths?) is not explained.
- UNKNOWN: Price Using option list and how each connects.

### 03.04 Cover Sheet part 2, Plan Organizer (id 646)
- OST-03-009 Images are linked by path, not stored in the database. Link text turns red when the file is missing; relink via Change Folder or Image Folder lookup.
- OST-03-010 Plan Organizer grid has 11 columns: Page Index (row position, reorder by drag or Move Up/Down), Sheet No. (default sequential 1,2,3), Sheet Name (from internal title, else file name; multipage PDF pages get file name plus index suffix), Repeats (count of repetitions for typical pages), Page Size, Scale (defaults from file or New Bid options), Image File (path relative to Image Folder when inside it), Index (page number within multipage file), Overlay Image (not multipage), Show (Original, Overlay or Both), Status (Auto Name progress).
- OST-03-011 Toolbar: Add blank page (inserted below selection), Add Images (auto add folder), Add new page and link to image, Add folder (page folders/disciplines), Duplicate Page, Expand/Collapse folders, Delete, Auto Name (and Auto Scale), Change Folder, Image Folder field with lookup, Move Up, Move Down.
- OST-03-012 Deleting a page removes it from base bid and all child bids with all takeoff on it, permanently, after confirmation.
- OST-03-013 Non-Group-4 TIFFs prompt for Group 4 conversion at first add only; other conversions later from the Takeoff tab.
- OST-03-014 Image Folder = common directory of the first images added; files outside it store full paths.

### 03.05 Adding a single page (id 647)
- OST-03-015 Blank page: no image; page size editable only until an image is linked, then fixed. Link by Lookup button in Image File column. One-step add: third toolbar button opens Add Image browse. Size and scale come from file if available else New Bid defaults. Scale must still be verified on the Takeoff tab.

### 03.06 Adding multiple pages (id 648)
- OST-03-016 Auto Add: pick one file; all files with the same extension in that folder are added (not subfolders; repeat per subfolder or per file type). Multipage PDFs are split into one Page per PDF page with index numbers, each independent.

### 03.07 Duplicating a page (id 649)
- OST-03-017 One page at a time; copy named "Copy of <Sheet Name>" placed below original, linked to same file, no takeoff or annotation copied. If the original is a Typical page the copy keeps the same number of virtual pages (repeats).

### 03.08 Auto Name (id 650)
- OST-03-018 New version (4.0.0.1006+): one click, uploads plans if not uploaded within the last 30 days, AI finds title block, fills Sheet No. and Sheet Name; progress shown bottom right; can keep working in any project.
- OST-03-019 Original version (before 4.0.0.982): select pages or page folders (assumed same title block layout; must be same page size), define two rectangles ("Sheet No." and "Sheet Name") on a sample page, status Ready, then run: statuses Ready, Processing, Completed; can interrupt, completed pages stay updated; per-page reset needed to change location for a subset.
- OST-03-020 Cloud only, needs internet; also returns page rotation and discipline (folder) in some versions.

### 03.09 Copy and paste bids across databases (id 656)
- OST-03-021 Both databases must be open; drag and drop or Ctrl+C/Ctrl+V; multi-select with Ctrl/Shift; confirmation Yes / Yes to All; progress window. Cannot copy a child bid without its parent. Move (cut) discouraged. Never move a QB-connected interactive bid (can destroy the estimate); copy then reconnect in QB.

### 03.09.01 Template jobs (id 257)
- OST-03-022 Template projects carry conditions, layers, bid areas, typical areas/groups, image legend settings and Estimate tab pricing (Styles cannot store pricing). Duplicate to start a job. Interactive copies prompt to duplicate the QB estimate too.
- OST-03-023 Suggested: locked Job Status "Template", name pattern "TEMPLATE - <job type>". Synchronize Databases does not copy projects. Sharing needs SQL database, not Access on a network drive.

### 03.10 Duplicating bids (id 657)
- OST-03-024 Select one or many projects; Duplicate via context menu, toolbar or Ctrl+D; confirm Yes. Copy keeps same name; only number changes. Points to the same plan files. For QB-connected bids, prompt to duplicate the QB side with pricing; "No" then Price Using Quick Bid yields blank pricing. Used for what-if scenarios.

### 03.11 Deleting and restoring (id 658)
- OST-03-025 Deleting a project moves base bid and all children to Deleted Bids folder. Deleting a child bid is permanent. Restoring a base bid restores surviving children. If the original folder was deleted, restore fails but drag out works. Empty Deleted Bids Folder is permanent (then run Compact and Repair). Confirmation dialog buttons: Yes, Yes to All, No, Cancel; can be suppressed.

### 03.12 Alternates and Change Orders (id 659)
- OST-03-026 Child bids share image files, Bid Areas and Typical Areas with base; plan organization is done only on the base Cover Sheet. Alternates: pre-contract options priced separately. Change Orders: post-contract scope changes, tracked separately.
- OST-03-027 Keep the No. field at 25 characters or less.
- OST-03-028 Accepted checkbox: accepted alternate adds or deducts its condition results against the base in the estimating program; OST itself keeps base and child results separate. Accepted change orders are always tracked separately from base.
- OST-03-029 Typical Group frames and markers are copied into new child bids (no takeoff inside); only variances are drawn.

### 03.12.01 Creating and accepting child bids (id 660)
- OST-03-030 Create via File > New or New button on Projects tab, or Project View tab in Conditions window (select Alternates or Change Orders header, click Add, or double-click the header).
