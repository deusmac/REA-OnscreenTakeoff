# OST notes, categories 06 and 07 (scale, drawing tools, auto takeoff, bid areas, zones)

## CATEGORY 06

### 06.00 Chapter overview (id 1032)
- OST-06-001 Chapter flow: set scale, verify scale, then draw linear/area/count/attachment takeoff, multi-condition takeoff, negative takeoff, manual quantity entry. Precondition: bid created, plan set loaded, conditions created.
- OST-06-002 Scale meaning: ratio of drawn distance to real distance, e.g. 3/8" on page = 1' real.

### 06.01 Why scale matters (id 705)
- OST-06-003 Every page needs scale set AND verified before any takeoff or annotation. Scale printed on the sheet is not trusted (scan distortion, resized pages, wrong original).
- OST-06-004 One scale per page. Multiple scales on one sheet: duplicate the page, one copy per scale (separate article "Handling More Than One Scale").
- OST-06-005 Drawings with different horizontal vs vertical scale are unsupported.
- OST-06-006 Changing scale after drawing takeoff is discouraged: some objects may not resize, may leave the page, or be blocked by connected objects.
- UNKNOWN: exact resize algorithm for existing shapes on rescale (anchor point, per-shape behavior).

### 06.01.00 Auto Scale (id 2756)
- OST-06-007 Auto Scale (AI cloud service, v4.0.0.982+) detects and sets scale for the whole plan set. Launched from project Cover Sheet or Takeoff BOOST toolbar button.
- OST-06-008 Flow: informational welcome dialog ("Get Started", "Don't show this again"), progress indicator bottom-right, completion popup. User must still verify scale per page.
- OST-06-009 Requires uploading plans to a service (legal-right warning).
- UNKNOWN: confidence/failure reporting per page, pages it skips.

### 06.01.01 Setting scale manually (id 706)
- OST-06-010 New blank pages take size and scale from "New Page Defaults" on the Cover Sheet Preferences tab, which derive from Tools > Options new-project settings.
- OST-06-011 Ways to set scale: Cover Sheet Pages tab dropdown; Scale dropdown on Settings toolbar (Takeoff tab); Scale dropdown in Annotation and View window; Edit > Set Scale dialog.
- OST-06-012 Set Scale dialog: Scale Style (Architectural, Civil, Metric); predefined list or Custom; "Apply to all Pages" checkbox; OK.
- OST-06-013 Custom scale entry format, imperial: feet and inches packed digits, last two digits are inches ("2500" = 25'0", "10006" = 100'6"). Metric: millimeters ("1000" = 1 m, "25000" = 25 m).
- OST-06-014 Scale change is blocked if the same page has takeoff in a child bid (alternate/change order) or, when inside a child bid, in the base bid.

### 06.01.02 Calculate scale from known linear (id 707)
- OST-06-015 Edit > Calculate Scale opens a dialog while a known-length dimension is visible. Steps: choose Scale Style, type the known length (same packed format as OST-06-013), then press at start point, drag to end point with button held.
- OST-06-016 A red line labeled with the entered length traces the drag. Label of the line is rounded up to whole inch, but the math uses the exact typed value.
- OST-06-017 Scale shown in the dialog updates automatically and may differ slightly from any standard scale. Formula (implied): scale = typed_real_length / drawn_pixel_length converted to page units.
- OST-06-018 "Apply to all Pages" option, OK to accept. Same child-bid lock as OST-06-014. Longest known linear gives best accuracy.
- UNKNOWN: whether the calculated scale snaps to the nearest standard scale or stays custom.

### 06.01.03 Verifying scale (id 708)
- OST-06-019 Verification: use the Dimension tool (Annotation toolbar) on a known dimension, zoomed in; reading must equal the plan label. Check horizontally AND vertically.
- OST-06-020 If mismatch, run Calculate Scale again with a longer reference.

### 06.02 Drawing takeoff overview (id 709)
- OST-06-021 All takeoff is drawn on the Takeoff tab in the Image Window with mouse or stylus; colored means counted.
- OST-06-022 Known quantities can be typed on the Estimate tab instead (see 06.09). Zones and Typical takeoff are separate topics.

### 06.02.01 Auto Takeoff overview and requirements (id 246)
- OST-06-023 Brand: Takeoff BOOST is the umbrella for AI tools; old "Takeoff Boost" = Auto Takeoff; toolbar has Auto Takeoff, Auto Count, Auto Link, Auto Scale buttons.
- OST-06-024 Entitlement: login-licensed Essential/Plus subscriptions get 5 projects; Core/Professional unlimited. Key-licensed: Advanced Maintenance 5 projects, Premium unlimited, Standard can request trial. Older versions need a separate code starting with "BOOST+". (licensing, brief)
- OST-06-025 Outputs it can generate: Footprint area (outside edge of exterior walls); Net area (area inside walls, cumulative, excludes wall thickness); Walls (straight line linears, optional per wall type via tag, existing walls); Ceilings (areas, GWB and ACT by pattern, optional types by tag, rest in generic "Ceiling"); Painting (both sides of interior walls = wall surface area); Counts (windows by type tag or untagged; doors, plumbing fixtures, elevators etc.); Volume (spread footings, slabs and linear footings).
- OST-06-026 Preconditions: project not in a Locked job status; not opened by another user on shared SQL db; user has permission to add takeoff; scale set and verified on every page to be run (can run on pages not currently viewed); only floor plans and enlarged floor plans supported (no details, sections, elevations); internet and firewall access.
- OST-06-027 Not complete: user still must review, rename and complete conditions (height, width), add conditions, reassign, assign to bid areas, fill manual takeoff.
- OST-06-028 Use case: rough scope and unit-cost estimate, export to bidding app.

### 06.02.02 Running Auto Takeoff (id 293)
- OST-06-029 Native PDFs preferred over TIFF (faster, better). Convert to TIFF after if viewing is slow.
- OST-06-030 Run sequence: set/verify scale, choose results, choose pages, press run. About 20 to 60 seconds per page.
- OST-06-031 Dialog sections. Areas: footprint, net area (no options), ceilings (optional ceiling-type tag shape). Linears: walls (optional wall-type tag shape; double-sided walls best from reflected ceiling plan), existing walls (color White/Black/Gray). Counts: windows (window-type tag shape), others on/off. Volume: spread footings, slabs, linear footings (option to split a linear footing at each spread footing).
- OST-06-032 Ceilings must be run on a ceiling or reflected ceiling plan. RCP also best for two-sided wall takeoff and carries heights, which get set per unique condition when found.
- OST-06-033 Selected result checkboxes are remembered for the next session.
- OST-06-034 Without a type tag: walls and windows consolidate to one condition each; ceilings always split GWB vs ACT.
- OST-06-035 Run on current page, or Run on multiple pages (v4.0.0.859+): any number of pages selected, processed one at a time, results appear per page. Status per page (progress then green check), per-page stop button, "Stop all Auto Takeoff" button; finished pages are unaffected by stopping.
- OST-06-036 Closing OST or database while running warns, cancels the running page; partial writes already saved remain.
- OST-06-037 Rationale for verifying scale first: changing scale later is unreliable and the service uses scale to recognize objects.

### 06.02.03 Auto Takeoff results (id 304)
- OST-06-038 All conditions created go into a folder named "Auto Takeoff".
- OST-06-039 Renaming a generated condition or moving it out of the folder means it will not be reused; the next run creates a fresh one in the folder.
- OST-06-040 Condition Type assignment: walls (when tagged) type "Walls", one condition per wall type, untagged go to generic wall condition; windows type "Windows" per window type; ceilings type "Ceilings" per ceiling type, otherwise GWB, ACT, Ceilings conditions; painting = both sides of all walls in one condition; footprint, net area and non-window counts have no type (show as "Unassigned"); volume items have their own types.
- OST-06-041 Each generated condition is assigned to an auto layer (Wall, Net Area, Footprint Area, Count, Window, Ceiling), layers added to the bid automatically; layer can be changed in condition properties.
- OST-06-042 Linear results can take a "Default Height" to also yield wall surface area; on RCP height may be detected.
- OST-06-043 Door variants returned: Door, Double Door, Opposing Door, Uneven Door. Plumbing: Bathtub, Double Sink, Floor Sink, Shower, Sink, Toilet, Urinal. Other: Elevator.
- OST-06-044 If a result's layer is hidden, takeoff is still created but not visible until layer shown.

### 06.02.04 Reviewing and deleting results (id 305)
- OST-06-045 Recommended: run on all pages first, then edit once. Reuse rule: same generated conditions reused across pages while they stay named and in the folder (see OST-06-039).
- OST-06-046 Review aid: hide Default and custom layers, keep Image and the auto layers visible.
- OST-06-047 Delete takeoff only (page scoped): right-click condition > Select Objects selects all objects of that condition on current page (yellow border); then toolbar delete, DEL key, or context menu Delete. No confirmation; undo with Ctrl+Z until leaving the page/bid. Trash sound plays.
- OST-06-048 Delete the condition (bid wide): button in Conditions window, DEL on a selected condition, or context menu Delete. Deletes all its takeoff on every page of the bid (base, alternate or change order bid only, not other bids in the project). Confirmation prompt, no undo. Multi-select with Shift (adjacent) / Ctrl (non adjacent).
- OST-06-049 After deleting generated conditions, a run re-creates what it needs.

### 06.02.05 Editing and moving Auto Takeoff conditions (id 307)
- OST-06-050 Double-click a condition to open Condition Properties. Fields worth completing: Name, Type, Layer, Dimensions (height, thickness; example 14 ft and 8 in), Results, Appearance (color, transparency, pattern, shape). Generated conditions have only basics filled (concrete ones get notes).
- OST-06-051 Types are set on walls, ceilings, auto counts, concrete conditions only.
- OST-06-052 Move conditions to custom folders by drag and drop; dropping on the "Conditions..." header removes folder membership.
- OST-06-053 Once all generated conditions are renamed/moved, a re-run will create new generated ones and leave edited ones untouched.

### 06.02.06 Reassigning takeoff to other conditions (id 1030)
- OST-06-054 Single or multi object: Select tool, click to select (click again deselects), Shift+click adds, right-click > Reassign Condition. Pick list shows only conditions of the same style (linear/area/count), including generated ones.
- OST-06-055 Batch by condition: select one or more conditions in the Conditions window (Ctrl or Shift), right-click > Select Objects (selects all their objects on current page only), then in the image right-click > Reassign Condition. All selected conditions must share one style.
- OST-06-056 Totals update immediately, reassigned takeoff takes the new condition color. Reassign is page scoped.

### 06.02.07 Fine tuning results (id 1033)
- OST-06-057 Edit shapes: click edge to show selection boxes per segment; drag a box moves adjacent segments; corner box drag adjusts both neighbors. Quantity updates live.
- OST-06-058 Known gaps: floors not generated (net area can be reassigned to floor conditions); doors come as counts not attachments (swap for attachments if they must reduce wall surface area); ACT needs grid set and aligned; may need extra conditions for untagged types; split objects, simplify area (remove vertices), backouts available.

### 06.02.08 Filling gaps (id 1031)
- OST-06-059 Manual completion uses ordinary conditions. Not generated: lights/vents/fixtures, floors. Attachments explained: sit on a parent, reduce parent results (example: 2'x4' light box removes 8 SF from ceiling, or two 2'x2' tiles).

### 06.02.09 Rerunning (id 306)
- OST-06-060 Rerun on same unchanged page gives identical results. Different scale or much higher-resolution image would change them.
- OST-06-061 Rerun rule: allowed only for result types not already delivered on that page while the generated condition still exists in the folder with original name (warning shown otherwise). To rerun same result type: rename the condition, move it out of folder, or delete its takeoff on that page.
- OST-06-062 A user condition that uses a reserved generated name and sits in the Auto Takeoff folder with takeoff on the page is treated as the generator's own and blocks the run.
- OST-06-063 Rerun after reassigning duplicates takeoff. Recovery trick: duplicate the page, clear takeoff on the copy, run, copy/paste back, delete the copy.
- OST-06-064 Rerun on one page re-creates deleted generated conditions but only that page gets new takeoff.

### 06.03 Multi-Condition Takeoff (id 710)
- OST-06-065 Select any number of conditions of mixed styles and draw once; all objects created together.
- OST-06-066 Mode decision: any area condition present means area drawing; linear with counts (no area) means linear drawing; counts only means count drawing (Auto Count unavailable here).
- OST-06-067 Attachments cannot be part of it (placed separately). Count objects are placed at area vertices or at linear segment breaks.
- OST-06-068 Area plus linears: area snaps to center of the linear objects. One linear plus area conditions: area uses its own "Snap To" settings if set, else snaps to linear center.
- OST-06-069 Resulting objects are independent afterwards. Same-style objects stack; use layers to separate them.
- OST-06-070 Rectangle click-drag works with multi-condition (two clicks for whole room). Example claims 19 clicks vs 4.

### 06.04 Linear takeoff (id 711)
- OST-06-071 Linear results: length, plus area (length * condition height), plus volume (height * thickness * length) depending on condition setup.
- OST-06-072 Snap Angle default 15 degrees, plus right-angle indicator relative to previous segment. Hold Shift to disable snapping while drawing. Both configurable in Tools > Options.
- OST-06-073 Normal mode: select linear condition, press at start, drag, release at end (single segment).
- OST-06-074 Continuous mode: click start, click each next point, double-click last point to finish. Single segment variant: click, click, double-click.
- OST-06-075 Engage continuous: Continuous Mode button on Takeoff Mode toolbar, or option "Automatic Continuous Mode" (off by default) which makes press-and-hold start continuous. Esc exits automatic continuous; double-click finishes.
- OST-06-076 Contour (freehand): click start, hold button and trace, double-click to finish. Path converted to short straight segments per Intelligent Curve Segments slider (Tools > Options > General); each is a separate segment and counted if "Segment Count" result is on.
- UNKNOWN: slider range/units and the geometric algorithm.

### 06.04.01 Arcs (id 712)
- OST-06-077 Right-click a segment > Set as Curved Segment (that segment only). Condition Advanced tab has "Set as Curved Segment (Default)".
- OST-06-078 Bend: select segment, hover the center box (cursor becomes double-ended arrow), drag. Remains one segment (unlike contour).
- OST-06-079 Circle: draw a line through circle, make curved, bend to semicircle, drag endpoint toward other end for near circle (small gap remains).
- OST-06-080 A curve-enabled segment cannot hold attachments even if unbent.
- UNKNOWN: arc length formula (circular arc through three points assumed).

### 06.04.02 3-point curve (id 714)
- OST-06-081 Right-click > Set as 3-Point Curved Segment gives a center handle in addition to end handles, for non-circular curves. Four-way cursor moves, double arrow cursor curves. Same attachment restriction.

### 06.04.03 Drop/Run (id 715)
- OST-06-082 Condition Advanced tab > Measurement > Drop/Run checkbox with "Add Length" value. Each drawn segment gets a drop/run box prefilled with the default; editable per segment by clicking the box.
- OST-06-083 Changing default affects future objects only. Unchecking Drop/Run removes applied values; rechecking restores them. Blank Add Length gives empty boxes for manual per-segment entry.
- OST-06-084 Meaning: extra vertical length added per segment (example 1'6"). Implied: segment_length = drawn_length + drop_run.
- UNKNOWN: how drop/run affects area and volume results, and whether it applies to segment count.

### 06.04.04 Manual length (id 716)
- OST-06-085 Per segment: Select, right-click > Set Length..., type value; shape resizes by page scale.
- OST-06-086 Condition option "Manual Length Entry (not to scale)" on Advanced tab: every drawn segment prompts for length; drawn size independent of length.

### 06.05 Area takeoff (id 717)
- OST-06-087 Area results: square footage, volume (via thickness), perimeter. Same snap angle and Shift override. Right-angle snap can make sides slightly unequal, inflating visible grid/tile counts or rounded-segment results.
- OST-06-088 Auto Magnify (off by default): enabled by setting Default Auto Zoom Level nonzero in Tools > Options; popup magnifier near cursor when page zoom is below that level.
- OST-06-089 Rectangle: press at anchor, drag diagonally, release.
- OST-06-090 Polygon: click each corner, double-click the last corner; program closes automatically. Do not double-click the start point.
- OST-06-091 Auto-Fill: the linear condition must have "Connect to" (Advanced); with area condition selected, double-click inside the closed linear loop to fill it.
- OST-06-092 Curved areas: many short segments with Shift or snap disabled.
- OST-06-093 Add vertex: Select, click area, hover edge until cursor indicates, click. Remove vertex by dragging it onto an adjacent vertex.
- OST-06-094 Invalid point: gong/thunk sound when a point would cause crossing lines. Esc steps back one point. Recommended to let double-click close.

### 06.05.01 Gridded area (id 718)
- OST-06-095 Grid conditions (e.g. 2x2 tiles) offer quantities: Area (less attachments), Tile Count (average) = area_sf / tile_sf (no rotation dependence), Tile Count (visible) = every full or partial visible tile counted (depends on grid alignment).
- OST-06-096 Align Grid: select object, Alignment button on Takeoff Mode toolbar or right-click > Align Grid. Two handles: position handle (left, arrows) drags grid; rotate handle (right, solid dot) rotates around center. Rotate first, then position.
- OST-06-097 Alignment changes visible tile count and visible grid (metal grid) quantities, not average. Example difference nearly 10 percent.

### 06.05.02 Backouts (id 719)
- OST-06-098 Backout: select a single area object, Backout icon on Takeoff Mode toolbar or Tools > Backout Mode, outline region inside the object. Reduces the condition result.
- OST-06-099 Backout is a selectable object: move, resize, delete, copy/paste; must stay inside the parent boundary and parent must retain area.
- OST-06-100 Fill the backout: pick a different area condition, double-click the clear region. Change fill by deleting the fill object and repeating.

### 06.06 Count takeoff (id 721)
- OST-06-101 Count: select count condition, click each location. Results may include volume, SF etc. per condition properties. Known quantities go on the Estimate tab (article text says Worksheet tab in places; later article says Estimate tab).

### 06.06.01 Auto Count (id 722)
- OST-06-102 Two tools: AI Auto Count (v4.0.0.770+, subscription login, up to 20 pages at once), legacy OCR pixel matching (older versions only; button now launches AI version).
- OST-06-103 AI flow: Takeoff BOOST toolbar button (View > Toolbars to show), welcome with "Get Started", cursor becomes object select, draw a box around the sample symbol. Dialog: apply to existing or new condition; match symbol only, or symbol plus text; Next; pick up to 20 pages; Run Auto Count. Results added per page; completion confirmation.
- OST-06-104 Legacy flow: select count condition, drag a box (automatic selection) or use Auto Count button and rope the object (manual selection, blue dashed outline). Dialog has Eraser (remove stray marks from sample), Change Selection, Search, Sensitivity slider.
- OST-06-105 Legacy results list: total matches, all selected by default, Select All, Unselect All, Preview (View window, Ctrl+2), Accept Count. Dialog fits 21 results, resizable. Accept places a count object on every match. Undo (Ctrl+Z) right after accepting removes them. Only current page scanned. Higher sensitivity = stricter match; advice: low sensitivity then deselect mismatches. After accept, they are normal count objects.

### 06.07 Attachments (id 723)
- OST-06-106 Attachment is a count-like object bound to a parent linear or area object; cannot exist alone; usually modifies parent results. Draw: select attachment condition, click the parent.
- OST-06-107 Linear parent rules: attachment width must fit horizontally along the segment (4' attachment cannot go on a 3' segment); attachment height may exceed the linear's height; not on curved-enabled segments (clear the curved flag if unbent first).
- OST-06-108 Area parent rules: attachment must fit fully inside parent. Gridded parent: attachment may not match aligned grid; use Rotate Takeoff to align; may need Snap to Grid unchecked (Attachment condition Advanced tab) and hold Shift while moving. Attachment orientation (W x H) must be set the same as the parent grid's orientation (2x4 grid needs 2x4 attachment, not 4x2).
- UNKNOWN: effect on parent for wall results (subtraction of width*height) is implied but formula not stated here.

### 06.08 Negative takeoff (id 725)
- OST-06-109 Two ways: object in a Negative Zone; or context menu "Count as Negative Quantity" on selected objects. Negative objects show a minus sign.
- OST-06-110 Math: condition_total = sum(positive) - sum(negative); not "ignored". 10 objects with 1 negative = 9 - 1 = 8. Use delete to just drop one.
- OST-06-111 Typical use: alternates and change orders by copying base bid takeoff and negating.

### 06.09 Manual quantities (id 726)
- OST-06-112 Only on Estimate tab and only for conditions with zero drawn takeoff. Quantity 1 column only is editable; Qty 2 and 3 unavailable. Displayed in blue.
- OST-06-113 Conditions window shows the value on all pages; Qty 2/3 shown in Conditions list when derivable (e.g. height and width allow SF/CF from LF; area condition cannot derive LF from SF so blank).
- OST-06-114 Drawing any takeoff with the condition permanently overwrites the manual value (no undo). Manual entry again only after all takeoff for that condition is deleted everywhere.

## Category summary 06
- Scale is per page, set then verify with Dimension tool; custom format uses packed feet-inches digits or millimeters; calculate by dragging over a known dimension; locked when child bid has takeoff on page.
- Auto Scale, Auto Takeoff, Auto Count are cloud AI tools needing page upload, internet, licensing.
- Auto Takeoff creates conditions in an "Auto Takeoff" folder with auto layers and types; rename or move to detach; rerun limited to new result kinds.
- Reassign Condition works on same-style conditions, page-scoped, by object or by whole condition.
- Linear tools: normal, continuous, freehand contour with Intelligent Curve, arcs, 3-point curve, drop/run, manual length; snap 15 degrees with Shift override.
- Area tools: rectangle drag, polygon with auto-close, auto-fill from connected linears, vertex add/remove, grid align (average vs visible tile counts), backouts with auto-fill.
- Attachments need parent and fit rules; negative takeoff subtracts count-wise; multi-condition draws everything at once by style priority (area > linear > count).
- Articles read: 30

## CATEGORY 07

### 07.01 Bid Areas (id 727)
- OST-07-001 Bid Areas = named locations within one project (building, floor, wing, phase, page like S101). Takeoff is assigned to areas; conditions are not.
- OST-07-002 Up to three tiers (e.g. Building > Floor > Room).
- OST-07-003 One object belongs to exactly one Bid Area or Typical Area, no splitting (splitting is done via zones). Typical Areas can be spread across several bid areas through the Typical Areas grid. A Typical Group Marker holds one bid area; only the marker's assignment matters, not the frame or its contents. Virtual page assignments are relative to the typical page.
- OST-07-004 Bid Areas usually pass to the bidding program so the estimate is broken out by area; they are required for Typical Areas.

### 07.02 Quick Add and creation (id 728)
- OST-07-005 Open Bid Areas dialog via Cover Sheet Areas button, Bid > Show Areas, or lookup button beside Areas dropdown on Image tab.
- OST-07-006 New adds a blank line; name max 50 chars, short preferred; avoid special characters (letters and numbers only).
- OST-07-007 Quick Add: pick Building, Floor or Room or type a custom label; From and To numeric range; creates "Floor 1".."Floor 3".
- OST-07-008 Data warning: changes are stored when dialog closes; after deleting, close the dialog before adding more.

### 07.03 Sub areas (id 729)
- OST-07-009 If an area is selected when adding or quick-adding, new areas indent beneath it (checkbox "Indent under ..."). Rename allowed afterwards.
- OST-07-010 Move up/down; indent/outdent by drag and drop or buttons. Delete blocked if takeoff or typical areas are assigned to it.

### 07.04 Assigning takeoff (id 730)
- OST-07-011 Preferred: draw first, assign later. Select area in the Area dropdown, Select tool, select objects, right-click > Assign to Current Area.
- OST-07-012 Alternative: while drawing, new objects auto-assign to the active area chosen in the dropdown. "(All Areas)" leaves objects unassigned.
- OST-07-013 Display: takeoff not in the current area is greyed out (may affect printing per options); the area name is bold in the dropdown if it has takeoff on the current page.
- OST-07-014 Check for unassigned rows on the Summary/Takeoff tab. Typical area assignment is analogous.

### 07.05 Zones (id 731)
- OST-07-015 Zone = special condition type used to group/split takeoff for reports and pricing; shows as grouping on Summary/Takeoff tab.
- OST-07-016 Rules: no overlap, no zone inside zone, defined exactly as drawn, can bisect linear/area objects (a given part belongs to one zone only).
- OST-07-017 Count and attachment objects belong to a zone when their selection box is at least 50 percent inside the zone (text says "50% or more" and ">50%").
- OST-07-018 Negative Zone: Zone Properties "Negative Quantities" checkbox (labeled "Count quantities as negative values" in create dialog) makes everything inside subtract from totals. See OST-06-110.
- OST-07-019 Zones export to many estimating programs as areas; in an interactive bid with the bidding app, a zone becomes a top-level Bid Area there.

### 07.05.01 Bid Area vs Zone (id 67)
- OST-07-020 Bid area: whole-object, one per object, grouping on Takeoff tab. Zone: geometric, can split an object, grouping on Summary tab by zone; parts outside any zone are "Unassigned".
- OST-07-021 Can group by both zone and area, can confuse especially with typical takeoff.

### 07.06 Create a zone (id 732)
- OST-07-022 Zones tab in Conditions window; Add button or Insert key opens Zone Properties: Name, Layer (optional, zone shape only; contained takeoff keeps its own layers), Appearance, Notes, negative checkbox. Zone drawn like area takeoff.

### 07.07 Draw and use zones (id 733)
- OST-07-023 Draw: polygon like area (click corners, double-click to close); gong and Esc rules as OST-06-094. Zones may touch but not intersect.
- OST-07-024 Splitting: a 20' wall across two zones keeps full quantity in the Conditions list, but Summary tab (group by Zone) splits it proportionally to the lengths inside each zone; a zero "unassigned" row may appear from pixel slivers.
- OST-07-025 Known issue: sloped area plus backout plus zone gives two rows when grouped by zone on the Summary tab (display only; Estimate tab and export correct).
- UNKNOWN: exact split math for areas and for linears crossing zone borders (geometric clipping assumed), and for volume or surface results derived from them.

### 07.08 Copy and paste zones (id 734)
- OST-07-026 Select zone shapes with Shift+click on the zone object, right-click > Copy (Cut unsupported). On the target page right-click in image > Paste; a green dotted outline follows the cursor; click to drop. Can paste repeatedly.

## Category summary 07
- Bid areas: named hierarchy of up to 3 levels, 50 char names, assigned per object (all or nothing), blocked deletion if used.
- Assignment by "Assign to Current Area" after drawing or auto while drawing with active area; unassigned shown on Summary tab.
- Zones are drawn polygons that split linear/area quantities geometrically; no overlap or nesting.
- Counts and attachments belong to a zone when at least half their selection box is inside.
- Negative zone flips all contained takeoff to subtract.
- Zones map to top-level Bid Areas in the bidding app; bid areas pass as areas.
- Zones copy and paste (no cut) with positional preview.
- Articles read: 9
