# QuickBid notes B: categories 05 (Items), 06 (Bids), 07 (Conditions)

## CATEGORY 05: Items

### 05.01 Items overview (id 433)
- QB-05-001 An Item represents material, labor, or both. Material and labor can be one Item or two separate Items depending on how the company prices. Example: plywood Item, install-labor Item, screws Item chained to plywood.
- QB-05-002 Master Items list opened from Master menu or from Condition Detail. Items created/edited in the Item Detail dialog (Master or Bid-level variant).
- QB-05-003 Master edits never change Items already used in a Bid. To change a used Item, use a Modify Item option in Condition Detail or Materials tab. Bid-level edits never affect other Bids; user may be prompted to push change to Master if they have rights.
- QB-05-004 Item used in a Condition Assembly, Chain or Mixture cannot be deleted.
- QB-05-005 There is no "Bid Item List"; it is split between the Materials tab and Labor tab of the bid.

### 05.02 Show Where Used (id 434)
- QB-05-006 Right-click Master Item, choose Show Where Used. Three lists: Condition Assemblies, Mixtures, Chains. An Item may appear in several.
- QB-05-007 Double-click an entry opens that Assembly/Item; Next/Previous buttons cycle through the hits.
- QB-05-008 Must update references everywhere before deletion is allowed.
- QB-05-009 If the Items list is filtered (dropdowns or search), only filtered Items are searched for Mixture and Chain usage. Remove filters to search all.
- QB-05-010 Condition Assembly = saved group of Items in Masters dropped into a Condition; Items follow assembly settings. Mixture = Item built from other Items producing a Yield. Chain = lead Item pulling related Items.

### 05.03 Master vs Bid-level Items (id 435)
- QB-05-011 Three levels: Database (Master) Item, Bid-level Item, Condition-level line.
- QB-05-012 Master = template. First use in a Bid creates a Bid-level copy, isolated from later Master changes. Rights set by DB admin control whether Bid-level edits can be saved up to Master.
- QB-05-013 Bid-level edits affect every use of that Item inside the Bid (description, material cost code, material pricing, labor crew, any calculation).
- QB-05-014 To re-pull fresh from Master: delete the Item from every Condition in the Bid and every Alternate; next insert creates a new copy.
- QB-05-015 Condition-level data stored per use: Section, Labor Cost Code, labor production rates, labor cost, Item style/size, Height, OC, Layers. Changing in the grid does not affect other uses even in same Condition.
- QB-05-016 One Material price/cost per Item across the whole Bid (and Alternates); changing it anywhere changes all uses. Change Orders keep their own material pricing. Labor production is per use.
- QB-05-017 Title bar tells level: "Item Detail (Master)" versus "Item Detail for <bid name>".
- QB-05-018 UNKNOWN: whether Alternates share the same Bid-level Item copy or hold a copy each (text says material price applies across Alternates).

### 05.04 Creating Master Items (id 436)
- QB-05-019 Three ways: from scratch, duplicate, or copy from another database (synchronize, import a Bid Package, copy a bid between databases).
- QB-05-020 Items can be created on the fly while pricing. Without master edit rights user cannot create items from scratch at bid level.
- QB-05-021 New: Master > Items > New or Insert key. Required: General tab Code (unique), Description, UOM, Mat. Cost Code (if material). Calculation tab: Section, Lab. Cost Code (if labor).
- QB-05-022 Duplicate: select (not open) item, Duplicate button, right-click Duplicate Item, or Ctrl+D. Code gets "_1" appended (PR becomes PR_1). New item's detail opens for editing.
- QB-05-023 If the list was opened from a Condition, highlight and Select inserts into the condition.
- QB-05-024 UNKNOWN: numbering when PR_1 already exists (PR_2 presumably).

### 05.05 Item Detail dialog overview (id 437)
- QB-05-025 Five tabs: General, Calculation, Sizing, Material Cost (Pricing), Labor Cost (Pricing).
- QB-05-026 Top fields: Code (unique, letters auto-uppercased, alphanumeric), Description (used on all bid reports), UOM.
- QB-05-027 UOM is one base unit per Item; it is a tag that accompanies every quantity, controls available options on Calculation, Sizing, Pricing tabs. Labor priced in a different unit needs a separate labor-only Item.
- QB-05-028 Buttons: Previous/Next (when opened from Condition/Assembly/Materials tab scrolling limited to that condition or filtered view; selected tab stays), OK saves, Cancel discards (with prompt).

### 05.06 Item Detail General tab (id 438)
- QB-05-029 Fields: Item Setup (Material, Labor, Both), Mat. Cost Code (required for material; rolls up costs across sizes), Type (optional, for filtering), Manufacturer (optional, material only, filterable), Supplier (New button, from Contacts of type Supplier; Show SPID box shows Supplier ID, default equals Item Code), Chained Items.
- QB-05-030 Supplier and Supplier ID appear only in Material Reports when Group by Supplier is checked.
- QB-05-031 Chained Items grid: Item (lookup from Master list) and Size/Style cell; Size/Style enabled only for items with sizes/styles; default is auto-size, chosen from detail height.

### 05.06.01 Chained Items (id 439)
- QB-05-032 A lead Item shows a link symbol in far-left column of Items list. Any Master Item may be chained.
- QB-05-033 Adding the lead to a Condition inserts chained Items immediately below it. Only first time lead is dropped in that Condition; a second drop of lead does not pull chain. If the whole chain is deleted and lead re-added, chain follows again.
- QB-05-034 Auto size: chain item size matched to Condition when inserted.
- QB-05-035 Chain differs from Condition Assembly: assembly can also set Height, OC, Layers, ratios between items and quantities, production.

### 05.07 Calculation tab overview (id 440)
- QB-05-036 Calculation tab converts Condition Quantity into Item Quantity. Example: wall measured 10 LF, height 8 ft, needs area 80 SF; takeoff ignores both sides and waste.
- QB-05-037 Inputs available: Condition Quantity 1, 2 or 3, Height, Layers, on center (OC), vertical repeats, install method, waste.
- QB-05-038 Five sections: Calculation Method (qty source, formula, waste), Condition Detail Default Entries, Formula Descriptions (info only), Installation Method (affects Standard Formula), On Center Exception Factors (override all calcs when OC is 16 in / 24 in or 400 mm / 600 mm).

### 05.07.01 Calculation Method (id 441)
- QB-05-039 Use Condition (Quantity): picks Qty 1, 2 or 3 from the Condition; default Qty 1. Selected quantity must be nonzero or reports misbehave (Report Data Checker).
- QB-05-040 Methods to Use: Standard Formula, Enter Direct Quantity, Default to Condition Quantity, Quantity x Height.
- QB-05-041 MATH Standard: item_qty = cond_qty * height / OC * layers, then waste applied (see waste notes). Horizontal/Continuous options in 05.07.04 drop terms.
- QB-05-042 Enter Direct Quantity: item qty starts at 0 flagged red; user types the number; then default material/labor pricing applies. Disables Installation Method and default Height/OC/Rows. After entry the app remembers ratio = entered qty / condition qty and scales item qty proportionally when condition qty changes.
- QB-05-043 Default to Condition Quantity: item_qty = chosen condition qty. Intended for UOM EA on a Count condition qty.
- QB-05-044 MATH Quantity x Height: item_qty = cond_qty * height * layers, then waste. Allowed only when Item UOM is EA, IN, LF, or LY.
- QB-05-045 With On-Screen Takeoff quantities, Standard Formula cannot be used on a Count item.
- QB-05-046 Waste % applies only to Standard and Quantity x Height methods. Positive whole or decimal value. It raises or lowers (text says either) the quantity.
- QB-05-047 Labor on waste: cover sheet Preferences option "apply labor to waste". If off, grid Qty shows qty including waste but that row's labor uses qty without waste (looks like a discrepancy).
- QB-05-048 Item qty then may convert further to a Material Container (gallon, roll, stud) via Sizing tab.
- QB-05-049 UNKNOWN: exact waste math form (qty * (1 + waste/100) assumed). Text writes "+ Waste" only.
- QB-05-050 UNKNOWN: whether negative waste is truly rejected (text says must be positive but also says it can decrease).

### 05.07.02 Formula Descriptions (id 442)
- QB-05-051 Read-only text panel on the tab showing the Standard and OC Exception formulas and how item qty is displayed with UOM. No input.

### 05.07.03 Condition Detail Default Entries (id 443)
- QB-05-052 Defaults applied when the Item is added to a Condition; they override the Condition's own values for this Item line only and remain editable afterward.
- QB-05-053 Fields: Section (CSI number, required), Lab. Cost Code (required for Labor or Both), Height (0 means use Condition height; ignored for Horizontal), Repeat every (vertical recurrence, e.g. fastener each 12 in; ignored for Horizontal), On Center OC (horizontal recurrence; ignored for Continuous), Rows/Layers (multiplier, e.g. 2 for both sides).
- QB-05-054 Example: condition height 10 ft but Item default height 8 ft (panels sold 8 ft) so item takes the 8 ft value.
- QB-05-055 UNKNOWN: how "Repeat every" enters the quantity math (not in the Standard Formula given). Probably only for fastener ratio; not pinned down.

### 05.07.04 Installation Method (id 444)
- QB-05-056 Affects Standard and Quantity x Height only. Horizontal ignores Height. Continuous ignores OC.
- QB-05-057 MATH neither checked: cond_qty * height / OC * layers (+ waste). Studs, wall covering.
- QB-05-058 MATH Horizontal: cond_qty / OC * layers (+ waste). Grid, channel, access floors.
- QB-05-059 MATH Continuous: cond_qty * height * layers (+ waste). Wallboard, insulation, stucco, paint (SF/SY results).
- QB-05-060 MATH both: cond_qty * layers (+ waste). Flooring, ceiling drywall labor.
- QB-05-061 The ignored variables are removed with their operator, not replaced with zero.
- QB-05-062 UNKNOWN: Quantity x Height has no OC term, so Horizontal checked there is unclear.

### 05.07.05 On Center Exception Factors (id 445)
- QB-05-063 Two decimal factor fields, one for 16 in OC (400 mm metric) and one for 24 in OC (600 mm).
- QB-05-064 When a line's OC equals exactly 16/24 (400/600), item_qty = cond_qty * height * factor * layers; OC term and Waste % are both replaced/ignored. Example factors .85 and .65 (illustrative only).
- QB-05-065 For other OC values the normal method plus Waste % is used, so keep Waste % populated.
- QB-05-066 Disabled when Installation Method is Continuous or when method is not Standard/Quantity x Height. Installation Method governs how the factor applies (Horizontal likely drops height; text vague).

### 05.08 Sizing tab overview (id 446)
- QB-05-067 Sizing converts Item Quantity (SF, LF) into purchasable containers. Example: 80 SF wall, gallon covers 80 SF so 1 gallon (waste ignored in the example).
- QB-05-068 Sizing choices constrain what can be configured on Material Cost and Labor Cost tabs.

### 05.08.01 Selecting a Sizing Method (id 447)
- QB-05-069 Size Method options: Sizes, Styles, Styles with Sizes, No Sizes, Mixture. Available options depend on Item UOM. Same material priced by LF and by SF requires two Items.
- QB-05-070 Most UOMs except EA and volume units (CF, m3) show a grid with columns for size, units per container, container, weight.
- QB-05-071 Sizes: pick Container then grid rows. Linear UOM: length only; area UOM: length and width; EA or cubic: no size. Units/Per = pieces or coverage per container (10 per bundle, 350 per gallon). Units/Per only converts quantity to number of containers. Only common sizes needed; custom sizes can be added in Condition Detail size dropdown (New).
- QB-05-072 Styles: single size, varying grade/color/finish/catalog number or labor method (brush/roll/spray, form types, wall-height labor). Each style may carry different price or labor value. Reports show description followed by style name. Item list shows Styled items in blue (Styles and Styles with Sizes).
- QB-05-073 Styles with Sizes: each style can have size attributes and price. On insert into a Condition the first style row auto-selects; Condition grid Size column shows the style name, flagged blue when multiple options exist.
- QB-05-074 No Sizes: size irrelevant; typical for EA UOM and labor-only Items. Units/Per assumed in LF or mm.
- QB-05-075 Mixture: specify quantities of component Items per a Yield (e.g. TF1 = Tape-250 + Mud4 per Yield 1,000 SF). Lets a mixture convert UOM (EA anchors per LF). Combines several materials into one condition line where labor applies to the mixture. Item list shows Mixtures in pink.
- QB-05-076 Container is a label only; no effect on calculations. Mixture Yield field used only for Mixture.
- QB-05-077 Chained and Mixture components can be looked up through Show Where Used.

### 05.08.02 Sizes method (id 448)
- QB-05-078 Repeat of QB-05-071: sizes grid (example four drywall sheet sizes, container sheet). Sizes in grid appear on Material and Labor Pricing tabs when pricing by Container.

### 05.08.03 Styles method (id 449)
- QB-05-079 Styles do not change the quantity or container count, only price/labor. Style dimensions are irrelevant to calc (backer rod diameters example). Each style can have its own material price and production rate.
- QB-05-080 If Material or Labor price method is UOM, all styles share one price. On insert the first style row is selected; changing style may update material and labor pricing depending on setup.

### 05.08.04 Styles with Sizes (id 450)
- QB-05-081 Style x size combos; each combination priced uniquely. Size affects container count (bigger size usually fewer containers). Example rebar with two lengths (10, 20 ft) times several styles.
- QB-05-082 In Condition grid the labor fields show production in quantity, pieces, or time.

### 05.08.05 Mixtures (id 451)
- QB-05-083 Mixture setup: Mixture Yield (round number, unit = Item UOM, e.g. 1000 SF) plus component grid (New, Lookup into Master Items, quantity column). Container field greyed; components' containers are used.
- QB-05-084 Component quantity is expressed in the component's container units. Example: 10,000 pieces per carton, 1000 needed per yield, enter 0.10. Example TF1: 1.5 rolls tape + 2 boxes mud per 1000 SF.
- QB-05-085 Mixture can convert UOM: incoming LF, outputs EA components.
- QB-05-086 If Material Pricing "Price Per" was set to other than 1 before choosing Mixture, reset it to 1 first.
- QB-05-087 In a Condition, size cell becomes a pink Mixture button opening Mixture Info; only component Material Cost editable there. "Change" opens the mixture Item Detail for components, labor pricing, production. Component Item details edited from Materials tab.
- QB-05-088 UNKNOWN: mixture quantity math, presumably containers_needed = item_qty / yield * component_qty. Not stated.

### 05.09 Material Cost tab overview (id 452)
- QB-05-089 Price methods available depend on Size Method and Container. Pricing may be by piece, UOM, container, per 1000 etc. Changing cost writes a date in "Changed" column; shows on Materials tab "Price Updated".

### 05.09.01 Price by UOM (id 453)
- QB-05-090 One price per Item UOM regardless of sizing. "Price Per" choices: 1, 100, 1000 units. MATH material_cost = item_qty / price_per * price (implied).

### 05.09.02 Price by Style or Style with Size (id 454)
- QB-05-091 Grid has price per style (or style+size). Price Per (1, 100, 1000) and Units (from Item UOM). EA items normally Price Per 1.

### 05.09.03 Price by Piece (id 455)
- QB-05-092 Price per size (piece). Not available when UOM is EA, CY or CF.

### 05.09.04 Price by Container (id 456)
- QB-05-093 Price per container; grid has units per container (example 500 clips, 18.98 per box). Container names are labels. MATH implied: containers = item_qty / units_per_container, cost = containers * price. UNKNOWN: rounding up to whole containers is not stated (ordering implies ceiling).

### 05.10 Labor Cost tab overview (id 457)
- QB-05-094 Two grids: installer info and production rates. Method (UOM, Style, Piece, Container) depends on sizing. Totals direct crew cost excluding Burdens, Markups, Indirect Expenses.

### 05.10.01 Labor general (id 458)
- QB-05-095 Labor Cost Method: UOM (production per day, hour and cost per UOM), Style (per style), Piece (per size), Container (per container).
- QB-05-096 Use Piece or UOM when install labor is same regardless of size/style.
- QB-05-097 Default Wage Type: anything other than Default overrides the Cover Sheet Wage Type when Item is added to a Bid. Changeable later at Condition or Bid level. Recommended: leave Default.

### 05.10.02 Installer / crew (id 459)
- QB-05-098 Labor tab top grid: Payroll Class rows (Add button) plus Crew (count of each class). Mixed crews allowed; differing pay rates are blended into the single cost shown in the production grid.
- QB-05-099 Option: fractional crew entries summing to 1 so production is expressed for one person-equivalent.

### 05.10.03 Fractional composite crew (id 461)
- QB-05-100 Crew entries as decimals (e.g. Hanger 0.6, General Laborer 0.4) totaling 1.00; Condition grid and bid reports then show crew size 1.
- QB-05-101 Payroll and Production reports split hours by fraction (60%/40%); cost is not split 60/40 because wage rates differ. Example blended unit labor price 0.110 per unit.
- QB-05-102 Price method guidance repeats 05.10.01.

### 05.10.04 Base production (id 462)
- QB-05-103 Production grid has three linked columns: per hour, per day, and Price. Editing one recalculates the other two. Price derives from Payroll Class wage settings excluding burdens, markups, indirect expenses.
- QB-05-104 MATH relation (implied): price = (crew_hourly_cost_total) / production_per_hour; per_day = per_hour * hours_per_day (hours/day from Cover Sheet preference).
- QB-05-105 Changing crew size does not change stored production rates; it changes labor price. Production or Price must be manually updated for new crew size.
- QB-05-106 Changing a wage in Payroll Tables does not change production; it changes unit labor cost.
- QB-05-107 Default Wage Type = "Default" uses the first Wage Type in the Wage Types list for item labor cost (the Item master level).

### 05.10.05 Labor in Condition Detail (id 463)
- QB-05-108 Condition line shows crew size, unit price and production for the whole crew. Example X58: crew 1, production 125/hr, 1000 SF gives 1000/125 = 8 hours; raw labor $0.120 per SF.
- QB-05-109 Raw unit labor price excludes Burden. Burdens (from Payroll Settings) applied automatically and included in Section Totals window (example $2.90/unit shown there; unclear basis).
- QB-05-110 Example shows 16 crew hours because 2 layers double the item qty (plus a little waste). MATH: crew_hours = item_qty / production_per_hour where item_qty includes layers (waste only if option on).
- QB-05-111 UNKNOWN: How $2.90 relates to 0.120 (appears to be total section labor not per SF). Cannot be verified.

## Category summary (05 Items)
- QB-05-S01 Item = material, labor, or both with one UOM; tabs General, Calculation, Sizing, Material Cost, Labor Cost.
- QB-05-S02 Three levels: Master template, Bid-level copy (one material price per item per bid), Condition-level line (labor production, height, OC, layers per use).
- QB-05-S03 Calculation: item_qty = cond_qty(1,2,3) * height / OC * layers + waste, with Horizontal dropping height, Continuous dropping OC; OC 16/24 exception factors replace OC and waste.
- QB-05-S04 Other methods: direct quantity (ratio remembered), default to condition quantity, qty x height (UOM EA, IN, LF, LY only).
- QB-05-S05 Sizing converts item qty to containers: Sizes, Styles, Styles with Sizes, No Sizes, Mixture (yield-based component list). Container is a label, Units/Per does the conversion.
- QB-05-S06 Material pricing by UOM, Style, Piece (not for EA, CY, CF), or Container; Price Per 1, 100, 1000; changed date tracked.
- QB-05-S07 Labor: payroll class crew (fractions summing to 1 allowed), production per hour/day/price linked; burdens added later at section level; wage type default from cover sheet.
- QB-05-S08 Chains auto-insert following items once per condition; Show Where Used lists assemblies, mixtures, chains; used items cannot be deleted.
- Articles read in category 05: 30 (ids 433 to 463 less 460 which is absent).

## CATEGORY 06: Bids

### 06.00 What are Bids (id 464)
- QB-06-001 A Bid (also Project, Estimate, Job, Tender) = total estimated cost of material, labor, equipment, subs, other, plus markups, indirects, overhead, profit.
- QB-06-002 A Bid contains the Base Bid plus Alternates and Change Orders (called child bids).
- QB-06-003 Creation routes: new from scratch, copy bid between databases, duplicate, interactive bid from takeoff app, import Bid Package, import takeoff file (*.ost).

### 06.01 Create a new Bid (id 465)
- QB-06-004 Only Project Name required. New via File > New > Bid, toolbar New dropdown, right-click in Bids list or Navigator, or Insert key on Bids tab.
- QB-06-005 Defaults come from Tools > Options > New Bid: Bidding Company, Job Status (first in master list), Bid Date/Time (now). After OK, Bid appears on Bids tab and Conditions tab opens.

### 06.01.01 Cover Sheet fields (id 466)
- QB-06-006 Every Bid, Change Order and Alternate has a Cover Sheet.
- QB-06-007 Fields: Job Status*, Bidding Company*, Project Name (max 75 characters, plain alphanumeric English only, no # % or slashes/brackets/shift-number symbols; special characters can break import/export), Lead Estimator*, Job Type*, Bid Date, Bid Time, Total Sq. Size (optional; used in Cost per Sq. Size report), Auto sum (sums first-level Bid Areas only into Total Sq. Size), Bid No. (auto from Next Bid Number option; editable but unique; do not change after creation), Job No. (free text), Acct. ID, Plans Date, Job Start, Job End. (* = from Masters; unknown value prompts to add to Masters.)
- QB-06-008 Buttons: OK (save, validates required), Cancel, Bid Areas, Typical Areas, Payroll Setup (only visible for imported or pasted bids; encapsulates the bid's own wage types and burdens so database payroll is not altered).
- QB-06-009 With takeoff app interactive, Bid Areas and Typical Areas are managed in the takeoff app.
- QB-06-010 Tabs: Job Site/Contacts (site info; zip needed for eQuotes; project contacts), Preferences, Notes (printable on reports), Estimating Team (per-estimator rights, capped by admin rights), Results (competitor pricing and award outcome via Contacts lookup).

### 06.01.02 Bid Preferences (id 467)
- QB-06-011 Preferences default from Tools > Options > New Bid; edits affect this bid only.
- QB-06-012 Static: Default Wage Type (list from Payroll Settings; used wherever record does not specify), hours in regular work day, days in regular work week (affect production/time calcs).
- QB-06-013 Calculation Options: Markup Method (Straight vs Gross, affects profit and overhead), checkbox Apply labor to additional waste quantity.
- QB-06-014 Apply Default Indirect Expenses: when checked, Stock, Clean, Supervision, Per Diem applied to Section costs from Default Markups and Indirect Expenses; when unchecked can still be added on Markups tab.
- QB-06-015 MWBE requirement text; Cover Page Report Text.
- QB-06-016 UNKNOWN: Straight vs Gross markup formulas (separate article, not in these files).

### 06.02 Import Bid Package (id 468)
- QB-06-017 Bid package file extension .qbp; imports only into same or newer version. Double-click file imports into active database, or File > Import > Quick Bid Package File. Default folder C:\OCS Documents\Quick Bid.
- QB-06-018 Rules: interactive source bid imports with read-only cover sheet (Cancel then Yes to save); interactivity must be restored by importing OST bid copy and reconnecting. If source database required login the bid goes into a newly created database named for the bid with "Require Login", copied security and estimator list. Re-importing same file makes another copy (no overwrite). Payroll settings packaged with bid: new Payroll classes added to Master, wage types added to Payroll Settings, existing ones not changed; Bid > Refresh Payroll Wages applies database wages to the bid.

### 06.03.01 Interactive rules (id 469)
- QB-06-019 Data flow: quantities are produced in takeoff app and pushed to Quick Bid; material/labor, equipment, subs, markups, indirects are added only in Quick Bid.
- QB-06-020 Bids, Alternates, Change Orders, Conditions, Bid Areas, Typical Areas must be created, modified, removed in the takeoff app. Once linked, Quick Bid disables adding/removing Conditions, changing Condition quantities, and editing Bid/Typical Areas.
- QB-06-021 Strict 1:1 relationship between one takeoff database and one QB database (master tables synchronized; many-to-one corrupts). One estimator at a time on an interactive bid. SQL Server needed for sharing; server/db names spelled identically for all users; never share Access databases.
- QB-06-022 Never open interactive bid in a program in no-license mode or not installed. Do not change Bid No.; use Job No. for custom number.
- QB-06-023 Tips: right-click condition in takeoff app, Change Details opens QB Condition Detail (can be default). For non-takeoff conditions enter quantity manually on the takeoff Worksheet tab; it transfers. F9 refreshes in manual mode.

### 06.03 Creating an interactive Bid (id 470)
- QB-06-024 Pre-reqs: both programs licensed, bids-tab filters cleared in both, target QB database open and user has rights.
- QB-06-025 In takeoff cover sheet set Price Using: Quick Bid (interactive, recommended: real-time push, QB must be open) or Quick Bid (manual: refresh by F9). Then Database lookup lists only databases open in QB. OK creates companion QB project. If QB not running, takeoff app offers to open it; refusing leaves bid in Manual until later switched to Interactive.
- QB-06-026 Small icons mark linked bids in each program's Bids tab.
- QB-06-027 Rights error fix: clear filters, license, Full Access to Bids List.

### 06.03.02 Synchronization (id 471)
- QB-06-028 Conditions, takeoff, areas, typical areas, Alternates, Change Orders all sync from takeoff app to QB.
- QB-06-029 Two master tables synced between databases on connect: Condition Types and Job Statuses. With Digital Production Control, Labor Cost Codes and Payroll Classes in use are synced to DPC (not whole tables).
- QB-06-030 Manual mode refresh: Bid > Refresh Quick Bid or F9. Disconnected state shows a red banner on the takeoff Image tab.

### 06.03.03 Connect / disconnect (id 472)
- QB-06-031 Reconnect: both apps open and licensed, correct databases active. In QB right-click bid, Connect to On-Screen Takeoff Bid, enter takeoff Bid number, confirm twice. Bid returns in Manual mode; set Price Using back to Interactive.
- QB-06-032 Disconnect: right-click bid or Bid menu, Disconnect from On-Screen Takeoff Bid. Nothing altered, link severed.
- QB-06-033 Reconnect fails if during disconnect: conditions added/edited/renamed (names must match exactly incl. case and numbering), project/alternate/change-order names changed, alternates or change orders added/removed, areas/typical areas changed. Fix: manual takeoff-file update; or compare condition lists, duplicate bids first.

### 06.04 Create Bid from takeoff file (id 473)
- QB-06-034 Source *.ost export (not a bid package) from OST or ConstructConnect Takeoff. File > New > Bid from Takeoff (or dropdown/right-click). Access Method: Import Takeoff file. Browse.
- QB-06-035 Options: Import zero-quantity conditions; Create Bid areas for unused areas; Round Decimal Places To (OST may carry 6 decimals; QB imports max 4; default 0).
- QB-06-036 ConstructConnect Takeoff exports only the top three Results per condition.
- QB-06-037 UNKNOWN: rounding rule (half-up assumed) and whether rounding applies before or after item calc; default 0 decimals could materially truncate quantities.

### 06.04.01 Update bid from takeoff file (id 474)
- QB-06-038 Right-click bid, Update from Takeoff, same options. Overwrites all QB conditions and quantities with takeoff file; QB conditions absent from file are permanently removed (warning lists them); existing areas are not removed; alternates/change orders in file can be added but not removed from QB.
- QB-06-039 Recommend duplicating bid before update. QB-only alternates/change orders must be removed before reconnecting.

### 06.05 Alternates and Change Orders (id 475)
- QB-06-040 Child bids: Alternates (options priced during bidding, owner accepts or rejects, accepted ones add or subtract from base price) and Change Orders (scope changes after award, tracked separately).
- QB-06-041 Alternate rules: same Payroll Settings and same Material pricing as the base bid, two-way (change in either reflects in the other). Markups and Indirect Expenses can be configured separately.
- QB-06-042 Change Order rules: may have own Payroll Settings, material pricing, Section Markups, Indirect Expenses (Stocking, Cleanup, Supervision, Per Diem). Totals independent: base changes do not alter CO total and vice versa. Pricing is seeded from base bid items; items not in base come from master. CO looks in base bid first before master.
- QB-06-043 An accepted Change Order is not merged into base bid labor/material reports but does appear on the base Bid Summary Report. Accepting a CO changes overall Selling Price while costs are reported separately.
- QB-06-044 Create: select parent bid, File > New > Alternate or Change Order. Cover Sheet fields: Name (required, 75 chars, same character restrictions), Job No., Acct. ID, Submitted (alternates only, default today), Lead Estimator (CO only), Job Start and Job End (CO only), Total Sq. Size (CO only, used in Bid Analysis report), Auto Sum (CO only, top level areas only), Areas and Typical Areas (CO only; alternates inherit base), Accepted, Notes. "No." field for children limited to 25 characters.

## CATEGORY 07: Conditions

### 07.00 What are Conditions (id 479)
- QB-07-001 A Condition describes a building object (wall, ceiling, door) with all material and labor to build it. One Condition per unique object type and per unique height.
- QB-07-002 Three types: Area (SF, SY, m2), Linear (LF, LY, mm), Count (EA).
- QB-07-003 Building a condition = adding Items; main pricing activity. Defaults make most costs auto-add.
- QB-07-004 One Condition can span multiple Bid Areas (assign quantity per area, e.g. per floor) when height and build are the same.
- QB-07-005 Typical Areas: groups of conditions that repeat (apartments, suites); quantity assigned to a Typical Area and a count of occurrences per Bid Area; reports by typical unit, floor, building or project total.
- QB-07-006 Interactive bids: create all conditions in the takeoff app.

### 07.01 Create or add conditions (id 480)
- QB-07-007 Five ways: from scratch, copy/paste between bids (or base to child), duplicate, import quantity survey from Excel, takeoff app (interactive).
- QB-07-008 New condition: Conditions tab, Insert key, File > New > Condition, New dropdown, or right-click New Condition; opens Condition Detail.

### 07.01.01 Copy conditions to another bid or child (id 481)
- QB-07-009 Copy/paste on Conditions tab (right-click, toolbar, Ctrl+C / Ctrl+V; multi-select) within same bid, to another bid, or base to Alternate/Change Order. Quantities and Condition Details copy over.
- QB-07-010 Condition numbers renumber in the receiving bid but keep original order.
- QB-07-011 Markups and Indirect Expenses are NOT copied (by design); unit costs and totals may differ and must be adjusted in the receiving bid.
- QB-07-012 Cross-database: missing Item Types, Condition Types, Payroll Classes are added to destination masters; if option "Create Master Items during Bid copying" (Tools > Options) is on, missing Items are added to Master Items too.
- QB-07-013 Condition Items (grid contents) can also be copied between conditions (see 07.12).

### 07.01.02 Duplicate conditions (id 482)
- QB-07-014 Select one or more (Shift adjacent, Ctrl individual); Duplicate icon, right-click, or Ctrl+D. Copies all properties except Cond. No.; new numbers sequential from next available. Condition Details including Markups and Indirect Expenses ARE copied (contrast with copy/paste to another bid). Use case: same wall at 8, 9, 10 ft heights.

### 07.02 Quantity survey import overview (id 483)
- QB-07-015 Excel (.xls/.xlsx) survey imports to create conditions and quantities. Unit system (metric vs imperial) must match the database. Row 1 must have data in some column (suggest project name in A1). One Bid Area per condition on import.
- QB-07-016 Import allowed only when not interactive and the Conditions list is empty; else import into a new bid and copy conditions over.

### 07.02.01 Survey format (id 484)
- QB-07-017 Header row is row 5 with exact headers: A Type, B Area, C Name, D Item, E Description, F Quant, G Unit. Columns H, I ignored; Rate and Total optional and not imported.
- QB-07-018 Column A marker: T = condition type row (type name in Description column E, nothing else on row); N = start of a condition block (Area in B, base Name in C, base notes in E). Applies to all following rows until the next T or N.
- QB-07-019 Sub-rows leave A, B, C blank. Column D (Item) is a suffix: condition name = Name + Item (e.g. Wall + A = "Wall A"). Column E on a lettered row = notes for that variation, appended to the base notes. If D blank on an N row, E is base notes.
- QB-07-020 F = one quantity, G = unit. Valid units: m, mm, m2, mm2, m3, mm3, EA, IN, LF, LY, IN2, SF, SY, SQ, CF, CY.
- QB-07-021 Rows lacking N/T marker and lacking Item, or with invalid data, are skipped.

### 07.02.02 Running the import (id 485)
- QB-07-022 Right-click Conditions tab, Import Quantity Survey Conditions; browse; confirm UOM matches database Measure Mode; scan with progress bar; error if Type/Area/Name headers not found or format wrong.

### 07.02.03 Import details (id 486)
- QB-07-023 Names persist until the base name changes; same for Area (new area auto-created; blank area becomes unassigned) and notes.
- QB-07-024 Type: T row with blank Description gives no type (discouraged because tabs filter by type); type carries forward until next T; missing type is auto-created in masters.
- QB-07-025 Quantity and UOM populate if present.

### 07.03 Condition Detail overview (id 487)
- QB-07-026 Condition Detail has five areas: Condition Information, Section Totals and Unit Pricing, Condition Notes, Item Detail Grid (Condition Grid), Controls and Toolbar.

### 07.03.01 Condition Information (id 488)
- QB-07-027 Interactive bids: Areas, Typical Areas and Quantities are read-only in QB.
- QB-07-028 Fields: Cond. No. (auto sequential, editable to unused number), Name (descriptive; appears on all reports; user can rename), Type (optional; groups Conditions tab and Assemblies list), Area (single area, or Multi-Area checkbox opens Multi Areas dialog; Typical Areas listed above Bid Areas; Qty 1, 2, 3 and Count columns auto-sum into the condition), Count (informational only, not a sum of the Multi-Area dialog), Quantity 1, 2, 3 (primary and secondary quantities with a UOM each; whole or fractional; most Items calc from Qty 1; Qty 1 UOM drives the Totals view), Height, Width and Depth.
- QB-07-029 Height: one per Condition. Imperial entered as feet and inches digits (10 ft = 1000, 13 ft 8 in = 1308); metric in millimeters. Changing height on a duplicate recalculates all item lines after a prompt.
- QB-07-030 Width and Depth appear only when Qty 1 UOM is EA; a checkbox ignores them in item calculations.
- QB-07-031 MATH EA conditions: perimeter = (width + depth) * 2; surface area = height * perimeter (sides only); volume = height * width * depth. Example column H 10 ft, W 2 ft, D 3 ft: perimeter 10 LF, area 100 SF, volume 60 CF, so any item UOM can be computed from a count.
- QB-07-032 Without a Depth, EA objects are still treated as 3-D square objects with front and back sides; the Ignore option disables this.
- QB-07-033 UNKNOWN: how perimeter/area/volume values are multiplied by the EA quantity (presumably qty * each) and which Qty slot they land in.

### 07.04 Areas, Typical Areas, Phases overview (id 489)
- QB-07-034 Bid Areas = locations (buildings, floors, wings, zones) to allocate costs; required for Typical Areas; reports per area.
- QB-07-035 Typical Area = repeating unit; user assigns count per bid area; totals computed. Because a condition has one height, name conditions and typical areas with height (e.g. "Apt. 2B - 8' 6").
- QB-07-036 Phases roll multiple Bid Areas up (e.g. Floors 1-2 = Phase 1). Some exports with Account Codes use Phases instead of Bid Areas. Phase info is copied from base bid to Change Orders created afterwards only; each bid then independent; add phases to existing COs by hand.

### 07.04.01 Bid Areas dialog (id 490)
- QB-07-037 Open via Bid > Show Areas, Cover Sheet Areas button, or lookup beside Area in Condition Detail. Buttons: New, Quick Add (multiple like areas, names from dropdown or custom; Indent under selected parent checkbox), Up/Down, Indent/Outdent, Delete, Print (preview, export pdf). Area size (SF) column feeds analysis reports and Total Sq. Size autosum. Plus sign marks parents.
- QB-07-038 After deleting an area, close the dialog before adding more (changes only stored on close) to avoid corrupt data.
- QB-07-039 Takeoff Zones transfer as top-level Bid Areas.

### 07.04.02 Single area (id 491)
- QB-07-040 Type first letters of area name or use lookup, Select. Dialog also allows add/edit/remove areas.

### 07.04.03 Multiple areas (id 492)
- QB-07-041 Multi-Area checkbox opens dialog with Qty 1, 2, 3 per bid area. Condition quantity fields become read-only; quantity is the sum. Phases cannot be set here, only from Cover Sheet Bid Areas dialog.

### 07.04.04 Typical Areas (id 493)
- QB-07-042 Open via Bid > Show Typical Areas, Cover Sheet button, or Multi button then Typical Areas. New names appear as columns beside Bid Areas; enter occurrences of each typical area per bid area (matrix). Multi-Area dialog then shows total repeat count in parentheses beside each typical area; enter per-occurrence Qty 1, 2, 3 on that row.
- QB-07-043 MATH condition_qty = sum over typical areas of (per-occurrence qty * total occurrences) + quantities in Unassigned and ordinary area rows. Example: Unit A-8 and A-10 each 50 Qty 1 and 5 Qty 2 per unit, Lobby 10 and 1 per lobby; result e.g. Qty1 2600 SF.
- QB-07-044 Common quantities (demising walls) should be assigned to Unassigned/area rows, not to a Typical Area, to avoid duplication. Height-specific conditions (walls) cannot span different heights via typical areas; horizontal items (acoustical ceiling) can.
- QB-07-045 Dialog tools: Fill Down, Fill Right, Areas button, Copy (to spreadsheet), Print (Typical Area Report, export).

### 07.04.05 Phases (id 494)
- QB-07-046 Phases assigned in Bid Areas dialog (Phase # per area plus Description such as dates). Roll up on exports; JobCost and Plexxis exports support phases in QB 4.96+. Phase values copy to later COs only.

### 07.05 Section Totals and Unit Costs (id 495)
- QB-07-047 Shows: priced material and labor, selling price with markups from Markup Detail, price including proportional share of indirect expenses (Stock, Clean, Supervision, Per Diem).
- QB-07-048 MATH unit price = section selling price / Quantity 1 expressed in the UOM chosen in the Totals dropdown (view only; does not change calcs). To change actual calc UOM edit Qty 1, 2, 3 UOMs.
- QB-07-049 View Markup button: read-only display of direct and indirect expenses; edit on Markups tab. View Options dropdown filters by CSI Section when condition spans sections.

### 07.06 Item Detail Grid (id 496)
- QB-07-050 Each condition row is driven by an Item code. Example wall K1 at 10 ft with nine items (track, studs, pan-head screws, concrete pins, layout labor, framing labor, wallboard with hang labor, board screws, tape and float), covering 295.69 LF (rounded 296).
- QB-07-051 Item code pulls from Master unless the Item already exists in this Bid. Height, OC, Layers and Qty editable per line without affecting other uses. Exceptions: Material price (one per bid) and crew makeup (one per item).
- QB-07-052 Colors: green = money; yellow = Height, OC, Layers and production values; red production = higher than the item's base (maybe unrealistic); blue production = lower than base; pink = Mixture; light blue = item code and sizing.
- QB-07-053 Columns: Sect (defaults from Master; editable per line), Item (entry field), Item Description (hideable via Show Description), Lab. Code (editable per line), Height (disabled if Horizontal and Continuous), OC, Layers, Qty, UOM (item UOM may differ from condition UOM), Size (dropdown; auto-matches condition height; New adds custom), Mat. Price, Per, Lab. Cost, Wage Type, Crew (button shows payroll classes), %Base, Qty/Hr, Pcs/Hr, Crew Hrs, Mat Total, Lab Total, Item Total.
- QB-07-054 Qty cell states: red 0 = direct-entry item awaiting a value; blue = manually entered; red 0 also = cannot calculate because setup inconsistent (e.g. LF item calculating from Qty 1 that is EA or blank).
- QB-07-055 Mat. Price edit prompts to update Master. Yes: updates current bid (all uses) and Master. No: current bid only. Existing other bids never change.
- QB-07-056 %Base column: production as a percent of the master base (100 = base). 110 raises production 10 percent; 50 halves it. Red above 100, blue below. Affects only that line.
- QB-07-057 Qty/Hr, Pcs/Hr and Crew Hrs headers toggle between hour and day when clicked.
- QB-07-058 MATH Mat Total = item_qty * mat_price / per. Lab Total = item_qty * lab_cost, where item_qty excludes waste when labor-on-waste is off. Item Total = Mat Total + Lab Total (raw cost, no markups or indirects). Column subtotals at bottom of grid.
- QB-07-059 Manual quantity: ratio stored = manual qty / Condition Qty 1 (100 with manual 50 gives 0.5; Qty 1 changed to 400 gives 200). Enter 0 to restore default calc.
- QB-07-060 UNKNOWN: whether ratio uses the Qty selected by the Item's "Use Condition" setting rather than always Qty 1.

Price, Lab. Cost, Qty/day, Pcs or Cuts/day, Crew Hrs, Material, Labor, Item totals).

### 07.10 Saving a Condition Assembly (id 500)
- QB-07-066 Assembly = saved template of items that adapts to the target condition; like a chain but saves labor production changes. Manufacturer assembly packages exist.
- QB-07-067 Pricing always looks to Bid-level items first (current bid prices), else Master. Payroll class wage: bid-level if used, else Master (one setup per class per bid).
- QB-07-068 Assemblies store production values (rate per quantity, e.g. per 1000 SF), not costs.
- QB-07-069 Height-bearing material items are reset to the target condition height on insert (10 ft assembly into 14 ft wall sets items to 14 ft); labor production stays as saved and may need adjusting.
- QB-07-070 Direct Entry items store a ratio to condition quantity (100 LF trim on 1000 SF = 0.1) and reapply it.
- QB-07-071 Create: build condition, set production, click Assembly button, New in Condition Assembly List (Master); detail dialog fills with the items and condition info (qty, UOM). Edit items, set unique Name, Type (tree grouped by Condition Type), Estimator (Owner, expected for every assembly), notes, item order; Close saves.

### 07.11 Inserting an Assembly (id 501)
- QB-07-072 Assembly button, expand list, double-click or Select. If grid already has items, Assembly Select dialog: Append (after last item), Replace (clears existing items first), Cancel.
- QB-07-073 After insert verify labor, production, materials, layers. If wage type differs from assembly, check Tools > Options "Use Wage Type from assemblies".

### 07.12 Copy item details between conditions (id 502)
- QB-07-074 Copy Details and Paste Details buttons below the grid (not the main toolbar Paste). Select all or Ctrl/Shift subset of rows. Works across bids and databases.
- QB-07-075 Only rows copy; Markups and Indirect Expenses are not copied, so unit costs and totals may differ. Cross-database: missing masters added; "Create Master Items during Bid copying" adds missing Items to Master.

### 07.13 Deleting conditions (id 503)
- QB-07-076 Delete button, Del key or context menu; single confirmation (Yes, Yes to All); no undo. Recommended to keep confirmation on. Interactive bid: removal only in takeoff app, which propagates to QB.

## Category summary (07 Conditions)
- QB-07-S01 Condition = building object with type Area, Linear or Count; up to three quantities with UOMs; one height (feet-inches digits, e.g. 1308) or mm; EA conditions add Width and Depth giving perimeter = (W + D) * 2, area = H * perimeter, volume = H * W * D.
- QB-07-S02 Condition is priced by Item lines; each line shows Height, OC, Layers, Qty, size, material price, production, %Base, crew hours; Mat Total = qty * price / per; Lab Total = qty * lab cost; raw cost excludes markups and indirects.
- QB-07-S03 Unit price shown = section selling price (with markups and indirect share) / Qty 1 in the chosen view UOM.
- QB-07-S04 Quantity allocation: single area, Multi-Area (qty per area), Typical Areas (occurrence matrix times per-unit quantities); phases roll up areas for accounting exports.
- QB-07-S05 Manual item quantity keeps a ratio to Qty 1; entering 0 resets to calc; red/blue flags indicate unusual states.
- QB-07-S06 Copy/paste of conditions or item rows to another bid does not carry Markups/Indirects; duplicate within a bid does.
- QB-07-S07 Quantity survey import from Excel: header row 5 (Type, Area, Name, Item, Description, Quant, Unit), T and N row markers, name = Name + Item, units list fixed; only into an empty, non-interactive bid.
- QB-07-S08 Assemblies save production and ratios, adapt heights, price from bid-level items first; insert via Append or Replace.
