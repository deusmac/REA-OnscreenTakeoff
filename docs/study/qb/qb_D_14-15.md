# QuickBid notes D: categories 14 (bid/accounting/material exports) and 15 (databases)

## CATEGORY 14

### 14.00 Import/export overview (id 570)
- QB-14-001 Three ways data leaves a bid: whole-bid package export/import; copy-paste from grid tabs (Materials, Labor); generated Materials and Accounting exports.
- QB-14-002 Most exports are CSV; accounting exports use vendor-specific layouts. Setup UI mirrors Reports but with fewer choices.
- QB-14-003 Vendor import help is out of scope (support line, skip).

### 14.01 Bid packages (id 571)
- QB-14-010 Bid package file extension qbp holds everything needed to rebuild a bid in another database (items, pricing, etc.).
- QB-14-011 Export: File menu or bid right-click, "Export to Bid Package". Default file name is built from bid number, bid name and date. Default folder set in Options > Folders > Package Folder.
- QB-14-012 Send by email: main toolbar send menu, "By Email" builds the package and opens a mail draft with the qbp attached (needs MAPI mail client).
- QB-14-013 Import always creates a NEW bid in the active database; never overwrites. Importing the same file twice makes two copies. Double-click on a qbp while app is running also imports.
- QB-14-014 Manual import: File > Import (or navigator right-click), choose package type, pick file, then cover sheet opens; OK returns to Bids tab.
- QB-14-015 Package can only be imported into same or newer app version than created it.
- QB-14-016 If source database required login, the import does not go into any existing database. App creates a new database named for the bid, set to login required, copying the source security settings and estimator list with passwords. To avoid this, copy the bid to a no-login database first, then export.
- QB-14-017 eQuotes created in the bid are included; invited suppliers and received supplier quotes are not. eQuotes must be resent from the new database (sent quotes are tied to origin database/bid).
- QB-14-018 Payroll settings travel with the bid. On import, missing payroll classes are added to the master, missing wage types added to payroll settings; existing ones keep database wages/burdens. Bid menu "Refresh Payroll Wages" applies database wages to the bid.
- QB-14-019 Import/copy into another database may add missing master records (items, cost codes, payroll classes) depending on a General option; applies even to restricted users.
- QB-14-020 Interactive link with takeoff app is lost on import: cover sheet is read-only; cancel then confirm save; must import a copy of the takeoff bid and reconnect.
- QB-14-021 Project names should avoid special characters (shift+number symbols) or import/export may fail.
- QB-14-022 UNKNOWN: qbp internal format and how item de-duplication against masters is matched (by code, name, id).

### 14.02 Bid/labor/material/accounting exports dialog (id 572)
- QB-14-030 Open via Exports toolbar button or Bid > Generate Exports. Dialog resembles Bid Reports. Select an export, click its options button, set file name/location (do not change extension), OK, then press Export. File is written only on Export, not on OK.
- QB-14-031 Default location is the database folder with a generic name.
- QB-14-032 In a change order, export covers that change order only. To export base bid with or without accepted child bids, select base bid in navigator first.
- QB-14-033 Accounting and custom exports need active maintenance subscription; bid, labor, material exports are for any licensed user.

### 14.02.01 Global export options (id 573)
- QB-14-040 Global options: include accepted alternates/change orders (base bid only), include bid number, use account codes. (Article says four; three are listed. UNKNOWN: the fourth.)
- QB-14-041 Use Account Codes: substitutes the cost code's linked account code for the cost code in output; if none assigned, cost code is used. If the export format supports phases, bid areas roll up into phases.

### 14.02.02 Filtering by area/division/section (id 574)
- QB-14-050 Export dialog has "Areas/Typical Areas to allow" selector; check areas, then set options file name (user should name per area) and Export. Repeat per area group.
- QB-14-051 Same filter approach exists for sections/divisions.
- QB-14-052 UNKNOWN: whether typical areas in a filtered export are expanded into their parent bid areas.

### 14.03 Job budget exports overview (id 575)
- QB-14-060 Supported targets: AccuBuild, ComputerEase, Dexter+Chaney Spectrum, Explorer Software, Foundation, QuickBooks, JobCost, Jonas, Maestro, Maxwell American Contractor, Plexxis, Sage 100 Contractors, Sage 300 CRE (Timberline), StarBuilder/StarImport.
- QB-14-061 Steps: Exports > Job Budget File > Options > pick Export Format > options > file > OK > Export.
- QB-14-062 Tax option semantics, two flavors. Flavor A "Include and Distribute Material Tax": checked rolls tax into the source cost code amount; unchecked drops tax from the file entirely. Flavor B "Distribute Tax": checked rolls tax in; unchecked emits tax as a separate row under the same cost code with category code MT.
- QB-14-063 Burden option "Distribute Burden": checked adds burden to labor amount; unchecked emits a separate row with category code LB (default, vs L).
- QB-14-064 Optional "Group by Section and Areas" for some formats.
- QB-14-065 Fallback if package unsupported: export CSV, edit in spreadsheet, import as text.

### 14.03.00 Account codes (id 576)
- QB-14-070 Account Codes are an optional separate master list (Master > Account Codes); each has code and description; assigned on the Cost Codes list per cost code.
- QB-14-071 Format varies by accounting vendor (4 or 5 chars, or hyphenated pattern).
- QB-14-072 Account code display affects only what is shown/exported, never calculations. Job Cost Summary, Field and Production reports can also switch to account codes.

### 14.03.01 AccuBuild budget (id 577)
- QB-14-080 Output XLS with headers. Custom category codes not supported (export comes out blank); must be M,L,S,E,O.
- QB-14-081 Columns: 1 Cost Code (account code if option on and assigned, else cost code); 2 Description (matching description); 3 Area (blank unless Group by Areas); 4 Material; 5 Hrs; 6 Labor; 7 Subcontractor; 8 Equipment; 9 Other; 10 Total.
- QB-14-082 Material = net amount, plus tax if Include and Distribute Material Tax. Sub, Equipment, Other each get "+ tax" under the same option. Labor = net, plus burden if Distribute Burden.
- QB-14-083 Total = row cost total. UNKNOWN whether it includes undistributed tax/burden; no overhead/profit stated.

### 14.03.02 ComputerEase budget (id 578)
- QB-14-090 CSV, no headers. Needs QB 4.99.03+. Custom category codes unsupported (blank output).
- QB-14-091 Columns: 1 phase number (only if Group by Areas); 2 phase description (same); 3 cost or account code; 4 matching description; 5 labor hours; 6 labor cost (net, or net+burden if distributed); 7 burden (blank if distributed); 8 material; 9 subs; 10 equipment; 11 other (each net, or net+tax if distributed); 12 marked-up contract amount including tax, burden, overhead and profit.
- QB-14-092 Only this export and the Explorer one carry a sell-price style column.

### 14.03.03 Dexter+Chaney Spectrum (id 580)
- QB-14-100 CSV, no headers; first row is a job record starting with a "P" marker in column 1, carrying bid name and job-site address fields and a grand total of labor hours in the hours column.
- QB-14-101 Detail columns: code (cost/account), description, category code (M,L,E,S,O only), quantity, UOM, amount, labor hours, then blank fields for billing item, alt phase, project qty, work comp code, vendor name, sub name.
- QB-14-102 Distribute Tax and Distribute Burden both available; unchecked yields separate rows with category MT or LB.
- QB-14-103 UNKNOWN: exact layout of first record (article table mixes header rows of two record types).

### 14.03.04 Explorer Software / formerly Conac (id 579)
- QB-14-110 CSV, no headers, no tax/burden options mentioned. Columns: 1 constant 1; 2 bid number; 3 section number; 4 cost/account code; 5 constant 0; 6 cost category (material, labor, other, equip, subs); 7 cost code description; 8 account code description; 9 quantity; 10 UOM; 11 labor hours; 12 net amount plus overhead, profit, tax, burden.
- QB-14-111 Vendor defunct; no support.

### 14.03.05 Foundation (id 581)
- QB-14-120 CSV, no headers, custom category codes unsupported (blank), only Distribute Burden option documented.
- QB-14-121 Columns: [1 blank, 2 area name; both omitted entirely when Group by Areas off]; code; material net; tax (material, equipment or other tax); labor net (or +burden); burden (blank if distributed); subs net; equipment net; other net.
- QB-14-122 Tax is its own column here, not distributed.

### 14.03.06 QuickBooks budget (id 582)
- QB-14-130 XLS with headers in IIF-style form: !BUD marker, ACCNT, AMOUNT, CUSTOMER, PERIOD, STARTDATE. One row per code, amounts summed across cost types; cost type not exported.
- QB-14-131 Row: BUD; account or cost code; amount (net, +tax if distribute tax, +burden if distribute burden); customer = bid name; period = MONTH; start date = date chosen in options dialog.

### 14.03.07 JobCost (id 583)
- QB-14-140 CSV with headers, 32 columns (A to AF). Option Distribute Tax (unchecked gives separate MT rows). Cost type codes not exported; types are separate columns.
- QB-14-141 Used columns: A Phase = cost/account code (10 chars at vendor, 50 in QB); B Phase Name = description (40 vs 75); E labor hours; F labor net; G burden; H equipment; I material; J sub; K miscellaneous (H to K net, or +tax when distributed); N Phase Type = accounting phase number when Group by Accounting Phase is on, else blank; U to X quantities for equipment, material, sub, other.
- QB-14-142 All other columns blank (billing qty, billing, billing contract, workers comp, change order id/status, sort group, production, labor OH, vendor id).
- QB-14-143 Grouping by accounting phase number rolls up all bid areas sharing that phase number (amounts, hours, quantities); empty phase numbers roll up together.
- QB-14-144 Burden is always its own column G here (no distribute burden option).

### 14.03.08 Jonas (id 584)
- QB-14-150 CSV with headers. Options Include and Distribute Material Tax, Distribute Burden. Cost types separated into columns.
- QB-14-151 Columns: Cost Item (code); Cost Item Description; Est. Lab. Hrs.; Est. Lab. Amt (net or +burden); Est. Material Amt; Est. Subcontractor Amt; Est. Equipment Amt; Est. Other Costs (each net or +tax); Estimated Units (quantity); Units of Measure.

### 14.03.09 Maestro budget (id 585)
- QB-14-160 CSV with headers. Distribute Tax and Distribute Burden. One row per code per category.
- QB-14-161 Columns: Project Code = job number from cover sheet; Activity Code = cost/account code; Description; Activity Type constant A; Prefix blank; Group = category code; Category = category code; Quantity Budget = quantity (labor hours when category is L); Budgeted Cost = net amount (+tax or +burden when distributed); Budgeted Revenue constant 0.
- QB-14-162 Separate tax/burden rows use category codes MT/LB.

### 14.03.10 Maxwell American Contractor (id 586)
- QB-14-170 Two formats: Detailed and Summary, both CSV, no headers, category codes not exported. Distribute Tax and Distribute Burden available.
- QB-14-171 Detailed: col1 code, col2 description, cols 3 to 6 blank, col7 gross amount (labor gross minus burden; materials, equipment, other and sub gross minus tax; tax or burden on their own rows; with distribute, gross plus tax/burden), col8 labor hours (blank for equipment, other, sub rows), col9 labor net (+burden if distributed), col10 material net (+tax), col11 sub net (+tax), col12 equipment net (+tax), col13 other net (+tax).
- QB-14-172 Summary: code, description, blank, quantity, UOM (only when quantity linked to a UOM), blank, gross amount (same rule), labor hours, labor net (+burden), then one combined column for material/equipment/other/sub net (+tax).
- QB-14-173 UNKNOWN: precise "gross" vs "net" definitions (gross appears to be net including tax/burden).

### 14.03.11 Plexxis (id 587)
- QB-14-180 CSV with headers. Detailed line export including item data: Acct ID, Section # and description, Category Code, Cost Code and description, Account Code and description, Quantity, UOM (2 chars), Price Per, Price, Tax, Amount (net), Labor Burden Amount (labor rows only), Labor Hours, Item Code, Item Description, Part Number, Size, Required QTY, Container, Bid Area (full path, 255 chars), Phase #, Phase Description.
- QB-14-181 Material-only fields (price per, price, tax, item code, item description, part number, size, required qty, container) blank on non-material rows. Required QTY = quantity if priced by UOM, else quantity divided by per (container size).
- QB-14-182 Article closing text mentions another vendor name, likely a copy error.

### 14.03.12 Sage 100 Contractors / Master Builder (id 588)
- QB-14-190 Proprietary budget_grid file, no headers, category codes not exported, option Distribute Burden only.
- QB-14-191 Columns: A code; B labor hours; C material net + tax (tax always included); D labor net (or burden row, or net+burden if distributed); E equipment net + tax; F subs net + tax; G other net + tax.
- QB-14-192 If the same cost code is used by a condition and by equipment/other, multiple rows for that code appear (one per cost type).

### 14.03.13 Sage 300 CRE / Timberline (id 589)
- QB-14-200 jce file. Distribute Burden and Distribute Tax. Row 1 is a header record (semicolon marker, bid name, job-site and company addresses), row 2 a marker record starting with asterisk and job number (bid number if job number blank).
- QB-14-201 Detail rows: col1 "C" for cost code rows, "E" for group header rows (when Group by Areas); col2 code; col3 area name on group header rows; col4 category; col5 bid date as mmddyyyy; col6 quantity; col8 amount (net, +tax, or labor +burden); col13 area name.
- QB-14-202 Area names truncated to 10 chars; multi-level areas export only the last level.

### 14.03.14 StarBuilder / StarImport (id 590)
- QB-14-210 TXT with headers. Distribute Tax/Burden. Columns: Phase = area name (5 char limit, last level only), Cost Code, Cost Type = category, Description, Estimated Cost (net, or +tax/+burden), Estimated Hours, Estimated Quantity, Unit of Measure.

### 14.04 Job materials exports overview (id 591)
- QB-14-220 Exports > Job Material File > Options > Export Format (generic, AccuBuild, Maestro). Same file/Export button flow. Change order scope rule applies.

### 14.04.01 Standard material export (id 592)
- QB-14-230 XLS. Only items with material cost codes; equipment, other, subs excluded.
- QB-14-231 Columns: Acct ID (cover sheet account id); Item Code; Description; Part Number (item code); Size; Req. Qty; UOM; Price; Total; Cost Code (or account code); Export Date.
- QB-14-232 Req. Qty = container quantity = material qty / container size when priced by container, else material qty in UOM.
- QB-14-233 Price (unit price) = material price / container size (priced by container) or per UOM. Total = material net amount.
- QB-14-234 UNKNOWN: whether net amount includes tax and waste.

### 14.04.02 AccuBuild materials (id 593)
- QB-14-240 XLS; column set identical to standard material export (11 columns). Material cost codes only.

### 14.04.03 Maestro materials (id 594)
- QB-14-250 CSV. Columns: Project No. (job number, blank if none); Resource No. (account id from cover sheet); Resource Description (unit size/container); Inventory Code (product number, else item code); Req. Qty (container qty if priced by container else material qty); Characteristics blank; Activity (cost/account code); Group constant M; Item Date (export date); User No. blank; UP (unit price); Amount (material net); Item Code; Size; Description (product description).

### 14.05 Job Data File (id 608)
- QB-14-260 Raw cost export in CSV, flexible, not vendor formatted. Costs include tax and burden but exclude overhead and profit.
- QB-14-261 Global options Include Bid Number and Use Account Codes are ignored; account codes always exported.
- QB-14-262 Custom category codes shown as M,L,S,E,O.
- QB-14-263 Fields (24): BidAltCOName (blank when no child bids included); SectName; AreaOrTypicalAreaName; LabMatEqOtSub (cost type); CostCodeName; AccountCodeName; Description; Quantity (cumulative over all conditions for that code; 0 for markups tax/burden and indirect expenses); UOM; Amount (cost less markups and indirects, excluding overhead/profit); CrewDay; HoursPerDay; ManDay; ProdDay; BidAltCONotes; AccountCodeDesc; BTCostCodeName; BTAccountCodeName; BTDescription; BTAccountCodeDesc; Escalation; BurdenTax; TotalLaborHours; AmountExcludeTPA.
- QB-14-264 CrewDay = labor cost / daily wage / hours per day / crew size. ManDay = labor cost / daily wage / hours per day. ProdDay = quantity / ManDays (article also says ManDays = crew days times crew size, which conflicts with the ManDay definition; flag). TotalLaborHours = ManDays * hours per day. Production fields meaningless on material rows.
- QB-14-265 Typical area rows show quantity but amount 0; money lives on the bid area rows they are allocated to. AmountExcludeTPA = unburdened cost, 0 on typical-area rows.
- QB-14-266 If burden/tax cost code columns (BT*) are populated, the AmountExcludeTPA on that row is the tax/burden itself, which also appears in BurdenTax on the parent row. Importer must not take both (double count).
- QB-14-267 UNKNOWN: "Daily Wage" source (payroll class daily rate?) and escalation formula.

## CATEGORY 15

### 15.01 What is a database (id 595)
- QB-15-001 One database stores all data: bids, conditions, items, pricing, vendors. Two shipped: sample and blank. Orgs split per estimator, office, or project.
- QB-15-002 Options and defaults do not transfer between databases (synchronize copies only some, see 15.05.03).
- QB-15-003 Two engine types: Access (single user, local disk) and SQL Server (shared, network).
- QB-15-004 Do not run a live database in a cloud-synced folder (file locking); backups in a cloud folder are fine.

### 15.02 Open/close databases (id 596)
- QB-15-010 Many databases can be open at once, one bid active at a time; each open database costs RAM. Open Databases dialog (File > Open, toolbar, Bids tab right-click): checkbox list; password prompt with remember-me; buttons Properties, Compact/Repair, Backup, Find, Remove.
- QB-15-011 Remove drops a reference only (not for databases in default folder, which always list). Close hides from Bids tab, no data change.
- QB-15-012 Properties edits backup, auto-compress, measure mode, login settings.

### 15.03.01 Find Access database (id 597)
- QB-15-020 Find > choose Microsoft Access > properties dialog > lookup file. Never work inside the Backup folder, never keep Access files on network or removable drives, never open one Access file from two users.

### 15.03.02 Connect SQL (id 598)
- QB-15-030 Find > SQL Server: enter server name (case sensitive for interactive link identity; lowercase advised; named instance as server\instance), auth Windows or SQL login (SQL login recommended here), Connect lists databases, pick one. SQL entries show no modified date or size.
- QB-15-031 Mismatched server name case breaks the takeoff/bid interactive link (connection identity string).

### 15.04.01 Create Access database (id 599)
- QB-15-040 File > New > Database (or Bids tab context). Fields: file name (default folder C:\OCS Documents\Quick Bid, changeable), measure mode Imperial or Metric, auto-backup frequency and count, auto-compress frequency.
- QB-15-041 Names alphanumeric only. Requires-login checkbox only available after creation (need an administrator estimator first).
- QB-15-042 Measure mode drives all UOM boxes; never mix imperial and metric bids in one database or link mismatched takeoff/bid databases.
- QB-15-043 Defaults: backup weekly, keep 2 copies.

### 15.04.02 Create SQL database (id 600)
- QB-15-050 Created from inside the app (not the SQL console); requires dbo-level rights. Fields: server, auth, login/password, database name (suggest year+product+office), measure mode. No auto-backup/auto-compress for SQL; admin handles backups and shrink.
- QB-15-051 App must be installed on each workstation; not client-server.
- QB-15-052 Migration path: create SQL db, synchronize masters from the Access db (only one source db), drag-drop bids across in navigator (disconnect interactive bids first, reconnect after), verify, delete originals, archive old mdb out of sight.

### 15.05.01 Upgrade (id 601)
- QB-15-060 Maintenance ops: upgrade (Access/SQL), compact/repair (both; compact Access only), synchronize (both), backup (Access only).
- QB-15-061 Upgrade happens at first open in a newer version; irreversible, older versions cannot open. Back up first. SQL: coordinate all users, dbo only, admin backs up.

### 15.05.02 Compact and repair (id 602)
- QB-15-070 Run at least weekly; all other users must close app; SQL: admin only; clears log file. Right-click database on Bids tab also runs it. Login re-entry after run.
- QB-15-071 Auto compress runs at app close per database setting (default monthly); size only, not repair.

### 15.05.03 Synchronize (id 603)
- QB-15-080 Tools > Synchronize Databases: copies master tables source to destination. Never deletes destination records; inserts new, updates existing matches. Does not copy bids. Default: all master tables; can pick subsets, dependent tables auto-selected (Styles pulls Condition Types and Layers).
- QB-15-081 Copies Options for General, Category Codes, Folders; for QB also Payroll Settings and Default Markups and Indirect Expenses. Does not copy New Bid, M/U Cost Codes, Lookup options.
- QB-15-082 Contacts are insert-only: an edited source contact creates a new destination contact (preserves history); old stays.
- QB-15-083 UNKNOWN: matching key used to decide "already exists" for updates.

### 15.05.04 Backup/restore (id 604)
- QB-15-090 Access only. Default folder ...\Quick Bid\Backup (Options > Folders). Manual via dialog or right-click. Auto-backup runs on app close; naming database1.mdb, database2.mdb rotating oldest first. Recommend After Each Use with 10+ copies.
- QB-15-091 Restore = copy newest backup into database folder, open, compact/repair; restored file is a new database with its own backup chain.

### 15.06 Security / access levels (id 605)
- QB-15-100 Security is per database. Needs at least one Administrator-level estimator. Access Levels dialog from Master > Estimators: new level has description, "Set as System Administrator" (full access to all tables), and per-table setting Full Access / Read Only / No Access for five tables: Master Items, Others Bids, Bids List, Master (menu), Payroll Classes.
- QB-15-101 Master Items: full = edit master items (cannot delete ones used by assemblies/chains); read only = view; none = hidden list but type-ahead still inserts bid-level copies; bid-level edits never write to master.
- QB-15-102 Others Bids (based on Lead Estimator in cover sheet): full see+edit all; read only see all, edit own only; none see only own.
- QB-15-103 Bids List: full add/modify/delete any bid (overrides Others Bids); read only cannot create/delete base bids, folders or import, but may edit alternates and change orders; none hides Bids tab (admin-only role).
- QB-15-104 Master menu: view/edit rules; overridden by Master Items and Payroll Classes settings. Payroll Classes: full edits rates/burden; read only views; none grays menu item, bid-level payroll tab still editable.
- QB-15-105 Precedence: Master Items and Payroll Classes override Master; Others Bids overrides Bids List read only.
- QB-15-106 Used items and payroll classes are copied into bid-level records, so restricted users still edit those bid copies.
- QB-15-107 App logins separate from SQL/network logins; Windows auth supports single sign on.

### 15.06.01 Require login (id 606)
- QB-15-110 Properties > Logins Required; admin credentials requested; database reopens at login screen. Application users get a login dialog with remember option; domain users pass through silently.

### 15.07 Concurrent users (id 607)
- QB-15-120 Sharing needs SQL. One editor per bid: first user to touch any tab or cover sheet takes a bid lock; others get read-only. Lock icon in navigator and Bids tab; View Lock shows user, date, time.
- QB-15-121 Lock released when editor closes app/database or opens another bid. Admin force-removal: database right-click > Bid Locks > select > Delete; the displaced user's later changes are lost and they go read-only.

### 15.08 Rolling out master updates (id 882)
- QB-15-130 Pattern: keep a "Company Master" database per year, flag file read-only (clear flag to edit), users open it via Find, then synchronize with master as source and personal database as destination; repeat any time. Bid prices not changed by sync because each bid holds its own copy of items. Users should close master afterward to avoid read-only warnings.

## Category summary

### Category 14 (26 articles read: ids 570 to 594 and 608)
- Whole-bid sharing is via qbp packages; import always creates a new bid, never merges, and carries payroll settings and eQuote definitions but not supplier replies.
- Exports run from one dialog with per-export options; file is only written on Export; scope is the selected bid (change order alone, or base bid with optional accepted children).
- Global options: include child bids, include bid number, use account codes (account code replaces cost code when assigned, drives phase rollup of areas).
- Tax and burden handling is the key variable: distribute into the cost type amount, emit separate rows coded MT and LB, or drop tax entirely (varies by target).
- Category codes M, L, S, E, O are fixed for many exports; custom ones blank the file.
- Per-target layouts differ in headers, extension, area/phase grouping and truncation limits (area names cut to 5 or 10 chars, last level only).
- Material exports contain only material-cost-code items; quantity and price convert by container size when priced by container.
- Job Data File is the richest raw export: quantity, crew-day, man-day, production, burden/tax linked rows, typical area handling. Excludes overhead and profit.
- Only ComputerEase and Explorer carry marked-up amounts.
- Takeoff link: package import severs the interactive link.

### Category 15 (14 articles read: ids 595 to 607 and 882)
- Database = Access (single user, local) or SQL Server (shared); created from the app with measure mode fixed per database.
- Options mostly per database; synchronize copies masters (never deletes, upsert, contacts insert-only) plus selected option groups.
- Maintenance: upgrade is one-way; compact/repair weekly; Access auto-backup on close with rotating copies; SQL maintenance belongs to admin.
- Security: estimator access levels over five tables with explicit override order; require-login needs an administrator.
- Concurrency: one bid editor via bid locks; admin can delete locks.
- Bids hold copies of items so master changes do not alter existing bid pricing.
- Interactive takeoff link depends on identical server name text and matching measure mode.
