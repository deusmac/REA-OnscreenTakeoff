# QuickBid behavior notes, categories 08 to 13 (ledger prefix QB)

Source: scratchpad/g/qb/08_* through 13_*. All paraphrased. Product is called Quick Bid in the guide.

## CATEGORY 08: Section markups, indirect expenses, additional markups

### 08.01 Markups overview (id 504)
- QB-08-001: Three markup families exist, each calculated differently: Indirect Expenses (Stock, Clean, Supervision, Per Diem), Section Markups (Escalation, Tax/Burden, Overhead, Profit), Additional Markups (lump fees on bid totals).
- QB-08-002: Indirect Expenses attach to individual Cost Codes (material side) or Payroll Classes (labor side). Section Markups apply per Section of the bid on Material, Labor, Subs, Equipment, Other.
- QB-08-003: ORDER OF OPERATIONS: Stock, Clean, Supervision are applied first; then Section Markups (escalation, tax/burden, overhead, profit); Per Diem is applied after those (no escalation or tax/burden on Per Diem).
- QB-08-004: Additional Markups belong to no Cost Code, Payroll Class or Division/Section. They are added to the final bid total.
- QB-08-005: Default markups and indirect expenses are optional setup (Tools menu); many estimators skip them because they vary by job.
- QB-08-006: At bid level these are viewed/edited on the Markups tab. Default view is the whole Bid including accepted Alternates and Change Orders listed separately. Clicking a section in the "Bids and Sections" grid shows detail for that section.
- QB-08-007: Overhead/Profit method is Straight or Gross (see 08.01.02).

### 08.01.01 Viewing markup detail (id 505)
- QB-08-008: Two view checkboxes in Markup Detail: "Select all Bid sections" (combine all sections of the bid being viewed) and "Include accepted alternate sections" (Base Bid plus accepted Alternates; Change Orders are never included with base bid markups).
- QB-08-009: Neither checked = single Section in view (normal working mode); the title bar names the section or "All Bid Sections". Indirect Expense buttons (Stock, Clean, Supervision, Per Diem) are active only for a single section (or the documented override case).
- QB-08-010: Clicking a Bid/Alternate/Change Order row in the top grid is equivalent to ticking "Select all Bid sections".
- QB-08-011: With Alternates accepted, the Indirect Expense buttons are disabled when only "include accepted alternates" is ticked without "select all".
- QB-08-012: Opening Indirect Expenses in all-sections mode erases all previously configured IE (override). All four IE tabs must be re-entered in that same session or the dialog cancelled without saving.
- UNKNOWN: QB-08-013: exact enable/disable matrix of IE buttons for combinations of the two checkboxes; article text is internally inconsistent on this.

### 08.01.02 Straight vs Gross markup (id 506)
- QB-08-014: Method is set per bid on the Cover Sheet; default for new bids is under Tools > Options > New Bid. It affects only Overhead and Profit, plus any percent-type Additional Markup (each additional markup picks its own method).
- QB-08-015: STRAIGHT: OH = cost * oh_pct; Profit = (cost + OH) * profit_pct. Example: cost 2000, 20%/20%: OH 400, Profit (2400*0.20) = 480, total 2880.
- QB-08-016: GROSS: marked_up = base / (1 - pct); markup = marked_up - base. OH: 2000/0.8 = 2500, OH = 500. Profit: (2000+500)/0.8 = 3125, Profit = 625, total 3125.
- QB-08-017: Profit is always compounded on cost plus overhead (both methods). Overhead is treated as cost.
- QB-08-018: Overhead and Profit are computed per cost category (Material, Labor, Subs, Equip, Other) in the detail grid.

### 08.02 Indirect expenses overview (id 507)
- QB-08-019: IE apply to Material and Labor only. Not to Subs, Other, Equipment.
- QB-08-020: Each IE button has an "M/U" checkbox in the first column. Checked: the IE amount is included in the subtotal and receives Overhead and Profit. Unchecked: IE is removed from subtotal before OH and P are computed (so no markup on it).
- QB-08-021: Per Diem sits below Tax/Burden because neither Escalation nor Tax/Burden apply to it.
- QB-08-022: Section mode: edits affect the single section named in the dialog title; values persist when reopened. Bid-level (all sections) mode: values are zeroed every time the dialog opens, then written to all sections on OK.
- QB-08-023: Each IE type (Stock, Clean, Supervision, Per Diem) has its own calculation method and result type, configured independently per section.
- QB-08-024: Initial IE values for a section come from Tools > Default Indirect Expenses (if configured) and can be changed after the section is used in a bid.

### 08.02.01 Adjusting IE for one section (id 508)
- QB-08-025: Steps: Markups tab, select section row, click Stock/Clean/Supervision/Per Diem button; dialog opens on that tab. Changing one tab does not touch the others for a single section.
- QB-08-026: Buttons: "Save as Default" (writes this tab's settings into Default Markups and Indirect Expenses for the section; each tab saved separately; prompts to overwrite if the section already has defaults; hidden in all-sections mode), "Apply to All" (copies the value in the current column to every row), OK, Cancel.
- QB-08-027: Defaults saved here are applied next time the section is used in a new Bid or Change Order.

### 08.02.02 Bid-level IE override (id 509)
- QB-08-028: To set the same IE for every section: select the Bid row or tick "Select all Bid sections"; dialog title has no section name.
- QB-08-029: A warning says section-level IE will be zeroed if confirmed and OK pressed. Even with no entries typed, original values are cleared. Not undoable (defaults are unaffected).
- QB-08-030: Configure all four IE types in one session; reopening zeroes everything again.
- QB-08-031: Escape path: if Yes was chosen on the warning, Cancel then No on save prompt preserves old settings.

### 08.02.03 Stock and Clean (id 510)
- QB-08-032: Stock and Clean tabs are identical in layout, configured separately.
- QB-08-033: Calculation Method options: Material Quantity, Material Cost, Labor Hours. "Show results as" options: Material Cost or Labor Cost (Labor Hours method forces Labor Cost result).
- QB-08-034: Grid columns: Mat. Cost Code (every material cost code in the section), Quantity (read only; only for Material Quantity method), Percent (for Material Cost or Labor Hours methods), Cost (for Material Quantity method; a fixed unit dollar value), Total Cost, Cost Code (where the expense posts), Installers and Wage Type (shown only when result is Labor Cost; Installers via lookup).
- QB-08-035: Material Quantity: total_cost = section_qty_of_cost_code * cost_per_unit. Example: qty 1000 * 0.05 = 50.00.
- QB-08-036: Material Cost: total_cost = material_cost_for_code * percent (when result is Material Cost).
- QB-08-037: Labor Hours: total_hours = labor_hours * percent; costed through the chosen Installer payroll class and wage type.
- QB-08-038: Not every material cost code needs an entry; only those requiring stocking or cleaning.
- QB-08-039: When result is Labor Cost, each Wage Type (for example Union, Open) must be configured separately; settings for one do not carry to another.
- UNKNOWN: QB-08-040: exact labor-cost formula when Material Quantity or Material Cost method yields a Labor Cost result (hours per unit? rate conversion?); the screenshots that show this are not in the text.

### 08.02.04 Supervision (id 511)
- QB-08-041: Calculation methods: Labor Cost, Labor Hours, Duration.
- QB-08-042: Labor Cost/Hours grid: Payroll Class (all used in section), Cost (wages, Labor Cost method) or Hours (Labor Hours method), Percent (share allocated to supervision), Total Cost or Total Hours, Supervisor (lookup of Payroll Class), Wage Type, Cost Code.
- QB-08-043: supervision_cost = payroll_class_wages * percent (Labor Cost); supervision_hours = payroll_class_hours * percent (Labor Hours), then costed at the Supervisor payroll class wage. Inferred, article describes outcomes only.
- QB-08-044: Duration method: Installers grid lists every Payroll Class + Wage Type combination with its labor days (total man hours / hours per day). Select / Select All / Select None controls pick which to supervise.
- QB-08-045: Duration math: total_estimated_time_days = sum of labor days of selected rows; total_duration_days = total_estimated_time / crew_size; supervision_cost = total_duration_days * supervisor_daily_base_wage. Daily wage = hourly base * hours per day (35 * 8 = 280). Example: 23.328 days * 280 about 6531.96 (display shows 3 decimals, math keeps more digits).
- QB-08-046: Duration supervisor wage uses base wage without burdens (as stated). Supervisors grid: New button adds a Payroll Class; Wage Type defaults to the cover sheet prevailing wage type; Cost Code chosen via lookup; Total Wages computed from payroll class settings. Total Supervision Cost shown in the supervisor grid is what appears in the Labor column of Markup Detail.
- QB-08-047: Duration cannot be saved as a default (bid-specific).
- QB-08-048: Same per Wage Type separate setup rule applies for labor results.
- UNKNOWN: QB-08-049: whether burden and tax are later applied on top of the supervision wage (the Labor column implies it flows into labor markups).

### 08.02.05 Per Diem (id 512)
- QB-08-050: Per diem is always based on labor hours per Payroll Class.
- QB-08-051: Columns: Payroll Class, Hours, Per Hour, Per Day, Total Cost, Cost Code.
- QB-08-052: total_cost = hours * per_hour. Entering Per Day derives Per Hour (and vice versa) using hours per day from the Cover Sheet: per_hour = per_day / hours_per_day.
- QB-08-053: Defaults come from Default Indirect Expenses; configurable at section or bid level.

### 08.03 Section markups (id 513)
- QB-08-054: Section Markups: Escalation, Tax/Burden, Overhead, Profit. Applied per Section to Material, Labor, Subs, Equipment, Other, after IE (per diem excepted).
- QB-08-055: Escalation: a percent (positive or negative), job-specific, global over all five cost types. It adds cost to the bid, does not change item unit cost in the condition item grid, but does change each Condition's selling (marked-up) unit cost.
- QB-08-056: Tax = sales tax on materials; Burden = taxes, fees, insurance on labor. Tax/Burden for Material, Subs, Equipment, Other is directly editable in Markup Detail. Labor burden is a computed composite from payroll settings of all payroll classes in the section; not editable per section (see Labor Burden Override, 10.08).
- QB-08-057: Overhead is a percent applied to total costs (material, labor, optional IE, tax/burden). Treated as cost, so Profit is applied over it. Some estimators leave Overhead blank and use Profit only.
- QB-08-058: Profit percent applies to costs including overhead, IE (if M/U checked), tax/burden.
- QB-08-059: M/U checkbox next to IE buttons governs whether OH and P apply to IE amounts; OH and P always apply to the base costs.

### 08.03.01 Adjust section markups (id 514)
- QB-08-060: Select section in Bid/Section grid; edit any white-background cell, press Enter; dependent fields recalc. Saved immediately on Enter or leaving the field.
- QB-08-061: Labor Tax/Burden cannot be edited with a single section selected. Previous / Next buttons cycle sections. Add Notes button stores notes about markup changes.

### 08.03.02 Bid-level markup override (id 515)
- QB-08-062: Selecting a Bid/Alternate/Change Order row, or ticking "Select all Bid sections", lets one entry overwrite the per-section markups for all included sections. Not undoable.
- QB-08-063: Which fields are editable depends on selection; labor burden edit in this mode wipes burdens for every wage type and puts a single value into the override burden code (see 10.08).

### 08.04 Additional markups (id 516)
- QB-08-064: Located at the bottom of the Markups tab. Shown on all proposals but not on reports that require division/section or cost code/account code breakdown.
- QB-08-065: Added to bid total after IE and section markups. A manual selling price override on a section or bid does not affect them; they are added on top of the adjusted price.
- QB-08-066: Row fields: Description, Method, Apply To (result), Value.
- QB-08-067: Methods: Amount (flat), Cost per Thousand (amount per 1000 units of the Apply To result, so value * apply_to / 1000), Percent (percent of Apply To result, Gross or Straight chosen per row), Subtotal (a running total row of everything above it).
- QB-08-068: Apply To list includes system results and results of earlier additional markup rows (numbered like "(1) Contingency"), so markups can stack on markups.
- QB-08-069: Buttons: Use Defaults (loads saved defaults), add-row, Save as Default (all future bids get these rows; delete all but one row and save to clear).
- QB-08-070: Typical use: bonds, site insurance, special fees; subcontractor markup can go here (unattached to section) or in section markup detail (attached to section). General contractor fees also fit here.
- UNKNOWN: QB-08-071: exact list of "system results" selectable in Apply To; Cost per Thousand rounding.

## CATEGORY 09: Materials adjustments and eQuotes

### 09.01 Chapter intro (id 517)
- QB-09-001: Chapter covers material swap, refreshing prices from masters, container rounding, eQuotes. Items take defaults from masters; equipment and other costs usually come from assemblies.

### 09.02 Material swapping (id 518)
- QB-09-002: On Materials tab, right-click a Material/Size row, choose "Replace Material where in use". Each size is a separate row (example 4x8, 4x9, 4x10, 4x12 of one item). "View conditions in use" shows where used.
- QB-09-003: Disabled if the item is in an eQuote.
- QB-09-004: Compatibility rules: same Item Setup and UOM; same Condition Quantity source for calculation (if calc method differs, the line qty becomes Manual but keeps its value); same Size Method; same Material Pricing Method; same Labor Pricing Method.
- QB-09-005: Replacement picker is Master Items filtered to compatible materials ("Show matching items" checkbox); incompatible items cannot be chosen even if filter is off. Select performs the swap with no further confirmation.
- QB-09-006: Section, labor code, item quantity, and labor production rates do not change on swap.
- QB-09-007: If target lacks the size, prompt to add it to the bid-level item only (not master). No cancels the swap.
- QB-09-008: Swap can be done per size row (example swapped only the 4x9 size).

### 09.03 Refresh material prices (id 519)
- QB-09-009: Bid > Refresh Material Prices sets every material price to current Master Item pricing, with a confirmation prompt.
- QB-09-010: It un-accepts all awarded eQuotes and clears the Supplier on the Materials grid. Not undoable.

### 09.04 Rounding to whole containers (id 520)
- QB-09-011: Three commands: Round all to Nearest Container, Round all Containers Up, Round all Containers Down. They operate by changing the item's Waste Factor.
- QB-09-012: Nearest: if waste can be lowered (never below 0) to reach a lower whole container count, it does so; if even waste 0 leaves a fraction, it rounds containers and waste up. Example: 6.3 cartons at 10% waste goes to 6 cartons by waste about 4.7%; at 2% waste it must go up to 7.
- QB-09-013: Round Down: if waste is 0 or would need to be negative, the item is left unchanged.
- QB-09-014: Waste Factor is stored once per Item Size/Style across the entire bid, so area filters on the Materials tab do not isolate the effect; other areas using the item are affected.
- QB-09-015: If cover sheet preference "Apply Labor to Waste" is on, rounding also changes labor cost.
- QB-09-016: Rounding changes selling price; if price was fixed to a contract number, return to Markups tab and reset the selling price (profit absorbs; if even zero profit cannot reach the contract price, price goes to the minimum with profit 0).
- QB-09-017: Not undoable; duplicate the bid for what-if work.

### 09.05 eQuotes concept (id 521)
- QB-09-018: eQuote = a named group of material items sent for supplier pricing; supplier prices the group as a whole; multiple suppliers can be compared side by side.
- QB-09-019: Requirements: active maintenance subscription; Lead Estimator on Cover Sheet with email in estimator profile; suppliers with email; job-site zip on Cover Sheet; internet; mail client allowing XML-type attachments.
- QB-09-020: Accessed on Materials tab by ticking "View eQuotes"; welcome wizard (can be disabled; re-enable in Tools > Options "eQuotes Welcome Dialog").
- QB-09-021: Lapsed maintenance blocks the feature with an error. (Licensing, one line.)

### 09.06 eQuote workflow (id 522)
- QB-09-022: Sequence: price bid first (conditions finished, waste/rounding done); add items to eQuote; pick suppliers; send; confirmation email to Lead Estimator; supplier receives email with unique one-time link; supplier fills web form (prices, notes, minimum order qty, good-through dates), has one chance to back out before final submit; link dies after submit; supplier gets confirmation with recap and an XML file; estimator gets email with a .qbq file; opening it while Quick Bid runs imports the pricing into the right bid; estimator reviews and accepts all or part.
- QB-09-023: Supplier sees only what identifies bidder, contact, project and materials; estimator email is not included in the request.
- QB-09-024: Exporting a bid via Bid Package keeps eQuotes but after import they must be resent; outstanding requests are tied to the originating database and bid.
- QB-09-025: An item can be in only one eQuote within a Base Bid plus its Alternates (Alternates share material pricing with base). Change Orders hold their own material pricing, so the same item can be in a separate eQuote per change order.
- QB-09-026: Do not rename the project or database, or move it, after sending; the response will not import.

### 09.07 Create an eQuote (id 523)
- QB-09-027: Select items on Materials tab (Ctrl/Shift, or corner cell for all), drag to the "New eQuote Request" header; eQuote Details dialog opens: Name, Ship Date, Stocking Instructions, Notes to Supplier (paste from Word/Excel works), then Close.
- QB-09-028: Request item list columns: Item Code, Description, Quantity Requested, UOM, Price Per, Current Price.
- QB-09-029: Items are grouped by Material Cost Code by default (toggle in eQuote Manager menu).
- QB-09-030: Items can be added until the eQuote is sent; after sending to a supplier, no additions.
- QB-09-031: Combine Sizes (right-click on selected like items) merges sizes of one item into one line; "Combine All Sizes" button does it for all possible items.

### 09.08 Add/remove eQuote items (id 524)
- QB-09-032: Add more by dragging onto the existing eQuote; already-used items are refused with a warning.
- QB-09-033: Remove Item by right-click; allowed even after sending. Supplier pricing returned for removed items is ignored, but supplier may not honor remaining prices. Deleting all items deletes the eQuote.

### 09.09 Delete eQuote (id 525)
- QB-09-034: Delete eQuote from header drop-down; irreversible. Sent eQuotes ask for extra confirmation; replies to a deleted eQuote cannot be imported.
- QB-09-035: If deleted after award, the supplier name is removed from Materials grid but accepted pricing stays; Refresh Material Prices restores master pricing.

### 09.10 Invite suppliers (id 526)
- QB-09-036: Invite via "Click to Invite" header (available only after items exist), opens Contacts filtered to Suppliers; one at a time. New/Change buttons manage contacts; only contacts typed Supplier appear; Download button fetches a state supplier list.
- QB-09-037: eQuote is all-or-nothing per invitee; cannot send part of the items to one supplier and part to another (make separate eQuotes).
- QB-09-038: eQuote Manager menu: Edit eQuote, Send All eQuotes (also resends to already-sent), Print all eQuotes, Print eQuotes Comparison, Group By Cost Code (default on), Delete eQuote, Expand all, Expand this, Collapse all (collapsed line shows name, suppliers, accepted status).
- QB-09-039: Supplier menu: Send eQuote (sets Sent icon), View eQuote, Print eQuote (only items in the eQuote, even unpriced), Accept Quote, Unaccept Quote, Remove Supplier.
- QB-09-040: Accept Quote applies to checked items: sets material price and supplier on Materials tab; Accepted icon in Total cell. If another supplier's items are accepted later, the last accepted wins for those items.
- QB-09-041: Unaccept removes supplier name from Materials but does not revert pricing (see 09.14.05 conflict).
- QB-09-042: Remove Supplier deletes that supplier column and its prices, irreversible, disabled if that supplier's quote is accepted.
- QB-09-043: Items with a supplier already assigned on Materials cannot enter an eQuote until supplier is cleared; supplier cannot be set on Materials for items sitting in an eQuote.

### 09.11 Send eQuote (id 527)
- QB-09-044: Pre-checks: Bidding Company set; Lead Estimator set with valid email in employee record; job-site zip; supplier emails.
- QB-09-045: Send one supplier via supplier drop-down; send all via eQuote drop-down "Send all eQuotes". Sent icon appears. Confirmation email to Lead Estimator.
- QB-09-046: Removing items after sending is allowed; best practice is to resend if inventory changes.

### 09.12 Supplier side (id 528)
- QB-09-047: Supplier uses a web form; no Quick Bid needed. Requesting contractor and site info come from Cover Sheet bidding company, lead estimator and job site fields. Submit eQuote with one chance to go back. Confirmation email with contractor and site contact info, quote details, and XML.
- QB-09-048: Vendor mail allow-listing advice (two sender domains). Support content; not detailed.

### 09.13 Receive eQuote (id 529)
- QB-09-049: Import by double-clicking the .qbq attachment (bid database must be open) or File > Import > Quick Bid Quote File (*.qbq) if blocked.
- QB-09-050: After import, Materials tab opens on the eQuote panel with eQuote Details dialog showing prices. Each supplier column splits into "Quote Price Per" (unit price) and "Quote Item Total" (extended), with Quote Total beneath.
- QB-09-051: Supplier menu now enables View, Print, Accept. "Print eQuote Item Notes" checkbox hides line notes on print. Remove Supplier deletes response.
- QB-09-052: Obvious errors (wrong per-unit basis or material) mean ask supplier to resubmit.

### 09.13.01 eQuote alerts (id 530)
- QB-09-053: Alert icon beside a supplier's amount flags minimum quantity or good-through restriction; view via supplier action menu > View eQuote.

### 09.14 Comparing and awarding overview (id 531)
- QB-09-054: Accepting updates material price and supplier for the items; prompts to update master pricing if rights exist.

### 09.14.01 eQuote details, unquoted, overrides (id 252)
- QB-09-055: Unquoted items: accept anyway (price becomes 0), uncheck so not accepted, type a price in the eQuote grid, or remove the item from the eQuote (removes for all suppliers).
- QB-09-056: Overriding a supplier price in the grid shows blue text; view/print of the eQuote still shows original supplier numbers; override only in grid. Typing 0 for that item restores the supplier's original price (text turns black).

### 09.14.02 Comparison report (id 713)
- QB-09-057: eQuote drop-down > Print eQuotes Comparison, choose which vendors, Preview/Print. Report omits minimum order value.

### 09.14.03 Accept entire eQuote (id 237)
- QB-09-058: Header checkbox under supplier name toggles all items; Accept Quote is greyed until at least one row is ticked. Prompt for master update depends on Options "Ask before updating master material pricing" and user rights; otherwise only bid pricing updates.
- QB-09-059: Accepting items priced 0 sets bid material price to 0 (warned).
- QB-09-060: After accept, Materials shows supplier, price, price date; accepted icon, supplier column coloured. Manually overridden prices are labelled "(OVERRIDE)" with supplier name.
- QB-09-061: Accepted eQuote items cannot be changed; to fix a price, unaccept, set price, re-accept. To award an item to another supplier, tick it under that supplier and accept; a warning says the item was priced before; Yes replaces supplier and price.

### 09.14.04 Cherry picking (id 1035)
- QB-09-062: Tick individual items; the supplier "select all" shows semi-selected; Accept Quote applies only those. Risk: supplier prices may rely on the group. Can unaccept later.

### 09.14.05 Unaccept (id 879)
- QB-09-063: Supplier drop-down > Unaccept eQuote removes the supplier from the grid. Article says it restores original pricing in its first sentence and then says it does NOT restore previous prices (only removes supplier). Use Bid > Refresh Material Pricing or accept another quote to change price. If master was updated on accept, price stays at master value.
- UNKNOWN: QB-09-064: whether unaccept ever restores prior pricing; treat as no restore (matches 09.10 text).

### 09.14.06 Update master pricing (id 256)
- QB-09-065: Option Tools > Options > "Ask before updating master material pricing" (Confirmations). Prompted only if user has master edit rights.
- QB-09-066: Yes: Master Item price updated and supplier added to the master item; existing bids unchanged until Bid > Refresh Material Pricing. No: bid only. Update is immediate, irreversible.

### 09.14.07 Min order qty and Verify eQuote Price (id 236)
- QB-09-067: Minimum Order Qty alert on a supplier's amount; hover for text. Compare apples to apples; minimum can raise total cost.
- QB-09-068: If supplier quotes one size and the item price method is by UOM (one price for all sizes), item pricing updates for all sizes; the matching size gets the supplier; other sizes show "Verify eQuote Price" in Supplier column and can be edited manually. If price method is by Sizes, each size can be awarded from a different eQuote.

## CATEGORY 10: Labor cost and production

### 10.01 Chapter intro (id 534)
- QB-10-001: Three levels of production adjustment: line item, condition, bid. Also labor cost code swap and wage refresh.

### 10.02 How labor production is calculated (id 535)
- QB-10-002: Production is effort per quantity and does not change with quantity; only hours and cost scale.
- QB-10-003: Line item view of labor can show unit price, production, piece count, time, or total money; production/time shown by day or hour and by pieces or cut.
- QB-10-004: Item-level labor values (cost, production, time, total) are interlinked; editing one recalculates others.
- QB-10-005: Labor is based on the item Quantity (Qty column), including layers: layers 2 doubles the item qty (100 LF to 200 LF); unit labor cost and production stay; Crew Hours and Lab Total double.
- QB-10-006: hours = item_qty / production_per_hour; labor_total = hours * crew rate (or qty * unit labor cost). Inferred relation from described behavior.
- QB-10-007: Three adjustment levels: item grid (affects only that line), Labor Adjust in condition (all items using a labor cost code in that condition), Labor tab (whole bid).

### 10.03 Single item production (id 536)
- QB-10-008: "% Base" column: 100 = master default production. 150 = 50 percent faster (red for over 100), 75 = slower (blue for under 100). Higher production lowers unit cost, crew hours and total; lower production raises them.
- QB-10-009: production_pct scales: new_production = base_production * pct/100; unit_cost = base_unit_cost / (pct/100) (inferred).
- QB-10-010: Click headers (Qty/Day, Pcs/Day, Crew/days) to toggle day or hour view.
- QB-10-011: Pcs/Hr column relates to Size: pieces = production_qty_per_hr / size_area. Example: 125 SF/hr gives 3.13 sheets/hr for 4x10 (40 SF) and 2.60 for 4x12 (48 SF); Qty/Hr unchanged by size. Labor uses full size of piece.
- QB-10-012: Right-click Pcs/Day > "View as Cut Size": pieces computed from the Height column (cut length) rather than the Size column (full stock length). Example: soffit 3 ft high with 9 ft stud stock uses 3 ft per piece. Pcs/Day and Qty/Day stay linked.

### 10.04 Condition-level Labor Adjust (id 537)
- QB-10-013: Labor Adjust button at bottom of Condition Detail. Dialog "Items to use": a specific labor cost code, "Selected Labor Codes" (highlighted rows), or "All Labor Codes"; defaults chosen from grid selection (one row selected = that code; some rows = Selected; all labor rows = All).
- QB-10-014: Also a "Height to Use" filter limits adjustment to labor codes at a specific height.
- QB-10-015: Shows crew time (days and hours), production by UOM, unit price, total money; editing one updates others. 20 hours shows as 2 days + 4 hours on an 8 hour day (hours per day from Cover Sheet).
- QB-10-016: Math base here is the Condition Quantity, not the line item quantity: total_hours = sum of hours of each labor item; production = condition_qty / total_hours.
- QB-10-017: Applying a total (example 3 hours) across All Labor Codes distributes proportionally: the same percent change is applied to every labor line.
- QB-10-018: Not recommended for single materials with more than one layer.
- QB-10-019: Affects only the current condition.

### 10.05 Bid-level production (id 538)
- QB-10-020: On Labor tab; two methods: in-line row edit and Labor Adjust dialog.
- QB-10-021: Labor tab lists one row per Labor Cost Code (split by UOM and production, optionally by height). "Show Production" reveals four yellow production columns: %Base, Production (Qty/Hr-Day or Pcs/Hr-Day), Total Crew Hours, and related. "View conditions in use" shows where a row applies.
- QB-10-022: Without "Show Production", edits set the same production everywhere the code is used and original per-use rates are lost. With it on, edit applies only where production matches that row.
- QB-10-023: Green cells: Cost (per unit) and Total Cost editable; changing cost changes production. Wage Type can change cost without changing production. "Prod. Updated" shows last update date.
- QB-10-024: Restore defaults: type 100 in %Base (with Show Production on).

## Category summary

### 08 (13 articles read)
- Three markup families with fixed order: Stock, Clean, Supervision, then escalation/tax-burden/overhead/profit, then Per Diem, then additional markups on bid total.
- Straight markup: OH = cost*pct, Profit = (cost+OH)*pct. Gross markup: amount = base/(1-pct) minus base. Profit always on cost plus overhead.
- IE applies only to Material and Labor; M/U checkbox decides if OH and P apply to IE.
- IE methods: Material Quantity, Material Cost, Labor Hours (stock/clean); Labor Cost, Labor Hours, Duration (supervision); per diem by labor hours.
- Duration supervision: days/crew size * supervisor base daily wage.
- Bid-level (all sections) edits overwrite section-level values irreversibly; IE override zeroes all four IE types on open.
- Additional markups: Amount, Cost per Thousand, Percent, Subtotal; can chain; not tied to sections or cost codes; unaffected by selling price override.
- Labor burden is a composite and only overridable at all-sections level via the Labor Override burden code.

### 09 (22 articles read)
- Material swap requires matching setup, UOM, calc, size, and pricing methods; keeps labor and quantities.
- Refresh Material Prices resets to master and un-accepts eQuotes.
- Container rounding adjusts the waste factor (bid-wide per item size), never below zero.
- eQuote: group pricing request, one eQuote per item per base/alternates (change orders separate), supplier web form, .qbq import.
- Accepting an eQuote writes price and supplier to Materials; partial accept allowed; unpriced items accept as 0.
- Overrides show blue and "(OVERRIDE)"; typing 0 restores supplier price.
- Master price update prompt controlled by option and rights; irreversible.
- Min order qty and good-through alerts; "Verify eQuote Price" for non-matching sizes under UOM pricing.

### 10 (8 articles read)
- Production independent of quantity; hours = qty/production.
- %Base scales production (150 faster, 75 slower), unit cost moves inversely.
- Condition Labor Adjust uses condition quantity and distributes proportionally; Labor tab adjusts whole bid; no undo.
- View as Cut Size uses height instead of full stock size for piece counts.
- Labor cost code swap changes code only, keeps production and cost.
- Refresh Payroll Wages resets wages and burdens from master.
- Labor Burden Override only in all-sections view, requires a flagged override burden, alternates cannot override.

### 11 (5 articles read)
- Selling price edit solves for a single common profit percent across cost types.
- No negative profit; zero entry yields lowest price.
- Change orders priced separately; accepted alternates can be included with base.
- Equip/Subs/Other costs allocate to Bid Areas, single or multi, default Unassigned.

### 12 (13 articles read)
- Crystal-based reports in four categories plus custom; run for selected bid with section and area filters.
- Report Data Checker flags zero or missing source quantities.
- Analysis formulas: cost per sq size, labor risk = (OH+P)/burdened labor, cost percentages, unit price by cost code.
- Job Cost Summary totals are after tax, before markup; material reports exclude escalation.
- All tabs and reports printable/exportable to PDF, Excel, Word.
- Custom report contract: .rpt plus .ini with parameter list.

### 13 (6 articles read)
- Proposals are Word merge templates with bracketed fields; one document per recipient.
- Conditions list field takes decimals, group-by-area and unit-price flags.
- Child bid proposals are separate runs; change order values via base bid.
- SOV tab builds a billing contract, groups by cost code type or description, tunable OH/P with variance to bid total.
- SOV reports: summary (with optional O and P detail) and detailed.
