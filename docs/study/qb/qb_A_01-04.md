# QuickBid behavior ledger, notes A (categories 01 to 04)

## Category 01 - Introduction

### 01.08.01 Decimal places and display rounding (id 326)
- QB-01-001 Display rounding is separate from storage: quantities show as whole numbers by default; the full-precision value stays in the database and drives every calculation.
- QB-01-002 Decimal display is a program-wide setting (all bids, all databases), not per bid.
- QB-01-003 Display rounding is ordinary half-up style (1.13 shows 1, 1.51 shows 2).
- QB-01-004 Configurable on: Condition Detail and some dialogs, and all program tabs except Bids, Subs and Payroll Class tabs.
- QB-01-005 Per-column setting via right-click "Show Decimal Places" then choose a count; "Floating" option is capped at six digits right of the point. Applies to Equip/Other tabs (Qty, Equip/Other Rate, Equip/Other Total, Lab. Rate, Lab. Total), Materials and Labor tabs (qty, rate, total columns), Schedule of Values (every numeric, percent, dollar column; no effect on SOV reports), Markups tab calculated (non-entry) fields.
- QB-01-006 Markups tab entry boxes always show two decimals and cannot be changed.
- QB-01-007 Reports and exports use hard-coded two decimals or whole numbers regardless of display settings.
- QB-01-008 In Condition Detail, decimals for Qty 1, 2, 3 are driven by the takeoff app in an interactive bid; otherwise fixed at zero decimals.
- QB-01-009 Also settable in the Indirect Expense dialog, Master Item Detail pricing fields, and Assemblies.
- UNKNOWN: whether any internal rounding (for example to cents) happens at line level before summing.

- QB-01-025 Context menus vary by tab and click location; some options (decimal places, Group by Type, Verify All) exist only on context menus.

### 01.05 How dialog boxes work (id 349)
- QB-01-026 Dialog edits are saved on OK/Apply, not live. Deleting conditions, detail rows, subs, equipment, other entries and markup sections is immediate and permanent (no undo).
- QB-01-027 Deleting an alternate or change order is permanent and bypasses the Deleted Bids folder; base bids go to Deleted Bids.
- QB-01-028 Title bar shows "Master" or the bid name so you know which level you edit. Editing a master affects all bids except Items, Payroll Classes, Assemblies already used in a bid (those have isolated bid-level copies).
- QB-01-029 Bid-level edits affect only that bid; user may be prompted to push changes back to the master (affects future bids only), depending on options and rights.
- QB-01-030 Lookup-opened dialogs are Select/Cancel; plain list dialogs are OK only.
- QB-01-031 Caution: add-delete-add in a table dialog without pressing OK between can corrupt; save between steps.

### 01.06 Sorting, searching, filtering, grouping (id 350)
- QB-01-032 Click header once for ascending, again for descending; arrow shows sort key. Typing in a sorted list jumps to the first entry beginning with the typed characters; further characters refine.
- QB-01-033 Filter boxes sit at list top. Bids tab has four: Project Name, Primary Contact (contains-match text), Job Type, Estimator (dropdown). Bids filters persist across sessions and can block creating interactive bids.
- QB-01-034 Lists can be grouped: Bids by Job Status, Conditions by Type, Subs/Equip/Other by Division/Section breaks.

### 01.07 Imperial or metric UOM (id 351)
- QB-01-035 Measure system is a database-level choice made at creation; imperial and metric cannot coexist in one database. Default imperial. One takeoff database links to exactly one bid database, so projects must be split by system.
- QB-01-036 Imperial UOMs: EA, IN, LF, LY, IN2, SF, SY, SQ, CF, CY. Metric: EA, mm, m, mm2, m2, mm3, m3.
- QB-01-037 SQ (roofing square) = 100 SF = 9.290304 m2; imperial only.

### 01.08 Entering values in measurement boxes (id 352)
- QB-01-038 Imperial entry: last two typed digits are inches, rest feet, normalized (824 gives 10' 0"; 800 gives 8'; 10 gives 10"; 1010 gives 10' 10").
- QB-01-039 Metric entry: typed number is millimeters (1200 gives 1.2 m). A decimal allows fractions of an inch or mm.

### 03.08 and 03.08.01 Payroll settings, wage types, burdens (ids 397, 398)
- QB-03-012 Wage Types: named list (Open, Union, Sub by default), unlimited; order is cosmetic; cannot delete once used in any bid, assembly or item default.
- QB-03-013 Burdens: max eight lines; each has name, Method (Amount or Percent), Cost Code, Active flag, and Labor Burden Override flag (only one row; must be percent method and active). Percent is entered as a whole number (7.65 for 7.65 percent).
- QB-03-014 Burden math: burdens apply to the base rate, not to each other. Amount burdens convert to a percent of base: pct = amount / base_rate * 100. total_burden_pct = sum(percent burdens) + sum(converted amount burdens). Example: 12.50 / 25.00 = 50 percent; plus 25 percent gives 75 percent. Implied loaded_wage = base_rate * (1 + total_burden_pct/100).
- QB-03-015 Markup Detail shows combined burden as one percent. Typing a new percent in the labor burden field in Markup Detail puts the entire amount on the Override burden, replacing prior burden values.
- QB-03-016 Separate burden lines on job cost reports only when each has its own cost code. Clearing a burden is blocked if in use.
- UNKNOWN: how the Fees and Insurance fields on a payroll class interact with burdens (listed fields: Base Wage, Fees, Insurance, Tax, Labor).

- QB-03-020 Indirect Expenses (Stock, Clean, Supervision, Per Diem). Labor-based ones must be configured for every Payroll Class and Wage Type combination; unconfigured combinations get none.
- QB-03-021 This article says that if any individual section has indirect defaults, all-sections indirect defaults are ignored entirely (conflicts with wording in 03.10.02; see QB-03-025).

### 03.10.01 Indirect defaults all sections (id 403)
- QB-03-022 Stock tab: Calculation Method = Material Quantity, Material Cost, or Labor Hours; "Show result as" Labor Cost or Material Cost; rows by Payroll Class, Percent, Installer, Wage Type, Cost Code. Clean tab same plus material cost code fields. Supervision tab: method Labor Cost or Labor Hours; rows Payroll Class, Wage Type, Percent, Supervisor, Wage Type, Cost Code. Per Diem tab: per hour or per day amount per payroll class (entering one computes the other using hours per day), plus cost code.
- QB-03-023 Method meanings: Material Quantity = percent of cumulative quantity per material cost code; Material Cost = material dollars by cost code times percent; Labor Hours = percent of labor hours per payroll class; Labor Cost (supervision only) = percent of labor dollars. Result allocation: to a material cost code (with a material quantity) or to a payroll class and labor cost code.
- QB-03-024 Bid-level supervision has an extra method, Duration, not available for defaults.
- UNKNOWN: exact formula of "percent" for each method (for example stock_cost = pct * hours * rate) and how Per Diem is multiplied (days or hours).

## Category 04 - Masters

### 04.00 What are masters (id 406)
- QB-04-001 Masters are the reusable records: items, equipment, contacts, manufacturers, project/condition/item types, job statuses, cost codes, payroll classes, assemblies, estimators.
- QB-04-002 Master lists are labeled "Master" in the title bar. Some tables (condition type, job type, job status) sync with the takeoff app, hence the 1:1 database link. Cost codes and payroll classes sync with the production control product.
- QB-04-003 Payroll settings, wage types, burdens are database settings, not master tables.
- QB-04-004 First use of an item, payroll class or assembly in a bid makes a bid-level copy; later master edits do not change that bid. Bid-level changes can be saved back to master with rights.
- QB-04-005 Estimators used in any bid (lead or team) or as assembly owner cannot be deleted. Dependencies (items need payroll class, labor code, type, manufacturer) block deleting in-use records. No undo. Databases can be synchronized to move master tables.

### 04.01 Find and replace in-use records (id 407)
- QB-04-006 Most masters cannot be deleted when in use. Global Find and Replace (Replace button on Contact Types, Item Types, Manufacturers, Containers, Job Types, Condition Types): choose the record to replace and a replacement from the same table; every use in all bids and masters switches; then the original can be deleted.
- QB-04-007 Replace changes existing bids too; to avoid that, sync master to a new database, replace there, sync back (the old record stays in use in old bids).
- QB-04-008 "Show Where Used" is item-specific. Materials-tab Replace Material is bid-scoped only.

### 04.02 Contacts (id 408)
- QB-04-009 Contacts = companies and people (owner, architects, subs, suppliers, clients, own company), excluding estimators and manufacturers. Filter by Contact Type or Section (trades). Lookups auto-filter by the mapped Contact Type. Company-level sub-contacts (people) live inside the company record and are hidden from the main list. Own company is set first; it is the default bidding company on cover sheets, reports, proposals.

### 04.02.01 Contact types (id 409)
- QB-04-010 Type determines lookup visibility; suppliers can be attached to items and get eQuotes. Types can be created on the fly by typing a new one.

### 04.02.02 Adding a contact (id 410)
- QB-04-011 Company Detail: Type, address and phone fields, email (needed for eQuotes), checkbox for default bidding company, AEC Info tab, Notes. Only Cost Code, Quote Adjust %, Trades affect behavior: Cost Code filters the subs list; Quote Adjust % adjusts a sub quote in proposals only; Trades filter subs and suppliers by CSI section.

### 04.02.03 Company contacts (id 411)
- QB-04-012 People are added inside the Company Detail via New.

### 04.02.04 Import contacts CSV (id 412)
- QB-04-013 CSV import with exact header names (22 fields: First Name, Last Name, Title, Department, Work Phone, Home Phone, Mobile Phone, Pager, Home Fax, E-mail Address, Company, Business Street, Business Street 2, Business City, Business State, Business Postal Code, Business Country, Business Phone, Business Fax, Web Page, Notes, Contact Type). Only Company required; unknown company or contact type is created. No commas inside data. Every defined column needs a cell per row. Errors are written to a log file.

### 04.02.05 Download suppliers (id 413)
- QB-04-014 Download button fetches suppliers by US state (requires maintenance subscription and internet); results are ordinary editable contacts.

### 04.03 Items list (id 414)
- QB-04-015 Items are the building blocks: material cost, labor cost, or both. Typing an item code jumps to the match in the list and in the Condition Detail item grid. Column picker to show or hide columns; adding Sizes or Styles columns produces multiple rows per item.

### 04.03.01 Items list search and filter (id 234)
- QB-04-016 Sort by any column (default by Code ascending), type-ahead follows the sort column. Search box covers Code, Section, Cost Code, Type, Manufacturer, Description. Multi-select filters: Section, Material Cost Code, Labor Cost Code, Type, Manufacturer, with an "All" entry to reset.

### 04.03.02 Items list controls and context menu (id 415)
- QB-04-017 Buttons: Columns, New, Change, Delete (blocked when used in assembly, mixture, chain), Print, Duplicate, OK. Context menu: Show Item Detail, Show where in use, New, Duplicate (appends _1 to the code, which must stay unique), Delete (no effect on existing bids), Update Material Pricing by percent (selected or filtered items, reversible by a negative percent), Set Material Cost Code, Set Labor Cost Code, Set Section, Set Type, Set Manufacturer (bulk).

### 04.03.03 Column selector (id 235)
- QB-04-018 Required columns locked on; Sizes, Styles, Product Number off by default; Section, Material Cost Code, Labor Cost Code, Type, Manufacturer optional. Default columns: Code, Section, Mat. Cost Code, Labor Cost Code, Type, Manufacturer, Mat. Cost, Per, Price Updated.

### 04.03.04 Color coding (id 233)
- QB-04-019 Blue = sized by Styles or Styles with Sizes; pink = Mixture; chain-link symbol = item that starts a Chain (chained items are auto-added when the parent is dropped into a condition; the example parent adds two chained items, one itself a mixture).

### 04.04 Item types (id 416)
- QB-04-020 Categories to group and filter items in the Item List and Materials tab; creatable on the fly from Item Detail.

### 04.05 Manufacturers (id 417)
- QB-04-021 Separate master from suppliers. An item has one manufacturer but many suppliers. Partner manufacturer databases and assemblies can be downloaded under maintenance.

### 04.06 Containers (id 418)
- QB-04-022 Labels for how a material is ordered (box, bundle, gallon, each); set on the item's Sizing tab; no calculation effect.

### 04.07 Divisions and sections (id 419)
- QB-04-023 Based on CSI MasterFormat, customizable. Every cost (items, subs, equipment, other) is tied to a section. Section number must be 5, 6, or 8 digits, first two digits are the division; spaces added automatically. Cannot delete if used. Custom schemes effectively need a new database because sample items use MasterFormat.

### 04.08 Cost codes and account codes (id 420)
- QB-04-024 Cost code: Type (Material, Labor, Subcontractor, Equipment, Other), unique code, description, optional Account Code and Section. Account code: maps many cost codes to one accounting code; a cost code has at most one. Reports/exports can show account codes and fall back to cost code if none. Lists printable and exportable.

### 04.09 Payroll classes (id 421)
- QB-04-025 Worker groups with wage info per wage type: Base Wage, Fees, Insurance, Tax; hourly and daily wage cells calculate from the inputs; blank means unused. Wage types are managed in Payroll Settings. Payroll Tab and labor reports group by class.
- UNKNOWN: exact hourly and daily wage formula (presumably base plus burdens, daily = hourly * hours per day).

### 04.09.01 Master vs bid-level payroll class (id 422)
- QB-04-026 Copy per bid on first use; bid-level edits are isolated; Refresh Payroll Wages pulls the latest master values.

### 04.10 Estimators (id 423)
- QB-04-027 Per-database list; required for lead estimator, team, assembly owner. Fields: name, login name (defaults to initials), email (needed for eQuotes). Entries may be app-managed or Windows-authenticated users (single sign-on).

### 04.11 Job statuses (id 424)
- QB-04-028 Status per bid set on the cover sheet; new bids take the first status in the list (reorder with Move Up/Down to change the default). Lock Bid column makes bids with that status read-only. Cannot delete a status in use. Printable.

### 04.11.01 Lock Bid option (id 254)
- QB-04-029 Setting Lock Bid on a status makes all bids with it read-only for all users; unlock by changing the bid status or removing the check. Check this first if a bid will not edit.

### 04.12 Job types (id 425)
- QB-04-030 Project category (office, residential, hotel); set on cover sheet; sort and filter bids; creatable on the fly.

### 04.13 Condition types (id 426)
- QB-04-031 Category of conditions (doors, partitions, walls); set in Condition Detail; used to sort, group, filter the Conditions tab, filter Labor and Payroll tabs, and group condition assemblies.

### 04.14 What are assemblies (id 427)
- QB-04-032 Assemblies are smart templates: Condition Assemblies (item groups with layers, labor production) adapt to the receiving condition (for example height); Equipment and Other Assemblies are line groups.

### 04.14.01 Condition assemblies (id 428)
- QB-04-033 Stores items plus adjustments (production, layers, on-centers). Saves production rates, not absolute labor cost: production per 1000 SF is reapplied. Uses current material cost and current payroll wages at insertion. Height-based items are re-sized to the new condition height; labor production is not retuned. Direct-entry items are stored as a ratio to condition qty (100 LF on 1000 SF gives 0.1 LF per SF) and re-applied proportionally.

### 04.14.02 Import and export condition assemblies (id 429)
- QB-04-034 .qba files; import by double-click or File > Import; missing masters (types, manufacturers) are auto-created; imported items get a 3-character manufacturer code suffix to avoid overwriting existing items. Export: Ctrl+M reveals checkboxes and an Export button, then prompts for the 3-letter code.

### 04.14.03 Download manufacturer assemblies (id 430)
- QB-04-035 Partner databases/assemblies under maintenance. Synchronize with the user's database as Source and the partner as Destination so user data overwrites partner data in the destination; existing items are updated by new info.

### 04.14.04 Equipment assemblies (id 431)
- QB-04-036 Create from selected Equip rows (right-click New Equipment Assembly) or from the Master list; name and owner; recommended to save quantities and rates as 0. Insert via Equip tab context menu; then fill quantities and current rates.

### 04.14.05 Other assemblies (id 432)
- QB-04-037 Same as equipment assemblies for the Other tab.

## Category summary

### Category 01 (14 articles read)
- Bid data lives in a database; display rounding never alters stored values; calculations use full precision.
- Imperial or metric chosen once per database; imperial entry convention: last two digits are inches.
- Master changes are global except Items, Payroll Classes, Assemblies, which are copied into a bid on first use.
- Deletions of conditions, rows, alternates, change orders are immediate and permanent; base bids go to a restorable Deleted Bids folder.
- Type-ahead plus add-on-the-fly builds masters during bidding.
- Keyboard map: Ctrl+C/X/V/D/N/O, Insert, Ctrl+Alt+R recalc, F2/F3/F4/F5.
- Bid menu actions Refresh Material Pricing and Refresh Payroll Wages overwrite bid values from master.
- Renumbering conditions in an interactive bid must be done in the takeoff app.

### Category 02 (30 articles read)
- Tabs: Bids, Conditions, Subs, Equip, Other, Markups, Materials, Labor, Payroll, Schedule of Values.
- Subs: only accepted bids count; Net Adjust % raises the sub total silently; multi-area allocation by dollars.
- Equip and Other rows: total = qty * rate for both the equipment (or other) and labor; labor tied to payroll class and wage type.
- Conditions filters (section, area, type) scale totals to the slice; detail from an area filter is read-only for quantity.
- Materials: one price and waste per material per bid (change orders independent); rounding to whole containers works by adjusting waste.
- Labor tab aggregates by cost code, UOM, production; supports wage-type change, production toggles, adjustments, height breakout.
- Markups: per-section markups (escalation, tax/burden, overhead, profit) and indirect expenses (stock, clean, supervision, per diem); all-sections edits override every section irreversibly; selling price override adjusts profit.
- Schedule of Values builds billing contracts grouped by cost code type or description.

### Category 03 (16 articles read)
- Program options vs database options; new-bid defaults include hours/day, days/week, wage type, markup method, waste labor flag.
- Burdens: up to eight, percent or amount (amount converted to percent of base), applied to base only; one burden may be the override target.
- Default markups and indirect expenses configurable for all sections or per section; apply only when a section is first used.
- Labor-based indirect defaults need one entry per payroll class and wage type.
- Indirect methods: material quantity, material cost, labor hours, labor cost (supervision); bid-level adds Duration.
- Accounting exports use category codes and M/U cost codes; tax distribution options.
- Active Sections and Named Sets drive sub coverage tracking.
- Folders: backups separate from the database folder; avoid cloud-synced live databases.

### Category 04 (31 articles read)
- Master tables and their dependencies; used records are undeletable, with Global Replace for six tables.
- Items: code, section, material and labor cost codes, type, manufacturer, cost, per, sizing, styles, chains, mixtures; bulk edit commands and percent price update.
- Cost codes (typed) map to account codes (many to one) for accounting.
- Payroll classes: wage per wage type from base, fees, insurance, tax; copied per bid.
- Job status can lock bids; first status is the default; types sync with the takeoff app.
- Condition assemblies store production rates and ratios, re-size to condition height, use current prices.
- Equip and Other assemblies are best saved with zero rates; import/export via .qba with a 3-letter item suffix.
- Contacts have types driving lookups; CSV import with 22 fixed headers; supplier download by state.
